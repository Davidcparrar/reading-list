## 1. SpecEngineeringBench: Evaluating Coding Agents as Autonomous Specification Engineers
- **Authors:** Xingjian Wang, Shijian Wang, Minghao Liu, et al.
- **Summary:** Introduces a 100-instance benchmark drawn from 78 Python repos that measures whether a coding agent can act as its own specification engineer — deciding what to test and where to look without being given the bug description, entry point, or file hints. Agents are scored on two tasks: generating valid test suites and uncovering recorded defects via execution. Across seven frontier agents, tests themselves are strong (≈91% head pass rate, ≈80% change-focused coverage), but only 26% of defects are surfaced by Fail-to-Pass tests and function-level localization recall drops to 51%, showing the specification-authoring step is the current bottleneck.
- **Theme:** (3) Spec-driven development & formal verification for coding agents.
- **Relevance:** Direct, best-in-class fit for the spec/formal-methods axis — it operationalizes "define the correctness spec before fixing the code" as a benchmark.
- **Link:** https://arxiv.org/abs/2611.32973

## 2. ACAP: Asynchronous Coding Agents for Efficient Robot Control
- **Authors:** Zexin He, Rui Li, Yushi Lan, et al.
- **Summary:** Organizes a single robot as a team of persistent coding agents, one per control group (e.g. arm+gripper, torso+chassis), with a hyper-agent that assigns tasks and arbitrates physical dependencies — deciding when a lead agent writes code versus when member agents act in parallel. Across 72 real-world rollouts on 25 task/platform settings, asynchronous coordination cut task-balanced time cost by 28.2% versus a single-agent baseline, and it beat a fixed-delegation baseline on all 8 collaborative settings. The release includes a dataset of rollouts with generated programs, actions, and feedback.
- **Theme:** (2) Multi-agent frameworks & orchestration.
- **Relevance:** Clean, non-trivial coordination protocol with explicit role/tool assignment and an asynchronous execution model — a concrete architecture, not a survey.
- **Link:** https://arxiv.org/abs/2611.31205

## 3. Lazy Agents Answer Against Their Own Beliefs: Reinforcement Learning with Verifiable Beliefs
- **Authors:** Richmond Sin Jing Xuan, Peilin Feng, Wenbin Wang, et al.
- **Summary:** Proposes RLVB, where the simulator's exact posterior over the hidden answer is used as a dense reward: the agent is encouraged to keep gathering evidence while its posterior is still ambiguous and to commit once the evidence has become sufficient, with no judge, critic, or reward model needed. Across three vision-language models on three benchmarks, RLVB beats the base model in all nine settings, and outperforms outcome-only RL and LLM-judged process rewards at lower GPU cost. The authors argue the gain comes from the agent actually acting on its stated belief rather than answering prematurely.
- **Theme:** (1) Core LLM advances — reasoning / planning / agentic RL.
- **Relevance:** A novel, model-free reward signal for long-horizon reasoning that cleanly separates "evidence-gathering" from "committing" — directly relevant to agent reasoning loops.
- **Link:** https://arxiv.org/abs/2611.32884

## 4. Collect for Coverage, Replay with Evidence: Adaptive and Efficient On-Policy Distillation for Long-Horizon Agents (CARE-OPD)
- **Authors:** Haowen Hou, Gen Li, Ruilin Li, et al.
- **Summary:** Attacks two failure modes in prefix-replay on-policy distillation of long-horizon agents: teacher-only trajectories miss the histories the student itself would produce, and fixed replay schedules miss the decisions that actually matter. CARE-OPD mixes student-seeded teacher completions with response-level confidence gating to broaden coverage, and uses hindsight replay allocation to focus supervision on turns with downstream execution impact. On SWE-bench Verified it reaches 59.5% task success while cutting end-to-end training time by 45% and environment actions by 44% versus asynchronous online OPD.
- **Theme:** (1) Core LLM advances — fine-tuning / agent training efficiency.
- **Relevance:** Concrete method + strong SWE-bench numbers; speaks directly to how to train agents on verifiable coding tasks.
- **Link:** https://arxiv.org/abs/2611.34756

## 5. When Every Rollout Fails: Splicing Learner-Conditioned Options into Long-Horizon Agent RL (SPLICE)
- **Authors:** Haowen Hou, Yicheng Liu, Zhen Huang, et al.
- **Summary:** Targets the "all-fail group" pathology in group-relative RL (e.g. GRPO), where every sampled trajectory on a hard task gets zero reward and there is no gradient. For each all-fail group, SPLICE picks a splice point in a failed current-policy trajectory, a proposal model generates a handful of bounded continuation options, and their value is estimated by repeated continuations of the current policy — the positive estimates form a return-weighted local target. On SWE-bench Verified and BrowseComp-Plus with two policy families, SPLICE beats GRPO in all four settings (by 2.8–9.8 pts) and raises the GRPO graduation rate on initially-failed SWE tasks by 10.8 pts, while using less teacher compute than full-trajectory guidance.
- **Theme:** (1) Core LLM advances — reasoning / planning via agentic RL.
- **Relevance:** Addresses a real, well-known blocker in training agents on sparse verifiable rewards; concrete SWE-bench evidence.
- **Link:** https://arxiv.org/abs/2611.34777

## 6. CoT-Proxy: Cross-Format Transfer for Distilling Long-Horizon Policies
- **Authors:** Dawid J. Kopiczko, Tijmen Blankevoort, Yuki M. Asano, et al.
- **Summary:** Shows that long-horizon agent behavior can be distilled from a strong teacher's *actions only* — the student is trained with the reasoning block left empty while a KL penalty on its own outputs keeps it near its base model — and the student still reasons normally at inference, an effect the authors call cross-format transfer. Distilling Qwen3.6-27B lifts Qwen3-4B's AppWorld task success from 7% to 18% and Qwen3-32B's from 12% to 25%; adding short "CoT-proxy" teacher summaries after the empty block raises the 4B further to 35%. Because no hidden chain-of-thought is needed, the method also distills closed teachers: from visible GPT-5.6 Luna outputs and API reasoning summaries, Qwen3-4B reaches 48% on AppWorld and 28% on SWE-bench Verified (from 3%).
- **Theme:** (1) Core LLM advances — fine-tuning / PEFT and agent distillation.
- **Relevance:** Practical, provider-agnostic recipe for turning a smaller open model into a capable coding agent.
- **Link:** https://arxiv.org/abs/2611.33148

## 7. Letting Models Manage Their Own Context: Where We Stand
- **Authors:** Alessio Devoto, Avinash Vem, Tara Safavi, et al.
- **Summary:** Compares harness-triggered context compaction against a model-driven context API in NVIDIA's open agent harness on OfficeQA Pro v2 and ML-engineering tasks across 8K–512K budgets. Models that use the API well reach higher accuracy with fewer input tokens, especially at tight budgets (GPT 6.1 roughly triples at 32K; Kimi saves up to 41% input tokens), but models differ widely in when and how aggressively they compact. The paper also shows that inference engines can reuse the KV cache of the unchanged suffix after a model-issued edit, cutting prefill compute by up to 15% per request with no measurable accuracy loss — pointing toward a model/engine co-design.
- **Theme:** (1) Core LLM advances — agentic system architecture / evaluation.
- **Relevance:** Timely, empirical study of a design axis every agent harness has to decide; actionable results for anyone building long-running agents.
- **Link:** https://arxiv.org/abs/2611.34147

## 8. Beyond Code and Pixels: Co-Generating Editable and Visually Rich Presentations (SlidesWeaver)
- **Authors:** Wenrui Zhou, Jiashun Liu, Sujie Hu, et al.
- **Summary:** Presents SlidesWeaver, a hybrid multi-agent system for generating editable `.pptx` decks in which language agents and vision agents coordinate through shared deck-level and slide-level state. Staged multimodal commitment plus diffusion-based composition planning lets the system trade compositional freedom against faithful text preservation while keeping native text and editable geometry. Across 1,728 generations over 24 system/model configurations, SlidesWeaver reports consistently higher overall quality on every dimension evaluated, with practical generation efficiency.
- **Theme:** (2) Multi-agent frameworks & orchestration.
- **Relevance:** Explicit coordination protocol (shared state) between heterogeneous agents — a useful reference for mixed-modality agent architectures.
- **Link:** https://arxiv.org/abs/2611.28010

## 9. Coding4Games: Can Modern Coding Agents Play Modern Video Games?
- **Authors:** Shifang Zhao, Haoyu Wang, Yuyang Yin, et al.
- **Summary:** Builds a coding-agent benchmark on 15 modern video games in which the agent must write a standalone program that plays the game end-to-end using visual observations and standard controls — with no LLM inference at play time — and scores it under a separated development stage and a frozen test stage with both outcome and process metrics. The best agent-written programs outscore the strongest per-step GUI baseline on 13 of 15 games and tie on one, though a human still beats every agent on 10. The paper also studies how development-stage compute budgets shape results.
- **Theme:** (3) Spec-driven development & formal verification for coding agents.
- **Relevance:** Treats gameplay success as an executable correctness spec for agent-generated code — a different, useful cut on coding-agent evaluation.
- **Link:** https://arxiv.org/abs/2611.31974

## 10. CUA-SEE: Self-Evolving Evaluation Environments for Computer-Use Agents
- **Authors:** Wenhao Wang, Panrong Tong, Quyu Kong, et al.
- **Summary:** Replaces fixed benchmarks for computer-use agents with a closed loop in which tasks and executable verifiers co-evolve from agent rollouts — explicitly separating three goals: broadening difficulty/feature coverage, probing each agent's capability boundary, and tightening verifier precision via state-grounded checks with adversarial validation. Across five agents, applications, and rounds, the evolved benchmarks grew harder and broader and the verifiers tracked human judgment substantially better than static ones.
- **Theme:** (1) Core LLM advances — agentic-system evaluation.
- **Relevance:** Practical response to the "benchmarks saturate" problem; relevant to anyone designing live evaluation for agents.
- **Link:** https://arxiv.org/abs/2611.30962
