## 1. J-Zero: Unified Challenger–Solver–Judge Co-Evolution from Zero Data
- **Authors:** Gyouk Chu, Myeongho Jeon, Eunho Yang
- **Summary:** Proposes a three-role self-play loop where a Challenger proposes ever-harder tasks, a Solver attempts them, and a Judge learns to score outcomes from predefined preference pairs, all bootstrapped without any seed dataset. The three roles are coupled so that improvements in one continuously reshape the training distribution for the others, extending self-improvement to non-verifiable domains where a rule-based checker is not available. Reported results claim gains over prior self-play baselines across both verifiable (math/code) and unverifiable (open-ended) benchmarks.
- **Theme:** 2 (multi-agent frameworks & orchestration — role assignment + coordination)
- **Relevance note:** Clean role-decomposed multi-agent training recipe with a novel Judge-adaptation trick; directly maps to the "role/tool assignment, agent architectures" bullet.
- **Link:** https://arxiv.org/abs/2608.26582

## 2. DART-SD: Diamond-topology Aware Retrieval and Tuning for Self-Distillation of Multi-Turn Tool-Calling Agents
- **Authors:** Hangrui Xu, Jiarui Wang, Yang Yang, et al.
- **Summary:** Frames the branching structure of multi-turn tool-calling trajectories as a "diamond" DAG and shows that naive SFT on best-trajectory data causes "topological collapse" where alternative valid branches are forgotten. The fix is a retrieval step over the diamond plus a localized self-distillation loss that only corrects the sub-steps where the student diverges, preserving the surrounding valid reasoning. Yields measurable gains on multi-turn tool-use benchmarks over trajectory-level SFT and DPO baselines.
- **Theme:** 2 (multi-agent — tool-use / agent training)
- **Relevance note:** Concrete method for fixing a well-known failure mode of tool-calling agent finetuning; directly relevant to agentic-system training.
- **Link:** https://arxiv.org/abs/2608.18524

## 3. ContextPilot: Teaching Agents for Proactive Context Management via Fine-grained RL
- **Authors:** Zhuoshi Pan, Qizhi Pei, Junru Lu, et al.
- **Summary:** Gives an agent an expanded toolbox of context-editing operations (add, drop, summarize, pin) and trains it with RL that samples multiple branches at each editing decision to isolate which edits actually improve downstream success. The reward is credit-assigned per edit rather than per trajectory, letting the agent learn a compact working context on long-horizon tasks. Reports better long-horizon completion rates than static-context and heuristic-compression baselines.
- **Theme:** 1 (core LLM — agentic evaluation, RL for reasoning) with strong Theme 2 spill-over
- **Relevance note:** Directly attacks the "context-management for agents" problem with a proper credit-assignment method rather than a heuristic; high implementation value.
- **Link:** https://arxiv.org/abs/2608.28476

## 4. StepGuard: Learning Step-Level Guardrails with Scalable Supervision and Safety-Utility Balancing
- **Authors:** Zhijie Zheng, Yu Li, Chen Qian, et al.
- **Summary:** Trains a small guard model that audits each proposed agent action before execution, using automatically generated adversarial trajectories as training data and a two-objective RL loop that jointly balances refusal-rate against task-success. Reports a 77.3% reduction in attack success on agent-safety benchmarks with only a small utility drop. Positions itself as an alternative to full-trajectory judges for real-time agent deployment.
- **Theme:** 2 (multi-agent — orchestration and safety layer)
- **Relevance note:** Step-level guard is a common architectural component for production agent stacks; useful reference for anyone wiring correctness checks around tool-calling.
- **Link:** https://arxiv.org/abs/2608.24777

## 5. Paint What You See: Benchmarking Dexterous Visual Tool Use in Multimodal Agents (EASEL)
- **Authors:** Shudong Liu, Dongyang Chen, Enci Zhang, et al.
- **Summary:** Introduces EASEL, a benchmark requiring multimodal agents to drive a parameterized graphical tool (a paint-like interface) in a closed loop, exposing failure modes the paper calls "reconstruction-similarity bottlenecks" and closed-loop instability. Compares recent frontier MLLM agents and finds none reach human-level dexterity on fine-grained visual actions. Provides a leaderboard and a modular protocol so new tools/actions can be plugged in.
- **Theme:** 1 (core LLM — agentic-system evaluation)
- **Relevance note:** Rare closed-loop, non-code agent benchmark with a well-specified scoring pipeline; fills a gap in the mostly-text agent-eval landscape.
- **Link:** https://arxiv.org/abs/2608.25417

## 6. Agentic Artifact Creation: Systems, Evaluation, Principles, and Opportunities
- **Authors:** Tianfu Wang, Zhezheng Hao, Xilin Xia, et al.
- **Summary:** Surveys 259 systems where an AI agent constructs or revises a durable deliverable (document, codebase, slide deck, design) rather than only returning a chat reply, and organizes them by artifact family, control loop, and evaluation methodology. Extracts a set of principles for "accountable control" of such systems — provenance, revision boundaries, and reviewer-in-the-loop patterns. Notes evaluation is currently dominated by ad-hoc rubrics and calls for shared benchmarks.
- **Theme:** 1 (core LLM — agentic-system evaluation)
- **Relevance note:** Useful survey/taxonomy for anyone designing agents that produce artifacts (specs, code, docs); the "accountable control" principles are directly reusable in system design.
- **Link:** https://arxiv.org/abs/2608.28122

## 7. Fast Weight Attention for Continual Learning
- **Authors:** Yifan Zhang, Steve Ta, Jasper Zhang, et al.
- **Summary:** Reinterprets several recurrent "fast-weight" memory modules (RWKV/linear-attention variants) as instances of online learning rules over key-value memories, then derives a normalization scheme that keeps updates stable when contexts grow. Empirically shows better length extrapolation and lower drift on continual-learning benchmarks. Also gives a small set of design axioms (bounded key norms, projected updates) that transfer across architectures.
- **Theme:** 1 (core LLM — memory / architecture)
- **Relevance note:** Unifies several ad-hoc long-context memory schemes under one framework with a stability guarantee; strong candidate for the memory subcluster.
- **Link:** https://arxiv.org/abs/2608.27763

## 8. Ring Forcing: Towards Precise Long-Term Memory for Autoregressive Video Diffusion
- **Authors:** Bowen Xue, Brandon Y. Feng, Chenguo Lin, et al.
- **Summary:** Trains an autoregressive video diffusion model with a "ring" schedule that repeatedly forces the model to re-consult compressed representations of much earlier frames, combined with a learned history-compression module. Demonstrates minute-scale object permanence and scene consistency where prior autoregressive video models drift within seconds. The memory design is architecture-agnostic and could inform long-context language modeling.
- **Theme:** 1 (core LLM — memory, cross-domain)
- **Relevance note:** Explicit long-term memory mechanism with clear evaluation; interesting cross-modal reference for LLM long-context work.
- **Link:** https://arxiv.org/abs/2608.26794

## 9. LayerRecall: A State-Conditioned Memory Router for Long-Horizon Consistency in Video Generation
- **Authors:** Yixuan Ding, Jiahao Kong, Wei Huang, Ruijie Quan, Yi Yang
- **Summary:** Adds a small router that decides which specific transformer layers of a video diffusion model should receive injected long-range memory tokens, conditioned on the current generation state. Trained with a cross-horizon prediction-matching objective so the router learns which layers actually need history to keep entities consistent. Reports stronger long-video consistency than uniform memory injection at similar compute cost.
- **Theme:** 1 (core LLM — memory routing)
- **Relevance note:** The state-conditioned per-layer routing idea is directly portable to long-context LLM architectures; not just a video-only trick.
- **Link:** https://arxiv.org/abs/2608.28460

## 10. PonderPounce: A Pretrained MLLM as an Episode Context Engine for Robot Control
- **Authors:** Suhwan Choi, Jaeyoon Jung, Sungkyung Kim, Yunsung Lee, Youngjae Yu
- **Summary:** Uses a frozen native-multimodal LLM as an "episode memory" engine that maintains a causal running context of what the robot has seen and done, then jointly trains a small reasoning head and an action head on top. Shows that treating the MLLM's context as the memory substrate (rather than adding a separate memory bank) improves manipulation-benchmark scores. Provides a lightweight recipe for reusing existing MLLMs in embodied-agent stacks.
- **Theme:** 2 (multi-agent — agent architecture, memory-as-context)
- **Relevance note:** Illustrative pattern for using an MLLM as a shared memory/reasoning module across sub-agents; useful architectural reference.
- **Link:** https://arxiv.org/abs/2608.24115
