## 1. From Execution to Capability: Scientific Experience Consolidation via Procedural Knowledge Synthesis
- **Authors:** Liwei Dong, Jiahao Zhao, Nan Xu
- **Summary:** Names an "abstraction–execution gap": procedures that reliably lift a 27B model give a 9B model almost nothing when handed to it as advice. The fix is to have the stronger model rewrite each abstract procedure into concrete, executable code trajectories, then supervise the 9B student on those, so the experience is consolidated into weights rather than into a runtime procedure library — gaining ~6.25 main-problem points on scientific tasks with procedure-free inference.
- **Theme:** Memory (procedural knowledge synthesis / experience consolidation for LLM agents).
- **Relevance note:** Direct hit on "memory for LLMs and agents" — treats an experience log as something to be compiled into capability instead of retrieved at inference.
- **Link:** https://arxiv.org/abs/2607.24459

## 2. JarvisHub: An Open Harness for Canvas-Native Multimodal Creative Agents
- **Authors:** Yunlong Lin, Zixu Lin, Zhaohu Xing, et al.
- **Summary:** Puts an editable canvas at the center of a long-horizon multimodal agent stack and treats it as both shared workspace and inspectable external memory. A three-layer architecture separates policy, tool execution, and canvas state so multiple specialists can interleave with human edits without losing project context across turns.
- **Theme:** Multi-agent orchestration (with a strong memory-as-shared-state angle).
- **Relevance note:** Rare open harness that makes the memory substrate a first-class part of the multi-agent protocol rather than a bolt-on RAG store.
- **Link:** https://arxiv.org/abs/2607.23588

## 3. From Proprietary to Open-Source: Bridging the Distribution Gap via Multi-Agent Protocol Distillation in Agentic Search
- **Authors:** Junlin Liu, Jiangwang Chen, Zixin Song, et al.
- **Summary:** Argues the gap between proprietary search agents and open students is really a *protocol* gap — how plans are named, queries phrased, evidence cited. MAPD forces teacher and student trajectories through a structured intermediate protocol during distillation, transferring skill rather than surface style; Qwen3-1.7B/4B reach 39.4% / 44.4% success on seven QA benchmarks with less verbosity collapse.
- **Theme:** Multi-agent frameworks (protocols for coordination + role assignment during distillation).
- **Relevance note:** Concrete evidence that a shared communication protocol is what actually transfers between agents in a coordination pipeline.
- **Link:** https://arxiv.org/abs/2607.24280

## 4. A New Role for Relevance: Guiding Corpus Interaction in Agentic Search
- **Authors:** Jiangnan Li, Yuqing Li, Mo Yu, et al.
- **Summary:** Reframes retrieval relevance as an *execution prior* for a ripgrep-style search agent instead of a pre-filter: document-level scores reorder which files the agent scans, and match-level reranking surfaces excerpts that output truncation would otherwise drop. The coarse-to-fine guidance converges faster and outperforms both retrieval-only and pure direct-interaction agents on reasoning-heavy QA and retrieval benchmarks.
- **Theme:** Multi-agent / agentic search (with a retrieval–memory interface angle).
- **Relevance note:** Practical alternative to "retrieve-then-read" that keeps the agent in the loop, worth reading against the SciConsolidate / JarvisHub views of memory.
- **Link:** https://arxiv.org/abs/2607.24223

## 5. The Physics of Multi-Turn Long-Horizon Planning: From Pre-training to Post-training via Single- and Multi-Teacher On-Policy Agentic Distillation
- **Authors:** Tianyi Men, Zhuoran Jin, Kang Liu, Jun Zhao
- **Summary:** Decomposes long-horizon planning skill into three life-cycle stages — acquisition in pre-training, shaping via GRPO / on-policy distillation, and integration via multi-teacher on-policy agentic distillation — and studies what each stage actually installs. Introduces "planning-pattern compatibility" as the property that lets a distilled policy generalize across environments and keep learning without regression.
- **Theme:** Core LLM advances (planning + agentic post-training).
- **Relevance note:** Useful mental model for where planning capability comes from and where cross-domain transfer breaks; sits between core LLM training and multi-agent evaluation.
- **Link:** https://arxiv.org/abs/2607.24720

## 6. Kimi K3: Open Frontier Intelligence
- **Authors:** Kimi Team (Moonshot AI), et al.
- **Summary:** A 2.8T-parameter Mixture-of-Experts model with ~104B activated parameters, native vision, and a 1M-token context window built on new Kimi Delta Attention plus "Attention Residuals" for information flow at long context. Reports frontier-tier results across coding, agentic, knowledge, reasoning, and vision benchmarks, trailing only Claude Fable 5 and GPT-5.6 Sol.
- **Theme:** Core LLM advances (frontier scaling + long-context architecture with an agentic evaluation slant).
- **Relevance note:** Interesting less for the leaderboard number than for what Delta Attention + Attention Residuals imply about supporting long-horizon agentic workloads at open weights.
- **Link:** https://arxiv.org/abs/2607.24653
