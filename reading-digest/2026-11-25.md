## 1. SpecEngineeringBench: Evaluating Coding Agents as Autonomous Specification Engineers

- **Authors:** Xingjian Wang, Shijian Wang, Minghao Liu, et al.
- **Summary:** Builds a 100-instance benchmark drawn from 78 Python repositories that asks coding agents to act as spec engineers — translating a natural-language requirement into a test suite that discovers unknown defects, with no oracle hints. The authors show that high surface metrics (test validity, line coverage) correlate poorly with the agents' actual ability to catch latent bugs, and that defect localization recall degrades sharply when the required granularity shifts from file to function level.
- **Theme:** (3) Spec-driven development & formal verification for code correctness.
- **Relevance:** Direct hit on spec-driven development for agent-generated code; it formalizes the gap between "tests pass" and "tests surface real bugs" that the user flagged as the core correctness question.
- **Link:** https://arxiv.org/abs/2611.32973

## 2. CoT-Proxy: Cross-Format Transfer for Distilling Long-Horizon Policies

- **Authors:** Dawid J. Kopiczko, Tijmen Blankevoort, Yuki M. Asano
- **Summary:** Distills long-horizon agent behavior from a stronger teacher using only teacher *actions*, leaving the student's reasoning block empty and regularizing against drift with a KL term; the student still runs at inference with thinking enabled. On AppWorld and SWE-bench Verified the method lifts Qwen3-4B and Qwen3-32B over SFT baselines, and augmenting with short teacher "CoT-proxy" summaries pushes results further — importantly, the recipe also works against closed teachers whose hidden CoT is unavailable.
- **Theme:** (1) Core LLM advances — fine-tuning and agent distillation.
- **Relevance:** Practical post-training recipe for agentic LLMs that sidesteps the closed-CoT ceiling; directly useful for anyone fine-tuning open models to imitate proprietary agents.
- **Link:** https://arxiv.org/abs/2611.33148

## 3. Lazy Agents Answer Against Their Own Beliefs: Reinforcement Learning with Verifiable Beliefs Teaches Them to Act on What They Believe

- **Authors:** Richmond Sin Jing Xuan, Peilin Feng, Wenbin Wang, et al.
- **Summary:** Diagnoses a failure mode where agents commit to final answers before their stated beliefs justify it, and proposes an RL reward derived from the simulator's exact posterior so the agent is scored on whether its actions are consistent with its current evidence. The resulting policies learn when to keep gathering information versus when to commit, improving calibration and task success on partially observable benchmarks.
- **Theme:** (1) Core LLM advances — RL for reasoning and planning under uncertainty.
- **Relevance:** A clean reward-shaping idea for agent RL that targets a concrete, observable pathology ("lazy commitment"); transfers beyond any one benchmark.
- **Link:** https://arxiv.org/abs/2611.32884

## 4. Unlocking the Power of Loops in Pretrained LLMs with Loop Residuals

- **Authors:** Xuanlei Zhao, Hailun Xu, Kai Wang
- **Summary:** Introduces LoopRes, a lightweight adapter that lets looped transformer layers attend back to a small window of their own prior iterations via trainable loop-aware keys, turning iterated-depth compute into a usable test-time knob. Reported gains over supervised fine-tuning across several model families and better scaling of accuracy with inference compute.
- **Theme:** (1) Core LLM advances — parameter-efficient depth adaptation and test-time scaling.
- **Relevance:** A small-footprint PEFT-adjacent trick that improves test-time reasoning headroom on existing pretrained weights; cheap to try.
- **Link:** https://arxiv.org/abs/2611.31094

## 5. Self-Evolving Evaluation Environments for Computer-Use Agents (CUA-SEE)

- **Authors:** Wenhao Wang, Panrong Tong, Quyu Kong, et al.
- **Summary:** Proposes CUA-SEE, a closed-loop harness that co-evolves tasks and executable verifiers for computer-use agents, raising task difficulty automatically as frontier agents saturate the easier ones. Keeps the benchmark diagnostic over time rather than static.
- **Theme:** (1) Core LLM advances — agentic-system evaluation.
- **Relevance:** Addresses benchmark saturation, which has become the main obstacle to comparing rapidly-improving computer-use agents; the co-evolution pattern generalizes.
- **Link:** https://arxiv.org/abs/2611.30962

## 6. What Makes Good Data for Training Coding Agents? A Systematic Study on SWE-Gym

- **Authors:** Yikai Zhang, Mai Xu, Yunbei Zhang, et al.
- **Summary:** Audits the SWE-Gym training set and finds a non-trivial share of "unsolved" tasks whose hidden tests actually reject correct fixes, i.e., the supervision signal is wrong. Repairing or removing those tasks trains strictly better coding agents, and the authors release a verified dataset plus the audit pipeline for others to reuse.
- **Theme:** (3) Spec-driven development & code correctness (oracle integrity for coding agents).
- **Relevance:** Reinforces that correctness of generated code is bottlenecked by correctness of the specification/test signal itself — a near-direct precursor to spec-engineering work like #1.
- **Link:** https://arxiv.org/abs/2611.30207

## 7. ACAP: Asynchronous Coding Agents for Efficient Robot Control

- **Authors:** Zexin He, Rui Li, Yushi Lan, et al.
- **Summary:** Structures a robot as a persistent team of coding agents, each owning one part of the robot and executing asynchronously, orchestrated by a higher-level hyper-agent that resolves conflicts and reassigns ownership. Real-world evaluation shows lower task latency than monolithic single-agent policies at comparable success.
- **Theme:** (2) Multi-agent frameworks & orchestration.
- **Relevance:** A concrete orchestration architecture with explicit role assignment and asynchronous communication — the exact axis of interest for this theme.
- **Link:** https://arxiv.org/abs/2611.31205

## 8. Embodied-Harness: Towards Recursive Self-Improvement for Robotic Manipulation

- **Authors:** Zhenxuan Fan, Zhuoya Wang, Yuqian Yuan, et al.
- **Summary:** Pairs an Actor agent that executes manipulation with a Reflector agent that mines each execution for reusable guidance, maintained in a hierarchical memory. Success improves recursively without updating model weights, driven entirely by inter-agent protocol and shared memory.
- **Theme:** (2) Multi-agent frameworks & orchestration.
- **Relevance:** Clean Actor–Reflector decomposition with a memory-mediated communication protocol; the pattern generalizes well beyond manipulation.
- **Link:** https://arxiv.org/abs/2611.27689

## 9. ToolSmith: An Automatic Tool-Generation Framework for Multimodal Search Agents

- **Authors:** Rui Sun, Junhua Huang, Luca Zancato, et al.
- **Summary:** Lets a multimodal search agent extend a small base tool library at runtime by synthesizing new tools and caching successful ones for reuse. In- and out-of-domain evaluations show gains over the fixed base library, with larger backbones extracting more value from the generated toolchain.
- **Theme:** (2) Multi-agent frameworks & orchestration — dynamic tool assignment.
- **Relevance:** Formalizes tool generation as a first-class action an agent can take, which cleanly complements static tool-use benchmarks.
- **Link:** https://arxiv.org/abs/2611.31198

## 10. Innata-0: A Native Embodied World System with Model-Agent Co-Design

- **Authors:** Innata Team (Yu Bai, Ziyi Bai, et al.)
- **Summary:** Co-designs an embodied world-action model and a surrounding agent that handles memory, verification, and recovery so that training-time and execution-time assumptions stay aligned across long-horizon physical tasks. Reports gains attributable specifically to the model↔agent alignment rather than either component alone.
- **Theme:** (2) Multi-agent frameworks & orchestration (model-agent system design).
- **Relevance:** Argues explicitly that agent orchestration and underlying policy model should be designed jointly — a useful counterpoint to "wrap a frozen LLM" architectures.
- **Link:** https://arxiv.org/abs/2611.30254
