## 1. CodeMidas: Scaling Agentic Coding RL Environments from Code Itself
**Authors:** Bowen Ye, Lei Li, Shicheng Li et al.
**Summary:** CodeMidas mines existing multi-language codebases and turns them into 5,545 executable reinforcement-learning tasks for coding agents — without needing curated issues, commit histories, or human-written tests. The pipeline auto-derives tasks and hidden verifiers directly from the code itself and trains agents that improve on issue-repair and program-construction benchmarks. The result is a scalable path to verifiable coding environments where reward signals come from the code's own behaviour rather than from surrogate labels.
**Theme:** Spec-driven development & formal verification for coding agents.
**Relevance note:** Directly attacks the "how do we define correctness for coding-agent outputs" problem by grounding rewards in executable specs extracted from real code.
**Link:** https://arxiv.org/abs/2609.22068

## 2. An Empirical Study of Harness Design for Coding Agents
**Authors:** Run-Ze Fan, Zihao Zhang, Simin Ma et al.
**Summary:** This study systematically varies the harness around coding agents — retrieval, planning scaffolds, tool budget, self-check loops — and measures how each component's contribution shifts with model capability, task type, and context budget. The authors show there is no universally optimal harness: cheap models benefit from heavier scaffolding while frontier models are hurt by it, and correctness-checking components dominate on repair tasks. The paper offers a decision matrix for picking harness components per task/model rather than defaulting to one recipe.
**Theme:** Spec-driven development & formal verification for coding agents.
**Relevance note:** Empirical evidence on which harness pieces (spec-checks, self-verifiers) actually move the needle on coding correctness.
**Link:** https://arxiv.org/abs/2609.20804

## 3. RecreationWorld: Scalable and Verifiable Environments for Hybrid Computer-Use Agents
**Authors:** Shuai Bai, Jiayong Deng, Yikun Fu et al.
**Summary:** RecreationWorld converts running applications into scalable training environments with hidden, programmatically-checkable tests that jointly probe GUI exploration, coding, and self-verification. Alongside the environment generator, the authors release RecreationBench — 250 tasks across five platforms with both programmatic assertions and visual assertions — for evaluating hybrid computer-use agents end-to-end. The framework treats agent trajectories as objects that must satisfy an explicit spec, closing the loop between training and correctness measurement.
**Theme:** Multi-agent frameworks & orchestration (agentic evaluation).
**Relevance note:** Verifiable-environment framing bridges themes 2 and 3 — spec-driven checks used to evaluate agent orchestration on real apps.
**Link:** https://arxiv.org/abs/2609.22000

## 4. SoL-Pi: Recursively Scaling Auto-Research Loops for Efficient Agent Harness
**Authors:** Haozhe Liu, Tian Ye, Song Han
**Summary:** SoL-Pi runs an agentic loop that itself researches and edits the harness controlling a downstream coding/agent workflow, recursively hunting for token-and-cost reductions that preserve task success. The authors show the same discovered harness modifications transfer across underlying models and tasks, suggesting harness search is a first-class optimization surface. The framework produces measurable API-cost reductions on standard agent benchmarks without accuracy loss.
**Theme:** Multi-agent frameworks & orchestration.
**Relevance note:** A concrete recipe for agent-architected agent orchestration — agents optimizing their own coordination layer.
**Link:** https://arxiv.org/abs/2609.20519

## 5. GraphSkillEvo: Evolutionary Optimization of Graph-Structured Agent Skills
**Authors:** Rui Sun, Zhi Zheng, Zhenkun Wang et al.
**Summary:** GraphSkillEvo represents an agent's reusable skills as directed graphs whose nodes are sub-procedures and edges encode tool/role hand-offs, then applies mutation and crossover operators to evolve better skill graphs against a task fitness signal. Because the representation is explicit, evolved skills transfer across underlying language models without retraining. The method beats flat prompt-library baselines across several agent benchmarks.
**Theme:** Multi-agent frameworks & orchestration.
**Relevance note:** A principled representation for role/tool assignment and skill reuse across agents — directly on-theme for orchestration research.
**Link:** https://arxiv.org/abs/2609.21749

## 6. MintAct: A Unified Visual Agent for Digital Environments
**Authors:** Mingfei Gao, Rui Tian, Haiming Gang et al.
**Summary:** MintAct is a single vision-language policy that unifies UI grounding and multi-step navigation across mobile, desktop, and web through shared environment infrastructure and asynchronous RL training. Training scales via a common action interface, and the resulting agent reaches state-of-the-art on cross-platform GUI benchmarks. The paper argues that a single unified controller outperforms per-platform specialists once training infra is shared.
**Theme:** Multi-agent frameworks & orchestration (agent architectures).
**Relevance note:** Concrete architecture answer to "one generalist controller vs. per-role specialists" for tool-using agents.
**Link:** https://arxiv.org/abs/2609.22083

## 7. RetireOPD: Self-Retiring On-Policy Distillation for Agentic Reinforcement Learning
**Authors:** Yan Yu, Zhengxi Lu, Yongliang Shen et al.
**Summary:** RetireOPD trains agentic RL policies by starting with on-policy distillation from a stronger teacher, then adaptively "retiring" the teacher on trajectories where the student has caught up, so reward-driven exploration can proceed unconstrained. The retirement criterion is per-trajectory, letting different rollout branches escape the teacher at different times. Empirically the method beats fixed-mix distillation-plus-RL baselines on multi-step agentic benchmarks.
**Theme:** Core LLM advances (fine-tuning / agentic RL).
**Relevance note:** A specific answer to when teacher-guidance should stop hurting exploration during agent training.
**Link:** https://arxiv.org/abs/2609.20784

## 8. When2Think: Learning Difficulty-Aware Length Control for Efficient Hybrid Reasoning Models
**Authors:** Microsoft Research (author list not fully disclosed in the daily-papers listing)
**Summary:** When2Think trains a reasoning model to predict, per input, how much chain-of-thought to spend, aiming to spend long reasoning only on problems that need it. The controller is learned from labeled difficulty signals and shortens outputs on easy problems while preserving accuracy on hard ones. This yields large token-cost savings on standard reasoning benchmarks without harming pass rates.
**Theme:** Core LLM advances (reasoning, planning).
**Relevance note:** Difficulty-adaptive test-time compute is a first-class primitive for agent planners with a token budget.
**Link:** https://arxiv.org/abs/2609.19671

## 9. Score Centering Stabilizes Off-Policy Reinforcement Learning
**Authors:** Martin Marek, Max Ryabinin
**Summary:** The authors identify that off-policy language-model RL drifts because policy-vs-sampler token-level score mismatches accumulate; subtracting the sampler's expected token scores ("score centering") cancels this drift. The fix is a small algorithmic change with no extra reward model, and it stabilizes training under severe rollout staleness and low-precision quantization. Empirically it recovers on-policy stability while keeping off-policy compute savings.
**Theme:** Core LLM advances (fine-tuning / RL infrastructure).
**Relevance note:** A minimal, plug-in stability fix relevant to any agentic-RL pipeline that trains with delayed rollouts.
**Link:** https://arxiv.org/abs/2609.20807

## 10. What Does Privileged Information Add to On-Policy Self-Distillation?
**Authors:** XiuYu Zhang, Wei Chow, Tat-Seng Chua
**Summary:** Through matched-answer ablations, the authors decompose the gains of on-policy self-distillation into distillation itself vs. exposure to teacher-only "privileged" information, and find distillation supplies most of the improvement while privileged references help only for some model/student pairings. The result challenges the current default of always injecting extra reference material during self-distillation. It suggests cheaper self-distillation recipes when the student is already competent.
**Theme:** Core LLM advances (fine-tuning / distillation).
**Relevance note:** Clarifies which lever actually delivers reasoning gains — informs any PEFT/self-distillation training recipe for agent LLMs.
**Link:** https://arxiv.org/abs/2609.20612
