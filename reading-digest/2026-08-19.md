# Reading digest — 2026-08-19

Found 10 paper(s) in the last 48h window.

## 1. Agent Lightning v1.0: Towards Harnessed Agentic RL
- **Authors:** Zhiyuan He, Siwei Zhang, Zhiwen Zhou, et al.
- **Summary:** Introduces a lightweight training framework that plugs reinforcement learning into arbitrary agent "harnesses" (tool loops, planners, scratchpads) without rewriting them. The authors define a harness-agnostic trajectory API and a credit-assignment scheme that lets RL updates flow through complex tool chains, and report meaningful gains on downstream agent benchmarks with only small amounts of data and compute.
- **Theme:** (1) Core LLM advances + (2) Multi-agent orchestration
- **Relevance note:** Directly targets agentic-system training and harness-level orchestration — a clean fit for both priority themes.
- **Link:** https://arxiv.org/abs/2608.17528

## 2. Agentic ESOpt: Fine-Tuning Long-Horizon LLM Agents with Minimal GPU Requirements
- **Authors:** Zhi Zheng, Rongsheng Chen, Yunpeng Ba, et al.
- **Summary:** Applies evolution-strategy (ES) optimization to full-parameter fine-tuning of LLM agents, sidestepping backprop-through-trajectory memory blowups. The method assigns credit at the trajectory level rather than per-token, enabling long-horizon reasoning fine-tunes on commodity GPUs and showing competitive results against PPO-style pipelines with far less memory.
- **Theme:** (1) Core LLM advances — fine-tuning / PEFT-style compute reduction
- **Relevance note:** Fresh angle on the fine-tuning axis: ES as a memory-efficient alternative for agentic training.
- **Link:** https://arxiv.org/abs/2608.17310

## 3. ClawGym II: Exploring Black-Box RL on Agent Harness
- **Authors:** Huatong Song, Fei Bai, Ming Yang, et al.
- **Summary:** Proposes a black-box RL formulation that treats a full agent harness as an opaque environment, using sandbox execution plus trajectory reconstruction to reconstruct usable rollouts. This lets the framework optimize general-purpose agents (with unknown internal control flow) stably at scale, reporting improvements over prior harness-specific RL setups.
- **Theme:** (1) Core LLM + (2) Multi-agent orchestration
- **Relevance note:** Complements Agent Lightning; useful contrast on the "how do we train complex agent stacks" question.
- **Link:** https://arxiv.org/abs/2608.16798

## 4. StartupBench: Benchmarking General-Purpose Agents on Market-Validated End-to-End Workflows
- **Authors:** Liya Zhu, Xin Ma, Tao Liu, et al.
- **Summary:** Builds an agent benchmark from real, revenue-producing AI-startup workflows rather than synthetic tasks, covering multi-step tool use, spec-following, and domain judgment. Frontier agents finish only ~30% of tasks end-to-end, with the failure modes concentrated in instruction adherence and domain expertise rather than raw reasoning.
- **Theme:** (1) Core LLM — agentic-system evaluation
- **Relevance note:** One of the more realistic recent agent evals; grounds "how good are agents really" in production-like tasks.
- **Link:** https://arxiv.org/abs/2608.17800

## 5. HarnessRisk: A Lifecycle-Oriented Benchmark for Agent Harness Safety
- **Authors:** Yajing Bai, Jinhao Duan, Jie Peng, et al.
- **Summary:** Introduces a benchmark that organizes agent-harness safety failures across six operational phases (config, planning, tool call, memory, execution, cleanup). Empirically, the paper finds harness *configuration* — not model reasoning — is the dominant attack surface, arguing that safety evaluation must be structured over the harness lifecycle rather than the model in isolation.
- **Theme:** (1) Core LLM — agentic-system evaluation (safety)
- **Relevance note:** Reframes agent safety as a harness-engineering problem; useful mental model for spec-driven agent design.
- **Link:** https://arxiv.org/abs/2608.17597

## 6. HarnessEval-W: Agentifying the Evaluation of Visual Worlds
- **Authors:** Weiliang Chen, Haowen Sun, Jun Gao, et al.
- **Summary:** Decomposes world-model evaluation into a hierarchy of specialized sub-agents that each score a specific facet (physics, semantics, temporal consistency) and produce a verifiable chain-of-reasoning attached to the score. The multi-agent evaluator produces more transparent, auditable judgments than monolithic LLM-as-judge setups.
- **Theme:** (2) Multi-agent frameworks & orchestration
- **Relevance note:** Concrete role/tool-assignment example; the evidence-linked scoring pattern generalizes beyond video.
- **Link:** https://arxiv.org/abs/2608.16859

## 7. ASI-Bench: At the Dawn of Artificial Superintelligence
- **Authors:** Junwei Zhou, Zhen Sun, Binyu Li, et al.
- **Summary:** Proposes a benchmark of 60 project-level tasks across 11 scientific domains, structured to progressively strip away human guidance so evaluators can measure where autonomous execution starts to break. Includes end-to-end scoring for planning, experimentation, and iteration rather than isolated question answering.
- **Theme:** (1) Core LLM — agentic-system evaluation
- **Relevance note:** Complements StartupBench with a scientific-execution axis; useful for tracking long-horizon planning progress.
- **Link:** https://arxiv.org/abs/2608.17271

## 8. Learn What's Left, Not What's Mastered: Saturation-Aware Advantage Reweighting for Multi-Reward Policy Optimization
- **Authors:** Yixuan Wang, Yifei Chen, Haichao Zhang, et al.
- **Summary:** Presents SA-MRPO, which independently standardizes each reward stream and adaptively down-weights the advantage of objectives that have already saturated, so training compute is redirected to under-optimized rewards. On multi-objective RLHF-style setups it converges to better Pareto frontiers than uniform reward mixing.
- **Theme:** (1) Core LLM — post-training / fine-tuning
- **Relevance note:** Practical trick for multi-reward alignment; relevant to any agent trained against multiple graded objectives.
- **Link:** https://arxiv.org/abs/2608.16072

## 9. GenRouter: Unified Workflow Routing for Agentic Image Generation
- **Authors:** Harold Haodong Chen, Zhiyu Hou, Wen-Jie Shu, et al.
- **Summary:** Frames image generation as a workflow-routing problem: a router agent inspects the prompt and dispatches it to the best of many specialized generation pipelines (edit, compose, restyle, etc.) rather than always invoking the heaviest one. Reports lower cost and latency at equal or better alignment vs. single-pipeline baselines.
- **Theme:** (2) Multi-agent orchestration
- **Relevance note:** Clean orchestration pattern — router + specialist pool — that transfers to non-image agent stacks.
- **Link:** https://arxiv.org/abs/2608.16721

## 10. From Sequence to Structure: Relational Uncertainty Propagation for LLM Agents
- **Authors:** Zhengzhao Ma, Boxi Cao, Yaojie Lu, et al.
- **Summary:** Models an agent trajectory as a dependency graph over steps and propagates uncertainty along that graph, giving trajectory-level (rather than step-local) confidence estimates. Empirically this catches long-horizon failure cascades that per-step uncertainty misses, and enables earlier abort/replan.
- **Theme:** (1) Core LLM — agentic reasoning / evaluation
- **Relevance note:** Bridge toward spec-checking of agent outputs: structural uncertainty is a prerequisite for meaningful correctness signals.
- **Link:** https://arxiv.org/abs/2608.16002
