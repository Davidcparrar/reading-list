## 1. Dream-RSI: Recursive Self-Improvement through Evolving Worlds
- **Authors:** Tong Zheng, Xidong Wu, Zheng Zhang et al.
- **Summary:** Proposes a scalable recursive self-improvement framework in which an autonomous agent treats its accumulated discovery history as a replay simulator, so candidate policy updates can be evaluated offline against realized search trajectories instead of paying the cost of fresh online rollouts. The method is instantiated on algorithm engineering, mathematical optimization, and GPU kernel authoring, and matches or beats online-evaluation baselines on discovery quality at much lower compute per improvement step.
- **Theme:** Core LLM advances (planning, agentic self-improvement).
- **Relevance:** Direct hit on planning and agent-system training loops; offline policy evaluation over discovery history is a cleanly novel mechanism, and the empirical spread across three concrete engineering domains is unusually strong for an RSI paper.
- **Link:** https://arxiv.org/abs/2609.14858

## 2. RSIAgent: Autonomous Exploration for Recursive Self-improvement in New Environments
- **Authors:** Sibo Zhu, Shicheng Fan, Xinyue Wang et al.
- **Summary:** Introduces a training-free multi-agent architecture that adapts to unfamiliar software environments by first exploring broadly, then drilling into locally consistent regions, and writing what it learns into a shared memory that later agents reuse. Because there is no parameter update, the same open-source base model is coordinated into behavior that outperforms frontier closed-source models on several environment-adaptation benchmarks.
- **Theme:** Multi-agent frameworks & orchestration.
- **Relevance:** Squarely on theme 2 — role/tool assignment, coordination via shared memory, and a novel broad-then-deep exploration protocol. Training-free is attractive because the framework can be re-hosted on new base models without a fine-tune.
- **Link:** https://arxiv.org/abs/2609.15364

## 3. Atria Dawn: The Dawn of Agentic Superintelligence
- **Authors:** Honglin Guo, Tao Gui, Yicheng Chen et al.
- **Summary:** Presents a foundation-scale agentic language model trained through a Verifiable Experience Pipeline that grounds tool-use traces in executable environments, so every rollout carries a machine-checkable outcome before it enters the training corpus. Evaluated across 16 agentic benchmarks and a 769-task user study of 56 participants, the model reaches competitive performance and, more interestingly, shifts human–agent interaction toward project-level partnership where the agent proposes methods and the human retains final decisions.
- **Theme:** Core LLM advances (foundation model, agentic-system evaluation).
- **Relevance:** Ties execution-verified data pipelines to agent-system evaluation with human-in-the-loop metrics — one of the more complete efforts this window to characterize where agentic foundation models actually help humans.
- **Link:** https://arxiv.org/abs/2609.15818

## 4. HazardAuditor: From Executable Threats to Safer Computer-Use Agents
- **Authors:** Yunhao Feng, Ruixiao Lin, Ming Wen et al.
- **Summary:** Builds an execution-grounded safety framework for computer-use agents that operate on browsers, terminals, and file systems, and introduces Guard Policy Optimization (GuardPO), a training method that converts binary safety outcomes into sequence-level advantages used to shape generative guard models. Across several safety benchmarks the resulting guards improve detection accuracy by up to 16.5 percentage points over prior guard baselines.
- **Theme:** Core LLM advances (agentic-system evaluation, safety fine-tuning).
- **Relevance:** Combines two of the sub-topics under theme 1 — agent evaluation and RL-style fine-tuning of a policy — in a way that is directly usable when you need to audit an agent before it touches a real filesystem.
- **Link:** https://arxiv.org/abs/2609.15134

## 5. Discovery Foundation Models: Toward Open-Ended Discovery Intelligence
- **Authors:** Ling Yang, Zhenfei Yin, Yingcheng Wu
- **Summary:** Argues for treating open-ended discovery as a system built on top of foundation models, and instantiates that system as GALILEO / Zetema, a closed loop where a dry-lab reasoning agent proposes hypotheses and interventions and a wet-lab-style component gathers evidence that revises the next round. The framework is described in enough detail to be reproducible on new domains, and the paper positions it as a route toward agents that can revise their own research questions.
- **Theme:** Multi-agent frameworks & orchestration.
- **Relevance:** Fits theme 2 as an orchestration framework — dry-lab and wet-lab roles, an evidence-grounded revision loop, and an explicit division of labor between the reasoning agent and the experimenting agent. Useful reference for building similar closed-loop research agents.
- **Link:** https://arxiv.org/abs/2609.15973

## 6. Omni-Streaming Thinking
- **Authors:** Enjun Du, Siyi Liu, Ziyu Zheng et al.
- **Summary:** Attacks a specific failure mode of streaming multimodal reasoning: models commit to cross-modal claims before the incoming stream has enough evidence to support them. The proposed decoder emits structured outputs that separate confirmed evidence, forecasts, and pending claims that are explicitly linked to future verification intervals, and this defers-until-verified regime raises the discrimination score (d′) from 1.38 to 2.95 against strong baselines.
- **Theme:** Core LLM advances (reasoning).
- **Relevance:** The premature-commitment failure mode is well characterized, and the structured "pending claim → verification window" output format is a portable idea for any streaming reasoning agent, not just multimodal ones.
- **Link:** https://arxiv.org/abs/2609.15128

## 7. When Agents Slow Down: Understanding LLM Agents' Test-Time Strategies via Elo-per-token Analysis
- **Authors:** Kaiyuan Liu, Qiuyang Mang, Bo Peng et al.
- **Summary:** Reframes test-time compute allocation as an Elo-per-token measurement problem, tracking how quality-per-token evolves as an agent revises solutions, uses tools, and decides when to stop. The main empirical finding is that agents beat random sampling early but hit diminishing returns and eventually underperform, so the paper recommends splitting a fixed token budget into parallel shorter sessions — on FrontierCS Polyomino Packing this parallel split gains +264 Elo over one long session at the same 100M-token budget.
- **Theme:** Core LLM advances (agentic-system evaluation).
- **Relevance:** Practical planning guidance for anyone tuning test-time compute for coding or reasoning agents; the Elo-per-token curve is a genuinely new evaluation lens.
- **Link:** https://arxiv.org/abs/2609.15309

## 8. BVB: Benchmarking Agentic Video Understanding via Programmatic Reconstruction in Blender
- **Authors:** Yolo Y. Tang, Daiki Shimada, Jiayue Meng et al.
- **Summary:** Constructs a benchmark that asks an agent to reconstruct a real-world video as an animated Blender scene, then scores both perceptual similarity of the reconstruction and how many spatiotemporal facts about the source clip the reconstruction actually preserves. Even the best evaluated agent reaches high visual similarity but retains only 53.7% of source-correct answers, exposing that perceptual quality and factual grounding come apart under this protocol.
- **Theme:** Core LLM advances (agentic-system evaluation).
- **Relevance:** A rare agentic-evaluation benchmark that decouples surface-level plausibility from grounded correctness — a useful design pattern for evaluating any generative agent whose output can look right while being factually wrong.
- **Link:** https://arxiv.org/abs/2609.15478
