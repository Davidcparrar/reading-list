## 1. Beyond Final Scores: A Systematic Evaluation of Agents for Long-Horizon AI Research and Development
- **Authors:** Yiwei Li, Wanli Yang, Hexiang Tan, et al.
- **Summary:** The paper stress-tests seven frontier LLM agents across 36 long-horizon AI R&D tasks and instruments each run beyond a final score — logging plan/act traces, artifact quality, and run-to-run variance. The finding is that current agents behave more like engineering optimizers than researchers: they reliably tune known techniques and can match human baselines on execution, but genuine methodological novelty appears in only ~1% of trajectories and the same agent produces widely different solutions across seeds. It reframes "agent capability" as a distribution rather than a point estimate and pinpoints where evaluation currently overclaims.
- **Theme:** Core LLM advances (agentic-system evaluation)
- **Relevance:** One of the more grounded critiques of headline agent benchmarks — directly on-theme for how to measure agent capability past pass@1.
- **Link:** https://arxiv.org/abs/2608.13417

## 2. Second Thought: Reasoning in Parallel as LLM Agents Act and Observe
- **Authors:** Zhensu Sun, Chengran Yang, Yunbo Lyu, et al.
- **Summary:** Second Thought is a training-free scaffold that runs an auxiliary reasoning stream while the main agent waits for tool/environment observations, so latent "think time" during I/O becomes useful work rather than idle tokens. When the observation returns, the auxiliary trace is merged back into the primary context, letting the main decode skip re-derivation. Across nine agent–benchmark pairs it cuts main-thread decoding by up to 43% (≈20% on average) with no quality loss, offering a cheap wall-clock win for tool-use agents.
- **Theme:** Multi-agent frameworks & orchestration (parallel act/think loops)
- **Relevance:** A concrete, deployable pattern for agent runtime orchestration — turns dead time in the act/observe loop into speculative reasoning.
- **Link:** https://arxiv.org/abs/2608.13667

## 3. Wyvern: An Agentic Framework for Generating Grounded Multimodal Reports
- **Authors:** Beatrice Alessandra Motetti, Emilien Guandalino, Daniele Jahier Pagliari, et al.
- **Summary:** Wyvern coordinates specialized agents — retriever, drafter, figure/table locator, and a claims auditor — to produce technical reports that interleave text, images, and tables with citations back to the source corpus. A key idea is an auto-revision loop where the auditor flags un-grounded claims and forces the drafter to either cite or drop them before the report is committed. The framework materially improves citation recall and grounding faithfulness over single-agent baselines while keeping report structure coherent.
- **Theme:** Multi-agent frameworks & orchestration
- **Relevance:** Role-differentiated multi-agent pipeline with an explicit grounding-audit loop — a clean datapoint on how verification-in-the-loop reshapes agentic report generation.
- **Link:** https://arxiv.org/abs/2608.14446

## 4. AutoDesign: Meta-Harness Optimization for Long-Horizon Agentic Design
- **Authors:** Yaxin Luo, Haobin Jiang, Jialv Zou, et al.
- **Summary:** AutoDesign treats the *agent harness itself* (tools, roles, communication topology, retry/verify policies) as the optimization target instead of the base model, using a meta-optimizer to search over harness configurations for a fixed LLM. On long-horizon design benchmarks like PosterBench it lifts scores substantially (reported PosterBench 78.32) while showing the same underlying model behaves very differently under different orchestrations. The takeaway is that agentic performance is at least as much a function of harness design as of model choice.
- **Theme:** Multi-agent frameworks & orchestration
- **Relevance:** Rare piece of work that treats orchestration/topology as a first-class hyperparameter and searches over it — sits at the center of the multi-agent-architecture thread.
- **Link:** https://arxiv.org/abs/2608.13560

## 5. SimpleOPD: Simple Tokenizer-Agnostic On-Policy Distillation for Long-Context Reasoning
- **Authors:** Haonan He, Haodi Lei, Yun Luo, et al.
- **Summary:** SimpleOPD distills proof-style reasoning traces from a long-context teacher into a short-context student without requiring shared tokenizers, using an on-policy distillation loop that matches the student's own rollouts against teacher-generated traces. Applied to Intern-S2-Preview, it lifts ProofBench by 21.2 points to 55.2, surpassing Gemini-2.5-Pro on that benchmark. The tokenizer-agnostic recipe removes a common friction point that has blocked cross-family distillation for reasoning.
- **Theme:** Core LLM advances (reasoning, distillation)
- **Relevance:** Practical distillation recipe that clears the tokenizer-mismatch barrier and produces measurable reasoning gains — high signal for reasoning-training work.
- **Link:** https://arxiv.org/abs/2608.14277

## 6. Claim-Level Reliability Assessment for Efficient Test-Time Reasoning
- **Authors:** Sen Xu, Wei Wang, Shixi Liu, et al.
- **Summary:** CLR reallocates test-time compute from broad self-consistency sampling to targeted per-claim verification: the model emits candidate reasoning steps, a light verifier scores individual claims, and only weak ones trigger extra work. On GPT-OSS-20B and the CMIMC25 benchmark it exceeds pass@1 by 27.15 pp while using 37% fewer tokens than standard best-of-N. The framing recasts inference-time scaling as an allocation problem rather than a sampling problem.
- **Theme:** Core LLM advances (reasoning, inference-time compute)
- **Relevance:** Concrete alternative to expensive best-of-N — clean quality/cost frontier improvements for reasoning workloads.
- **Link:** https://arxiv.org/abs/2608.11994

## 7. Twin: Playing an Unknown Game with a Test-Time Digital Twin
- **Authors:** Alexy Skoutnev, Kirill Acharya, Gaston Longhitano, et al.
- **Summary:** Twin has a coding agent write an *executable* world model of the environment it is placed in, then uses that model as a test-time digital twin: predictions are validated against observed transitions, mismatches become counterexamples that drive code repair, and only validated models are used for planning. On ARC-AGI it clears 179/183 levels (97.8%), the strongest reported number to date, by turning environment inference into a code-synthesis-plus-verification loop. It is one of the cleanest current examples of using code generation as the substrate for continual, verifiable agent behavior.
- **Theme:** Spec-driven / formal verification for coding
- **Relevance:** Agent architecture where correctness is checked against a synthesized executable spec and repaired via counterexamples — a direct instance of formal-verification-style loops for coding agents.
- **Link:** https://arxiv.org/abs/2608.14490

## 8. Submodular Policy Learning for Distributed Task Allocation
- **Authors:** Jing Liu, Luca Ballotta, Yangyang Yang, et al.
- **Summary:** SubMAPL is a policy-gradient method for *open* multi-agent systems where agents can arrive or depart during execution, framing distributed task allocation through a partition multilinear extension so the objective stays differentiable under changing team size. A KL-mirror update keeps policies stable across membership changes, and the method retains performance guarantees on submodular allocation problems where classical fixed-team methods degrade. The result is a principled coordination policy that survives churn — relevant for real multi-agent deployments where the roster is not static.
- **Theme:** Multi-agent frameworks & orchestration (coordination under open membership)
- **Relevance:** Rare formal treatment of *open* multi-agent coordination with departures/arrivals, filling a gap most current agent frameworks assume away.
- **Link:** https://arxiv.org/abs/2608.14390

## 9. Rewrite Once, Validate Anywhere: Producing OWL-Aware SHACL Constraints
- **Authors:** Anouk Oudshoorn, Piotr Gorczyca, Dörthe Arndt
- **Summary:** The paper compiles OWL EL⁻ ontology axioms into SHACL constraint shapes so that any standard SHACL validator can enforce them without a separate reasoning stage at validation time. This decouples spec authoring (in OWL, expressive) from spec enforcement (in SHACL, deployable everywhere), yielding an "author once, validate anywhere" pipeline for data-integrity contracts. Practically, it lets teams treat semantic constraints as build-time artifacts checkable in the same tooling as code linters.
- **Theme:** Spec-driven development / formal verification
- **Relevance:** The clearest spec-driven / formal-methods paper in the window — turns declarative specs into portable, verifier-agnostic constraints, a pattern directly transferable to correctness contracts for agent outputs.
- **Link:** https://arxiv.org/abs/2608.14104

## 10. Approximate Muon with Low-Rank Adapters
- **Authors:** Ben Anson, Conor Houghton, Edward Milsom
- **Summary:** sMuon approximates the Muon optimizer's spectral-normalization step inside a low-rank (LoRA-style) parameterization by linearizing the objective and solving a small least-squares problem per step, so the whole update stays inside cheap matmul kernels. This bridges a widening gap between second-order-flavored optimizers and PEFT — the two currently live in separate stacks — and preserves most of Muon's optimization behavior while keeping the LoRA memory/compute profile. The recipe is a practical PEFT ingredient for training-time efficiency work.
- **Theme:** Core LLM advances (fine-tuning / PEFT)
- **Relevance:** Concrete integration of a modern optimizer family with parameter-efficient fine-tuning — a useful new tool in the PEFT toolkit.
- **Link:** https://arxiv.org/abs/2608.14492
