## 1. HERMES: Harness Engineering for Software Engineering via Modular Executable Dev-Primitives
- Authors: (HuggingFace daily papers listing, authors not fully extractable from feed)
- Summary: Introduces Dev-Primitives, which attach a resident LLM to each repository component (module, directory, service) so an agentic SE harness can route work through those local experts instead of a single monolithic agent. The HERMES framework composes these primitives and reports a 12.4% average gain over matched baseline harnesses with a 26.2% inference-cost reduction on Terminal-Bench 4.0. The design turns code structure into orchestration structure, which is directly relevant to multi-agent coding systems.
- Theme: Multi-agent frameworks & orchestration (coding focus)
- Relevance: Concrete, measurable multi-agent orchestration pattern for software engineering — exactly the intersection of themes (1) and (2) with a coding payoff.
- Link: https://arxiv.org/abs/2610.07832

## 2. DAEDALUS: Bootstrapping Agent Memory from Self-Generated Tasks
- Authors: (listed in HuggingFace daily papers)
- Summary: An explorer agent proposes solvable tasks while a solver agent attempts them, and the solver's failure traces are mined for reusable heuristics that are vetted and stored in a persistent memory bank for test time. The authors report mean success-rate gains of up to 15.9 points across AppWorld, τ²-bench, and AutomationBench, suggesting that self-generated curricula plus failure-derived heuristics are a reliable way to grow agent memory without external supervision.
- Theme: Multi-agent frameworks & orchestration (also agentic-system memory)
- Relevance: Two-agent co-training with a durable heuristic memory — a canonical multi-agent memory architecture.
- Link: https://arxiv.org/abs/2610.08048

## 3. SkillForge: Co-Evolving Skills and Agents via Dynamic Skill Lifecycles
- Authors: Yuyao Ge, Yiwei Wang, Yuchen He, et al.
- Summary: SkillForge treats an agent's skill library as a living population with lifecycle states (trial, active, stable, retired), driving selection and mutation by fitness during RL. It pre-filters skills before SFT, retires stale ones, and uses an LLM to propose mutations, reporting up to 7.8% relative gain over the strongest baseline with a compact library while releasing the accompanying SkillFurnace dataset.
- Theme: Multi-agent frameworks & orchestration (skill coordination)
- Relevance: Explicit lifecycle protocol over an agent-shared skill bank — orchestration of competencies rather than agents themselves.
- Link: https://arxiv.org/abs/2610.09832

## 4. SafeActBench: From Evidence to Action — How Tool-Using Agents Fail
- Authors: (HuggingFace daily papers listing)
- Summary: Introduces SafeActBench (656 cases across six domains) together with an "Evidence Ledger" — a deterministic trajectory evaluator that checks whether each agent action was preceded by the evidence it required. The analysis finds that tool-using agents routinely act before prerequisites are established and that multi-action workflows amplify these omissions, pointing to concrete places where spec-driven preconditions could prevent failures.
- Theme: Spec-driven development & formal verification (plus agentic evaluation)
- Relevance: A deterministic, specification-style trajectory checker is a direct instance of applying formal correctness ideas to coding/tool-using agents.
- Link: https://arxiv.org/abs/2610.07753

## 5. RunningTab: Direct Workspace Interaction with Environment-Side Tabs
- Authors: Jinheon Baek, Soyeong Jeong, Yumin Choi, et al.
- Summary: RunningTab adds an environment-maintained task record that tracks requirements, excerpts of files already read, and candidate files not yet opened, so the agent cannot silently forget what the user asked for. The structure doubles as a shared coordination surface for multi-step work, and the paper argues this environment-side state is more reliable than putting the same information in the agent's own context window.
- Theme: Multi-agent frameworks & orchestration (workspace coordination)
- Relevance: Externalizes the "working memory" that normally gets lost between agent steps — an orchestration primitive useful across multi-agent setups.
- Link: https://arxiv.org/abs/2610.10444

## 6. We Query, Therefore We Compute: Oracle Computation Beyond the Machine, with an Application to Agents
- Authors: (HuggingFace daily papers listing)
- Summary: Models the LLM as an Oracle inside a two-stack pushdown automaton, giving a single formal machine that subsumes both Workflows and Agents, and then uses that abstraction to reason about caching and scheduling. The authors also sketch ArchNights, a RISC-V/Linux-style OS design for agentic systems implemented on gem5, so the formal model has an executable counterpart.
- Theme: Spec-driven development & formal verification (formal methods for agents)
- Relevance: A formal computational model for agent orchestration — the kind of abstraction spec-driven approaches need.
- Link: https://arxiv.org/abs/2610.09243

## 7. SWE-Game: Can Coding Agents Build the Games We Want?
- Authors: Yuhua Wen, Linghe Kong, Weiran Huang, et al. (tail of a longer author list)
- Summary: SWE-Game is a benchmark of 247 tasks built on 41 executable Godot games, covering five task types from brief-to-game creation to Godot-to-Unity porting, and it evaluates agents with engine-state checks, reference-input replay, and vision-language rubrics. Across six models, best scores remain below 60/100 on construction tasks, and the authors trace failures to requirement omissions and gameplay-logic errors — i.e., exactly the specification-adherence problems that drive interest in spec-driven coding agents.
- Theme: Spec-driven development & formal verification (coding correctness benchmark)
- Relevance: A multi-signal correctness benchmark that targets how well agents follow a spec in a non-trivial coding domain.
- Link: https://arxiv.org/abs/2609.33678

## 8. Mechanics of Long-Context Hybrid Models (Part 1.1): From Hybrid Attention to Hybrid Position
- Authors: Xiaoran Liu, Ziwei He, Xipeng Qiu
- Summary: Analyzes hybrid architectures that interleave full attention with sliding-window or linear attention, explaining the length-extrapolation and context-extension behavior each hybrid admits, and proposes Sliding-Window Linear Attention as a concrete recipe. The paper reads as a mechanistic account of why today's long-context hybrids succeed or fail, which is useful for anyone picking a backbone for reasoning or planning agents.
- Theme: Core LLM advances (reasoning / long-context mechanics)
- Relevance: Clean mechanistic analysis plus a new mixing recipe — directly actionable for choosing/building reasoning backbones.
- Link: https://arxiv.org/abs/2610.10114

## 9. On KL-Regularized Policy Optimization (KLPO) for Asynchronous LLM Post-Training
- Authors: Yifan Zhang
- Summary: Proposes a critic-free RL method aimed at asynchronous LLM post-training where rollouts come from stale sampler checkpoints, anchoring the KL regularizer at the sampler to avoid importance weighting and multiple-response-per-prompt requirements. The paper also shows that SPPO, GPO, REBEL, and BPO are special cases of this single framework, offering a unifying lens on recent policy-optimization variants.
- Theme: Core LLM advances (fine-tuning / RL post-training)
- Relevance: A unifying, implementation-friendly RL recipe for async pipelines — useful whenever an agent system is RL-fine-tuned off-policy.
- Link: https://arxiv.org/abs/2610.08963

## 10. Rethinking Cross-Tokenizer On-Policy Distillation: From Alignment Coverage to Supervision Reliability
- Authors: (HuggingFace daily papers listing)
- Summary: Investigates on-policy distillation between teacher and student models that use different tokenizers for math reasoning and code generation, and finds that a narrower set of reliably aligned positions can outperform broader alignment coverage because the latter admits conflicting training signals. The result reframes cross-tokenizer distillation around supervision quality instead of coverage, which matters for mixing frontier teachers with smaller agent-friendly students.
- Theme: Core LLM advances (fine-tuning / PEFT-adjacent)
- Relevance: Concrete finding about supervision reliability in cross-tokenizer setups — directly relevant to distilling reasoning/code capabilities into deployable agent models.
- Link: https://arxiv.org/abs/2610.08448
