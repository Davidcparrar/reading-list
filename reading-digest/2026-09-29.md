## 1. Self-Evolving Coding Agents: From Digital Programs to Physical-World Intelligence

- **Authors:** Hongcheng Gao, Jingjing Zhou, Zelin Zheng, et al.
- **Summary:** The paper proposes "Physical Coding" — a paradigm where a coding agent expresses robot task state and execution plans as code that is then verified before execution. The system orchestrates perception, planning, and control tools while evolving via traced experience, moving beyond one-shot code generation to a self-improving loop that couples plans with executable checks.
- **Theme:** Multi-agent frameworks & orchestration + Spec-driven development / verification for coding
- **Relevance:** Rare paper this window that bridges agentic-coding architectures with explicit planning-and-verification loops — directly on theme 3, plus theme 2.
- **Link:** https://arxiv.org/abs/2609.35432

## 2. CompoWorld: Compositional Environment Scaling for General Agents

- **Authors:** Xiao-Wen Yang, Weiyi Xu, Wen Da, et al.
- **Summary:** Introduces a compositional environment-synthesis approach that stitches reusable services with verified state contracts and shared interfaces, yielding 448 services and 10,130 tools. Training and evaluating agents against this synthesized environment lifts Qwen3.6-35B by 9.17 points on AutomationBench and reportedly surpasses Claude Opus in that setting.
- **Theme:** Multi-agent frameworks & orchestration
- **Relevance:** Concrete, verifiable interface contracts as a scaling axis for agent training — directly relevant to role/tool assignment and orchestration protocols.
- **Link:** https://arxiv.org/abs/2609.33665

## 3. Skill2Env: Capability-Oriented Environment Synthesis from Skills for General Agents

- **Authors:** Weiyi Xu, Xiaowen Yang, Wen Da, et al.
- **Summary:** Rather than hand-crafting agent training tasks, Skill2Env starts from reusable skills and derives environments whose capability demands match target difficulty patterns. An "Iterative Task Hardening" loop rejects insufficiently challenging blueprints and revises them, producing ~1.5K high-scoring trajectories that lift performance across several agent benchmarks.
- **Theme:** Multi-agent frameworks & orchestration (agent training environments)
- **Relevance:** Complements CompoWorld with a skill-first synthesis pipeline — useful reference for capability coverage in agent-eval design.
- **Link:** https://arxiv.org/abs/2609.33772

## 4. TraceDance: An Automated System for Building Agent Behavior Benchmarks from Real-World Agent Deployment Traces

- **Authors:** Dehai Min, Daoan Zhang, Yiming Zeng, et al.
- **Summary:** TraceDance mines production agent traces via an "Anchor-and-Confirm" retrieval pass combined with LLM confirmation and behavior-specific rubrics, turning them into targeted decision-point benchmarks. Nine frontier LLMs average only a 26.7% pass rate on the resulting evaluations, exposing large gaps in agent decision quality that standard end-task metrics hide.
- **Theme:** Agentic-system evaluation (core LLM + multi-agent)
- **Relevance:** Directly answers "how do we measure correctness of agent behavior on real workloads" — high-signal for anyone building agent evals.
- **Link:** https://arxiv.org/abs/2609.33295

## 5. Improving Test-Time Scaling with Adaptive Looped Transformers

- **Authors:** Yichen You, Tianyu Fu, Aosong Feng, et al.
- **Summary:** Proposes TaH2, which selectively re-applies transformer iterations only on tokens that benefit from extra compute rather than uniformly deepening the whole rollout. On AIME the accuracy-vs-compute slope improves by 53% over uniform test-time scaling baselines, and gains keep rising up to depth 8 where prior methods plateau.
- **Theme:** Core LLM advances (reasoning, test-time compute)
- **Relevance:** A concrete, scalable knob for reasoning-time compute allocation — likely to influence how planning/CoT budgets are structured in agents.
- **Link:** https://arxiv.org/abs/2609.35748

## 6. Knowing When Thinking Is Not Enough: Teaching Small Reasoning Models to Reason Beyond Their Parametric Knowledge (FlyBy)

- **Authors:** Chanuk Lee, Minki Kang, Sangwoo Park, et al.
- **Summary:** FlyBy trains a small model to distinguish "I lack the reasoning steps" from "I lack the knowledge," and to selectively query a stronger model only for the latter. The routing policy hits 45.96% pass@8 on hard reasoning problems at roughly 2.7x lower serving cost than a monolithic Qwen3-14B baseline.
- **Theme:** Core LLM advances (reasoning, cost-aware routing)
- **Relevance:** A clean small-model + big-model orchestration pattern that maps naturally onto agent tool-routing — cheap to deploy in real stacks.
- **Link:** https://arxiv.org/abs/2609.34327

## 7. Surprising Success, Repeated Failure: Entropy-Guided Credit Assignment for Exploration in LLM Reasoning (EAPO)

- **Authors:** Woongyeong Yeo, Minki Kang, Chanuk Lee, et al.
- **Summary:** EAPO treats successful and failed reasoning trajectories asymmetrically under RL: high-entropy decisions in successful rollouts get amplified positive credit, while low-entropy decisions on failed rollouts get sharper penalties. The result is more exploratory reasoning behavior and consistent gains across multi-step benchmarks over uniform-credit RL baselines.
- **Theme:** Core LLM advances (RL / reasoning)
- **Relevance:** Practical, drop-in credit-assignment refinement for agents trained with RL on tool-calling or CoT trajectories.
- **Link:** https://arxiv.org/abs/2609.33781

## 8. Beyond Teacher Assignment: Domain-Normalized Multi-Teacher On-Policy Distillation

- **Authors:** Xin Li, Hao Jiang, Xin Gao, et al.
- **Summary:** For multi-teacher on-policy distillation (a math specialist, a code specialist, an instruction-following specialist, etc.), the paper rescales each teacher's feedback by its measured spread on the student's own rollouts. The domain-normalized weighting reliably beats fixed-weight and simple router baselines on cross-domain benchmarks.
- **Theme:** Core LLM advances (fine-tuning / distillation)
- **Relevance:** Directly relevant to PEFT / distillation stacks where a small deployed model needs balanced capability across coding, math, and instructions.
- **Link:** https://arxiv.org/abs/2609.35347

## 9. Learning Native Reflection in Unified Models with Interleaved Reinforcement Learning

- **Authors:** Yijia Fan, Ziqi Huang, Zhongang Cai, et al.
- **Summary:** Applies interleaved RL to reflection trajectories in a unified multimodal model so that "credit flows across rounds and to both roles of the same model" — i.e., generator and self-critic share reward across rounds of self-repair. Yields +12.05 GenEval points and transfers to several image-generation benchmarks.
- **Theme:** Core LLM advances (self-reflection / RL)
- **Relevance:** Self-critique loops with joint credit assignment are directly applicable to reasoning-agent self-verification, even outside multimodal settings.
- **Link:** https://arxiv.org/abs/2609.35767

## 10. Learning to Learn from Context: Synthetic Training from Perturbed Public Documents

- **Authors:** Haoyi Wu, Yang Xiao, Yusong Sun, et al.
- **Summary:** Builds a training pipeline that perturbs public documents and synthesizes context-dependent QA/reasoning items which genuinely require reading the (perturbed) document to answer correctly. Applied to Qwen3.6-35B, in-context reasoning on CL-bench climbs from 13.7% to 24.6% without any human annotation.
- **Theme:** Core LLM advances (fine-tuning, in-context reasoning)
- **Relevance:** Cheap, scalable data recipe for teaching agents to actually use retrieved context rather than parametric memory — foundational for retrieval-heavy agent stacks.
- **Link:** https://arxiv.org/abs/2609.33642
