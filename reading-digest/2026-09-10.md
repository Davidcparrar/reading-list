## 1. NeoHorse-1: Towards Recursive Self-Improvement via Agentic Post-Training with Routing Harness
- **Authors:** NeoHorse Team, Guoliang Cao, Guohao Dai, et al.
- **Summary:** Introduces an agent-native model family that treats a router over a heterogeneous pool of specialists as the harness, then reuses its live routing traces to bootstrap supervised fine-tuning and on-policy distillation in a three-stage curriculum. User interactions are structurally validated and semantically scored into training examples, closing a recursive self-improvement loop that lifts eleven-benchmark averages from 58.94 → 64.87 at 4B and 65.60 → 69.04 at 9B.
- **Theme:** (2) Multi-agent orchestration + (1) Fine-tuning
- **Relevance:** Directly couples routing/orchestration signals to post-training data curation — a rare end-to-end recipe for turning a multi-agent harness into training supervision.
- **Link:** https://arxiv.org/abs/2609.08183

## 2. Procedural Graphs: Self-Evolving Execution Structures for LLM Agents
- **Authors:** Google (author list not exposed on HF page)
- **Summary:** Proposes representing an agent's control flow as a procedural graph that the agent itself edits at run time, so the execution structure evolves in response to intermediate results instead of following a fixed plan. The formulation gives a first-class object for coordination, branching and re-planning that can be inspected, cached and reused across tasks.
- **Theme:** (2) Multi-agent frameworks & orchestration
- **Relevance:** A general-purpose orchestration substrate that reifies "how the agent runs" as a mutable artifact — directly on-theme for coordination protocols and role/tool assignment.
- **Link:** https://arxiv.org/abs/2609.09153

## 3. Omni Interaction Agent Technical Report (Gander)
- **Authors:** Orantqing, Shengpeng Ji, Junlong Tong, et al. (Tencent Hunyuan)
- **Summary:** Presents Gander, a streaming multi-modal agent built as a "Cerebellum–Brain" pair: the Cerebellum handles low-latency reactive interaction over video/speech/text chunks while the Brain runs slower reasoning, communicating through a Thinker–Talker token stream. The chunk-level streaming architecture is the paper's core contribution to real-time multi-modal agent coordination.
- **Theme:** (2) Multi-agent frameworks & orchestration
- **Relevance:** Concrete two-agent role split (fast reflex vs. deliberative) with an explicit token-level protocol between them — a clean instance of role/tool assignment done inside a single deployed system.
- **Link:** https://arxiv.org/abs/2609.08977

## 4. Show-Harness: Just a VLM Agent Can Play Robots
- **Authors:** Yanzhe Chen, Zechen Bai, Zhijun Cao, et al. (Show Lab)
- **Summary:** Argues that a single VLM agent, given a small set of discrete semantic actions and per-embodiment execution modules, can drive robot control both zero-shot and after light fine-tuning. The "harness" abstracts embodiment specifics away from the reasoning agent, letting the same VLM reason across robots without retraining the policy.
- **Theme:** (2) Multi-agent orchestration (agent + tool/embodiment adapters)
- **Relevance:** A minimal, reproducible pattern for tool/role assignment between a reasoning agent and executor modules — useful reference for coding-agent tool interfaces.
- **Link:** https://arxiv.org/abs/2609.10522

## 5. Miles v0.1: Production-Level Post-Training
- **Authors:** RadixArk, Tom Chen, Mao Cheng, et al.
- **Summary:** Describes a full-stack post-training system pairing SGLang-based rollout engines with Megatron-LM / FSDP trainers, and supporting LoRA-RL, on-policy distillation and diffusion training in one pipeline. The headline case study runs asynchronous agentic RL on a 744B model at a 263s median step time on 64 GPUs, a data point on what "production" post-training looks like today.
- **Theme:** (1) Core LLM advances — fine-tuning / PEFT infrastructure
- **Relevance:** Rare open technical description of an end-to-end production post-training stack, including LoRA and agentic RL — the plumbing side of the fine-tuning theme.
- **Link:** https://arxiv.org/abs/2609.08368

## 6. Eliciting Weak-to-Strong Generalization with On-Policy Reverse Distillation
- **Authors:** Youngrok Park, Sangmin Bae, Hojung Jung, et al. (KAIST AI)
- **Summary:** Introduces OPRD, which watches how a teacher's policy would shift on the *student's* own rollouts and boosts verifier-supported policy-gradient components along that direction. The construction preserves policy-optimization fixed points while letting the student exceed a weaker teacher, and generalises to successive and multi-teacher distillation.
- **Theme:** (1) Core LLM advances — fine-tuning / distillation
- **Relevance:** A principled recipe for weak-to-strong training that keeps the RL objective well-defined — relevant to any pipeline that fine-tunes strong models with imperfect supervision.
- **Link:** https://arxiv.org/abs/2609.08798

## 7. Φ-Bench: Can Large Language Models Engineer the Infrastructure That Powers Them?
- **Authors:** Leilei Ding, Shumin Wang, Yuting Huang, et al. (StepFun)
- **Summary:** A benchmark of open-ended LLM-infrastructure engineering tasks, spanning CUDA kernel optimisation up to end-to-end serving-system design and implementation. Rather than judging a single unit test, evaluation runs the produced systems and measures real infra metrics (throughput, correctness of the resulting stack).
- **Theme:** (1) Core LLM — agentic-system evaluation
- **Relevance:** One of the first hard evaluations of coding agents on *systems* code (not leetcode), directly on-theme for evaluating agent outputs in real coding applications.
- **Link:** https://arxiv.org/abs/2609.10226

## 8. Difficulty-Adaptive Tree-Structured Policy Optimization for Expanding Reasoning Coverage
- **Authors:** (author list not exposed on HF page)
- **Summary:** Reformulates reasoning-focused RL as tree-structured policy optimisation where the branching factor and rollout depth adapt to per-problem difficulty. The construction is designed to widen the set of problems the trained model can solve, rather than just deepening solutions on problems it already handles.
- **Theme:** (1) Core LLM — reasoning
- **Relevance:** Direct attack on the "coverage vs. depth" trade-off in reasoning RL, a well-scoped alternative to fixed-width GRPO-style pipelines.
- **Link:** https://arxiv.org/abs/2609.08650

## 9. Risk-Conditioned Fine-Tuning of Large Language Models
- **Authors:** (author list not exposed on HF page)
- **Summary:** Extends Risk-Averse RLHF so that the desired degree of risk aversion is conditioned on an input signal and can be dialed at inference time, rather than baked into a single fine-tune. Aimed at deployments where rare-but-severe generations must be controlled without paying the average-case quality tax up front.
- **Theme:** (1) Core LLM — fine-tuning / RLHF
- **Relevance:** Inference-time tunable safety knob learned during fine-tuning — a cheap-to-adopt idea for agent stacks where different tools have different risk envelopes.
- **Link:** https://arxiv.org/abs/2609.08064
