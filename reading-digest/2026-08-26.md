# Reading digest — 2026-08-26

Found 10 paper(s) in the last 48h window.

## 1. Recuris: Recursive Experiential-Working Memory Evolution for Long-Horizon Agent Harnesses
- **Authors**: Zhaochen Yu, Yingcheng Wu, Zhenfei Yin, et al.
- **Summary**: Recuris equips a long-horizon agent harness with two coupled memory stores — a Working Memory that tracks current task progress and a growing Experiential Memory of skills — so skill selection is grounded in what the task actually needs rather than the accumulated history. A fixed Meta-Agent then turns execution traces into validation-gated updates to the Skill Memory, forming a bounded recursive memory-evolution loop. Across four long-horizon benchmarks and ten models, task success improves in 35 of 37 pairs, with the largest gains on the longest tasks (+32.2 points) and up to 80% fewer common long-horizon failures.
- **Theme**: Multi-agent frameworks & orchestration (agent architectures)
- **Relevance note**: Directly attacks the memory/skill-selection failure modes of long-horizon agent harnesses — the central pain point for agentic orchestration.
- **Link**: https://arxiv.org/abs/2608.24876

## 2. Prime Agent: A Self-Improving RLM Harness
- **Authors**: Seth Karten, Alex L. Zhang, Kevin Thomas, et al.
- **Summary**: Prime Agent is an open-source harness built around a persistent IPython REPL following a Recursive Language Model abstraction, plus a Continual Harness that preserves histories, memories, skills, prompts, and subagent specs across trajectories. Recursive subagents coordinate through direct agent-to-agent communication, and daemon-backed sessions are inspectable via an Agents View. The harness lifts ARC-AGI-3 RHAE Best@1 from 30% to 95.5% and matches or beats native harnesses on long-context coding, GPU-kernel generation, emulator construction, and nanoGPT speedruns.
- **Theme**: Multi-agent frameworks & orchestration (coordination, communication protocols)
- **Relevance note**: Concrete agent-to-agent communication protocol plus subagent management for coding — hits multi-agent orchestration and coding-agent themes simultaneously.
- **Link**: https://arxiv.org/abs/2608.23552

## 3. Apodex 1.1: Scaling Agentic Intelligence for Complex Work
- **Authors**: Apodex Team, B. An, B. Li, et al.
- **Summary**: Apodex 1.1 scales agentic capability along two axes — Environment Scaling for verifiable executable environments and Agentic Coordination Scaling that trains agents to decompose long-horizon tasks, delegate parallel work, integrate asynchronous results, and replan — sitting on a shared execution harness and "AgentOS" that maintains task state and provenance across tools and agents. Training turns environment trajectories and coordination traces into reliable behavior. Despite being substantially smaller than frontier systems, it reaches the leading performance band across finance, scientific research, math, coding, and search.
- **Theme**: Multi-agent frameworks & orchestration (role/tool assignment, coordination)
- **Relevance note**: A production-scale recipe for training multi-agent decomposition and parallel delegation — directly on-theme for agent architecture and coordination.
- **Link**: https://arxiv.org/abs/2608.23283

## 4. Meta^n: Recursive Self-Improvement through Emergent Depth
- **Authors**: Zae Myung Kim, Young-Jun Lee, Seungyeon Jwa, et al.
- **Summary**: Meta^n keeps a single meta-operation Ω fixed and recurses on its input: at each layer, Ω reads the traces of the solver stack below plus the code that produced them and writes the next layer as a strategic pre-process plus a library of callable helpers. Because Ω never changes, it cannot destabilize the system; because its input strictly grows, each layer reasons from a higher vantage than the last, and depth is set by convergence rather than fixed in advance. Across two backbones the method beats prior self-improving agents on all eight benchmark families, and is the only system scoring above zero on the memorization-resistant ARC-AGI-2.
- **Theme**: Core LLM advances (reasoning, agentic self-improvement)
- **Relevance note**: A clean architectural answer to the two-level cap on meta-reasoning in self-improving agents, with strong ARC-AGI-2 evidence of genuine reasoning gain.
- **Link**: https://arxiv.org/abs/2608.24735

## 5. CAFE: Self-Improving Search Agents Need Co-Evolving Feedback
- **Authors**: Boyang Liu, Senjie Jin, Peixin Wang, et al.
- **Summary**: CAFE alternates a single shared-parameter model between search-agent and critic roles, coupling online RL — where a comparative call/skip success gap shapes request returns and feedback-aware advantage shaping reweights token advantages around feedback events — with offline preference optimization from matched successful/unsuccessful trajectories. This lets the critic infer useful in-trajectory corrections even as the agent's failure distribution shifts. On seven agentic search benchmarks CAFE beats RL-based baselines on average, retains gains across all six out-of-domain benchmarks, and reduces answer-level hallucinations; one-sided ablations show that improving only the agent or only the critic plateaus.
- **Theme**: Multi-agent frameworks & orchestration (role coupling and feedback protocols)
- **Relevance note**: A concrete recipe for coupling agent + critic roles that must co-evolve — relevant to any orchestration that leans on a judge/critic component.
- **Link**: https://arxiv.org/abs/2608.24794

## 6. AutoSaddler: Automatic Harness Optimization with Durable Updates from Agent Execution Traces
- **Authors**: Sungho Park, Wonjoong Kim, Rongyuan Tan, et al.
- **Summary**: AutoSaddler formulates harness improvement as an offline learning problem: it diagnoses failure traces from mini-batches, generates structured patches that treat the harness itself as code, and uses validation-based selection to accept updates. Ablations argue that the recipe works because it does deep debugging rather than shallow reflection, applies targeted rather than unconstrained edits, and selects for generalization rather than trajectory-specific repair. On GAIA2, SWE-Bench Pro, and Terminal-Bench 2.0 the framework raises agent performance by 9.0, 9.6, and 10.0 points over the corresponding base harnesses.
- **Theme**: Core LLM advances (agentic-system evaluation and improvement) with multi-agent overlap
- **Relevance note**: Treats the harness itself as the optimization target — directly applicable to any team maintaining a hand-crafted agent scaffold.
- **Link**: https://arxiv.org/abs/2608.23041

## 7. MobilePA-Bench: Benchmarking Mobile Planner Agents on Complex Real-World Tasks
- **Authors**: Yi Zhu, Xiongwei Wu, Qiyi Wang, et al.
- **Summary**: MobilePA-Bench runs planner agents inside an executable sandbox that maintains live application databases and returns structured feedback across 13 functional domains and 212 realistic mobile tools, evaluating not only tool calls but three advanced dimensions — sub-agent collaboration, memory usage, and skill invocation. It exposes concrete failure modes (strict tool ordering, permission limits, runtime errors) that static function-calling benchmarks miss. Frontier LLMs remain unreliable on this benchmark, and its interactive design doubles as a foundation for agentic reinforcement learning.
- **Theme**: Core LLM advances (agentic-system evaluation)
- **Relevance note**: Rare interactive-planner benchmark that actually measures sub-agent delegation, memory, and skill use — directly evaluates the capabilities the digest's other themes try to build.
- **Link**: https://arxiv.org/abs/2608.23035

## 8. The Mask Is Not the Model: Auditing Prefix Invariance in Attention, State-Space, and Hybrid Sequence Models
- **Authors**: Taebong Kim, Youngsik Hong, Minsik Kim, et al.
- **Summary**: The paper formalizes "prefix invariance" — that representations at position t must not depend on future inputs — and gives a training-free, gradient-free two-forward-pass audit that pinpoints exactly where causality breaks. The key observation is that inspecting attention masks is not enough: leaks can still occur via scans or normalization even when the mask is correct. Across 192 injected-fault trials on eight checkpoints the audit localizes 192/192 (versus 0/192 for mask inspection) and additionally finds a real defect in Zamba2 and Nemotron-H.
- **Theme**: Spec-driven development & formal verification (formal method for model correctness)
- **Relevance note**: A formal, testable specification of a correctness property for sequence models, with an automated verifier that finds real bugs — the clearest formal-verification-flavored contribution in the window.
- **Link**: https://arxiv.org/abs/2608.22876

## 9. CyberFactory: Scaling Cyber Security Capabilities with Instances from the Wild
- **Authors**: Jian Yang, Haau-Sing Li, Shawn Guo, et al.
- **Summary**: CyberFactory turns public CVEs into executable, verifiable task instances for LLM training across proof-of-concept generation, vulnerability patching, and cybersecurity QA, then uses a reusable vulnerability-analysis skill to guide a teacher through source inspection, priored problem solving, and evidence-based validation. The resulting supervision is agentic — the model interacts with real tools and target environments and revises solutions from execution feedback — and yields a Qwen-3.5 fine-tune that reaches 52.4% Pass@1 on CyberGym under a one-hour budget, +22.8 points over its base. Data, trajectories, and model are open source.
- **Theme**: Spec-driven development & formal verification (execution-verified coding agent training)
- **Relevance note**: Anchors coding-agent training in executable, verifiable ground truth (patches must apply, PoCs must run) — the same "spec-as-oracle" pattern the theme calls for, in a security setting.
- **Link**: https://arxiv.org/abs/2608.23181

## 10. On-policy Distillation with Verifiable Reward
- **Authors**: Wenze Lin, Jiale Zhao, Xitai Jiang, et al.
- **Summary**: OPDVR unifies on-policy distillation (dense token-level guidance) with RLVR (task-level correctness) by reformulating the implicit reward of sampled-token OPD in terms of trajectory correctness and applying a ReLU gate so that correct trajectories get non-negative rewards and incorrect ones non-positive. This turns sampled-token OPD into a proper RLVR method that plugs into any policy-gradient algorithm (e.g. GRPO) with zero added hyperparameters. On six reasoning benchmarks OPDVR consistently outperforms standard OPD.
- **Theme**: Core LLM advances (fine-tuning / reasoning)
- **Relevance note**: Cleanly resolves the trade-off between dense distillation signal and outcome verifiability — a small, hyperparameter-free change with broad reach across post-training pipelines.
- **Link**: https://arxiv.org/abs/2608.24696
