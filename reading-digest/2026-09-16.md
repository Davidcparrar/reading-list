## 1. ModularRSI: Modular and Generalizable Recursive Harness Self-Improvement
- **Authors:** Siwei Wu, Jincheng Ren, Yizhi Li, et al.
- **Summary:** ModularRSI decomposes an agent harness into five orthogonal modules (e.g. tool selection, memory, planner, critic, execution) that are evolved independently on held-out development tasks and recomposed at test time, so no single monolithic prompt or scaffold has to generalise on its own. The authors report improvements on unseen and cross-domain tasks over a fixed baseline harness, with ablations showing module-level evolution transfers where whole-harness search over-fits.
- **Theme:** T2 (with T1 crossover on agentic-system evaluation)
- **Relevance note:** Directly targets orchestration architecture — component-level self-improvement of an agent framework — rather than yet another prompt template, which is exactly the multi-agent-orchestration bucket we care about.
- **Link:** https://arxiv.org/abs/2609.14857

## 2. Emergence World: Adversarial Stress-Testing of Long-Horizon Multi-Agent Systems
- **Authors:** Deepak Akkil, Tamer Abuelsaad, Karthik Vikram, et al.
- **Summary:** The authors run eight parallel "worlds" of continually interacting LLM agents (~850k LLM calls, ~50B tokens over 16 days) that build tools, maintain memory, and share institutions, then inject three controlled adversarial events — phishing-style indirect prompt injection, misinformation, and a privacy-breach probe — to see how failures propagate. No world achieved full resilience across all three; recognising the threat did not stop agents from engaging with adversarial content and writing it into persistent memory as much as 46 hours later, arguing that model-level alignment does not compose into system-level safety.
- **Theme:** T2 (agentic-system evaluation)
- **Relevance note:** One of the first evaluations that treats multi-agent orchestration as a long-horizon dynamical system rather than a single-turn benchmark, which is uniquely useful for grounding correctness claims about agent stacks.
- **Link:** https://arxiv.org/abs/2609.17320

## 3. ScienceBuddy: Recursive-in-Recursive Self-Improvement for Interactive Scientific Agents
- **Authors:** Shuhan Xue, Jianyuan Zhong, Ziyuan Nan, et al.
- **Summary:** ScienceBuddy is an interactive research workspace in which the scientist–agent loop is itself instrumented: every human intervention (edits, follow-up questions, rejections) is converted into a training task for the underlying agents, and an outer loop trains the mechanism that mines those interactions. The result is a two-level recursion (task-level and meta-level) that keeps the agent aligned with a specific scientist's workflow over sustained sessions instead of decaying after a short conversation.
- **Theme:** T2 (multi-agent framework with fine-tuning feedback loop, crossover T1)
- **Relevance note:** A concrete design for turning human-in-the-loop feedback into continual training signal for an agent team — a pattern that generalises to any long-lived orchestrator.
- **Link:** https://arxiv.org/abs/2609.17523

## 4. RSIAgent: Autonomous Exploration for Recursive Self-Improvement in New Environments
- **Authors:** Sibo Zhu, Shicheng Fan, Xinyue Wang, et al.
- **Summary:** RSIAgent is a training-free multi-agent framework that drops into an unfamiliar environment and self-bootstraps by first running a broad exploration pass that builds a shared memory of affordances and tools, then a deep pass that specialises on the most promising sub-tasks; role assignment and communication are driven by that memory rather than by a fixed prompt. The paper argues this "broad-then-deep" schedule beats naive parallel exploration when the environment has no prior benchmark to train on.
- **Theme:** T2 (coordination, communication, role assignment)
- **Relevance note:** Puts explicit structure on how multiple agents divide exploration work in a new domain — the coordination-protocol angle of the multi-agent bucket.
- **Link:** https://arxiv.org/abs/2609.15364

## 5. HarnessVLN: Unifying Training-Free Embodied Navigation through an Agent Harness
- **Authors:** Yang Chen, Lirong Che, Zhenyu Huang, et al.
- **Summary:** HarnessVLN packages perception, mapping, and navigation as tools behind a uniform interface and layers a hierarchical event memory plus a spatiotemporal scene graph so a single planner agent can reason about "what happened where, when" before choosing an action. In a zero-shot setting it outperforms training-heavy VLN pipelines by validating each proposed action against the graph rather than executing directly from language.
- **Theme:** T2 (tool assignment, agent architecture)
- **Relevance note:** Clean example of an agent harness whose contribution is the *interface contract* between tools and planner, which is transferable beyond navigation.
- **Link:** https://arxiv.org/abs/2609.15195

## 6. Dream-RSI: Recursive Self-Improvement through Evolving Worlds
- **Authors:** Tong Zheng, Xidong Wu, Benjamin Coleman, et al.
- **Summary:** Dream-RSI replays the log of past discoveries as a set of "worlds" against which candidate exploration policies can be scored offline, replacing expensive on-policy rollouts with cached counterfactual evaluations. The authors show this collapses the cost of the outer self-improvement loop enough to make recursive rounds practical on tasks where each real trajectory is expensive.
- **Theme:** T2 (agentic RL / planning, crossover T1)
- **Relevance note:** Turns a compute-bound RSI loop into a data-bound one — directly relevant to whether recursive agent-improvement pipelines are affordable.
- **Link:** https://arxiv.org/abs/2609.14858

## 7. Stellar Colosseum: A Many-Agent Harness for Long-Horizon Research in Mathematics and Theoretical Computer Science
- **Authors:** Honghao Lin, David P. Woodruff, Vahab Mirrokni, et al.
- **Summary:** Stellar Colosseum is an orchestration harness that pits dozens of specialised agents (prover, counterexample-hunter, literature-searcher, referee, etc.) against open math / TCS problems over long horizons, with an explicit protocol for how claims are challenged and merged. The paper reports non-trivial progress on selected problems and analyses which failure modes emerge from the *interaction* of agents rather than from any individual role.
- **Theme:** T2 (multi-agent orchestration and evaluation)
- **Relevance note:** Rare study focused on scaling *count* of coordinated agents; the referee/challenge protocol is the reusable idea.
- **Link:** https://arxiv.org/abs/2609.15983

## 8. The Router Within: Eliciting Native Skill Routing from a Frozen LLM
- **Authors:** Ruishuo Chen, Xun Wang, Yu Chen, et al.
- **Summary:** The authors ("Gavel") show that the routing signal a mixture-of-experts model would learn is already latent in the hidden states of a plain frozen LLM, and can be extracted by a lightweight linear probe over intermediate activations. Using those probes as skill routers outperforms external retrieval / dispatcher pipelines without adding any trainable parameters to the base model.
- **Theme:** T1 (core LLM: inference-time skill routing)
- **Relevance note:** Cheap, model-preserving alternative to retrieval-augmented routers — attractive for agent stacks that already rely on a frozen strong LLM.
- **Link:** https://arxiv.org/abs/2609.15982

## 9. Mind2Dialogue: Training Human-Aware Language Models by Simulating User Mental States
- **Authors:** Zixuan Wang, Yufan Zhou, Jinzhou Tang, et al.
- **Summary:** The authors argue that instruction-tuned models are trained on the *dialogue surface* but never on the *user's latent state*, and fix this by generating privileged training data in which each turn is paired with a simulated mental state (goal, confusion, belief revision). Fine-tuning on this augmented data yields significant gains on personalisation and follow-instruction benchmarks over strong baselines at matched compute.
- **Theme:** T1 (fine-tuning method)
- **Relevance note:** A concrete data recipe for making a base model behave better inside long agent conversations, which is where most orchestration failures actually happen.
- **Link:** https://arxiv.org/abs/2609.15972

## 10. Disentangling Representation Evolution in Transformers through Directional Decomposition
- **Authors:** Shwai He, Haichao Zhang, Shen Yan, et al.
- **Summary:** The paper decomposes each transformer block's residual update into a component parallel to the current hidden state and one perpendicular to it, then tracks how the two evolve across layers and training steps. The perpendicular component turns out to carry most of the edit-sensitive information, giving a geometric criterion for where interventions such as activation patching or knowledge editing will actually take effect.
- **Theme:** T1 (core LLM analysis; interpretability / editing)
- **Relevance note:** Groundwork for principled model editing / PEFT — useful when we need to reason about whether a fine-tune actually changed the right thing.
- **Link:** https://arxiv.org/abs/2609.15975
