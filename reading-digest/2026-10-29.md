## 1. TAO: Tool-Aware Joint Scheduling for LLM-Based Agentic Serving
- **Authors:** Shuhuai Li, Shengdong Ye, Dongdong Ge, et al.
- **Summary:** Proposes a serving-layer scheduler for LLM agent workloads that treats external tool latency as a first-class dimension: it uses dynamic programming to co-schedule LLM steps and the sessions that will next wait on tool returns, instead of letting idle sessions block GPU slots. The authors report lower end-to-end latency and higher throughput than tool-oblivious batch schedulers on agentic workloads.
- **Theme:** (2) Multi-agent frameworks & orchestration
- **Relevance:** Direct hit on the "role/tool assignment, orchestration" sub-theme — scheduling is the layer where multi-agent systems live or die in production.
- https://arxiv.org/abs/2610.37230

## 2. Your Policy Is Secretly a Harness: The Decision Geometry of Agent Interfaces
- **Authors:** Jian Mu, Ruibo Shen, Yao Shu
- **Summary:** Argues that the shape of an agent's action/tool interface (its "harness") implicitly defines a decision geometry over which the trained policy operates, and that changes to the harness can swap the ranking of policies without any retraining. The paper formalizes this and shows benchmark cases where interface design, not model capability, dominates measured agent performance.
- **Theme:** (2) Multi-agent frameworks & orchestration
- **Relevance:** Reframes agentic-system evaluation around interface/harness design — relevant to anyone measuring agents or picking tool protocols.
- https://arxiv.org/abs/2610.37255

## 3. Rare, Relevant, and Still Wrong: How Memory Fails LLM Group Decisions
- **Authors:** Anouar Imel, Imad Charradi, Abderrahman Sghir, et al.
- **Summary:** Studies what information LLM "group chats" should retain when compressing multi-turn deliberation, and empirically shows that both rarity-based and relevance-based memory heuristics drop content that later proves decisive. Builds a controlled testbed for multi-LLM group decisions and documents concrete failure modes of common compression rules.
- **Theme:** (2) Multi-agent frameworks & orchestration
- **Relevance:** Communication/memory protocol between agents is the exact sub-theme called out; useful counter-evidence against defaulting to standard retrieval heuristics in multi-agent setups.
- https://arxiv.org/abs/2610.37624

## 4. Can LLMs Uncover Hidden Physical Laws through Free Exploration? (LongChang)
- **Authors:** Zhen Yang, Wen Wang, Xander Xu, et al.
- **Summary:** Proposes LongChang, a framework where an LLM agent is dropped into a simulated world with silently altered physical constants and must infer the modified laws through free exploration. The authors evaluate several frontier LLMs; the best model recovers the modified law in 16.7% of settings, exposing concrete planning/experiment-design gaps.
- **Theme:** (1) Core LLM advances (reasoning + agentic exploration)
- **Relevance:** Clean benchmark for long-horizon scientific reasoning by agentic LLMs — closer to real tool-use + hypothesis-formation than typical math/code benchmarks.
- https://arxiv.org/abs/2610.37649

## 5. ThinkWorld: World Imagination Reinforces Chain-of-Dynamics Reasoning
- **Authors:** Chaehyun Kim, Chi-Pin Huang, Jisoo Kim, et al.
- **Summary:** Introduces a chain-of-dynamics reasoning formulation where a model learns to imagine future world states as part of its reasoning trace, with reinforcement learning over trajectories drawn in part from unlabeled human videos. The authors claim improved transfer from human demonstration to robot execution versus prior VLA baselines.
- **Theme:** (1) Core LLM advances (reasoning / planning via learned world models)
- **Relevance:** Novel training signal for reasoning that is grounded, not purely textual — may generalize beyond robotics to any domain where state transitions are structured.
- https://arxiv.org/abs/2610.37666

## 6. Vision-Language-Action or World-Action? Just Action Models (JAM)
- **Authors:** Yonghao Yu, Lang Huang, Runyi Li, et al.
- **Summary:** Argues that popular VLA stacks over-engineer the visual-generative component, and proposes JAM: an action-only architecture trained with an explicit action loss plus a foresight loss that predicts future actions, with no pixel-space video generation. Reports that JAM matches or beats generation-heavy baselines at a fraction of the compute.
- **Theme:** (1) Core LLM advances (model architecture + training objective)
- **Relevance:** Interesting counter-trend to generative-world-model VLA; relevant for anyone evaluating how much visual generation is actually needed inside an agent loop.
- https://arxiv.org/abs/2610.37219

## 7. VibeVideoBench: Evaluating Multimodal Agents on Code-Driven Video Generation
- **Authors:** Muxi Diao, Wenbin Xu, Lele Yang, et al.
- **Summary:** Benchmark of 239 tasks where a multimodal agent must write code that renders an MP4 matching a target specification; the paper diagnoses that a majority of failures come from poor temporal budgeting rather than code bugs. Provides a standardized evaluation harness and per-category difficulty tiers for agentic code-generation on a multimodal target.
- **Theme:** (3) Spec-driven / correctness of agent coding outputs (loose fit)
- **Relevance:** The spec-side of the "spec → code → verifier" loop: the spec is a target video, the agent writes code, the artifact is checked against the spec. Not formal verification, but it is specification-anchored evaluation of coding agents.
- https://arxiv.org/abs/2610.35864

## 8. CodeCap-Bench: Can Code Serve as a Good Video Caption?
- **Authors:** Jiafu Tang, Yifan Xu, Eric Tang, et al.
- **Summary:** Benchmarks whether code (treated as an executable, formal description) outperforms natural-language captions for video understanding, finding that code captions win on question-answering and reconstruction but current models still struggle on temporal dynamics. Introduces the dataset and task alongside baseline results.
- **Theme:** (3) Spec-driven / formal description of behavior (loose fit)
- **Relevance:** Treats code as a structured specification language for grounded content; adjacent to spec-driven development in that it tests whether a model can emit a correct executable spec of a target behavior.
- https://arxiv.org/abs/2610.37341
