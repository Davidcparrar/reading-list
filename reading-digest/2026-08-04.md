# Reading digest — 2026-08-04

## 1. LongHorizon-Harness: Advancing Long-Horizon Agents for Real-World Tasks
- **Authors:** Ziyu Ma, Hailang Huang, Shun Zou, et al.
- **Summary:** Reformulates long-horizon LLM-agent execution as a task-state management problem by pulling task state and completion assessment out of the growing conversation context. A Manage-Execute-Audit (MEA) three-role loop uses a manager to keep the task state, a fresh-context executor to run one subtask, and a read-only auditor to independently verify environment changes before the next round. Reports large jumps on WeaveBench (Qwen 3.7-Plus 51.8 → 80.7), Terminal-Bench 2.1, OSWorld 2.0, and a Claude Opus 4.7 boost on OSWorld from 20.0 → 34.3, with a portable AgentAdapter so it plugs into different agent loops.
- **Theme:** Multi-agent frameworks & orchestration
- **Relevance:** Clean, model-agnostic MEA orchestration pattern with strong cross-model empirical wins — directly on the coordination/role-assignment thread.
- **Link:** https://arxiv.org/abs/2608.01964

## 2. Progressive Agent Skill Generation via Reinforcement Learning (Skill-α)
- **Authors:** Junhao Shen, Zhanqiu Zhang, Yiwen Guo, et al.
- **Summary:** Treats agent-skill construction as a sequential editing process trained with RL, so each edit becomes an individually evaluable action rather than a monolithic pipeline output. Introduces a "rollback reward" that scores each edit by rerunning the downstream task with and without the edit on an anchored query, yielding direct downstream-utility signal for skills that otherwise lack a natural label. Under a GPT-4o worker, Skill-α beats the strongest heuristic/pipeline skill baselines by 3.3 pts on CL-Bench and 6.7 pts on tau2-bench, in both document-to-skill and experience-to-skill settings.
- **Theme:** Multi-agent frameworks & orchestration (agent skill/tool assignment)
- **Relevance:** Ties agent-skill quality directly to execution outcome via RL — a principled alternative to hand-tuned skill pipelines that are common in agent frameworks.
- **Link:** https://arxiv.org/abs/2608.01678

## 3. SKT: Skill-Use Training at Scale via Verified Synthetic Data Generation
- **Authors:** Zelin Tan, Yiqun Zhang, Hao Li, et al.
- **Summary:** Builds a synthetic-data pipeline that grounds tasks in real agent skills, composes single- and multi-skill task packages, and keeps only trajectories that both pass rule/agent-based verification and demonstrably use every required skill. From 2,000 public skills the pipeline yields 4,000 tasks and 27,164 verified trajectories, plus a held-out SkillEval benchmark on a disjoint skill pool. SFT on the SKT trajectories consistently improves skill-use across models and harnesses, with ablations showing gains scale with skill coverage and depend on the verification filter.
- **Theme:** Core LLM advances (fine-tuning) + Multi-agent (tool/skill use)
- **Relevance:** Concrete recipe for producing verifiable multi-skill supervision — bridges core LLM fine-tuning with practical agent tool/skill orchestration.
- **Link:** https://arxiv.org/abs/2608.02287

## 4. DeepVoyager-VL: Incentivizing Vision-in-the-Loop Search for Long-Horizon Multimodal Agents
- **Authors:** Huanyao Zhang, Jiepeng Zhou, Runhao Zhao, et al.
- **Summary:** Targets the pattern where multimodal agents restrict vision to the input/answer stage instead of using visual evidence to drive further retrieval. Constructs a multimodal event graph to synthesize training queries with intermediate visual dependencies and long reasoning chains, then trains an agent to actively acquire and load images on demand during multi-turn search via SFT alone (no RL). Reports gains across ten multimodal search benchmarks, arguing that intermediate visual signals meaningfully extend the reasoning span of deep-search agents.
- **Theme:** Multi-agent frameworks & orchestration (agent architecture)
- **Relevance:** Extends deep-search orchestration into the multimodal setting with a clean data-synthesis recipe; useful reference for vision-aware agent designs.
- **Link:** https://arxiv.org/abs/2608.01827

## 5. SWE-Touch: Benchmarking Coding Agents When Users Touch the Code
- **Authors:** Yuqiao Tan, Jinxiang Meng, Fangyu Lei, et al.
- **Summary:** Stress-tests coding agents in shared workspaces where a human may edit task-relevant code mid-run, by mining task-critical regions from repair trajectories and injecting validated "Counter-Edits" via a separate User Patch Generator with matching messages. Across nine models on SWE-bench Verified (plus SWE-Bench Pro and DeepSWE for longer horizons), Counter-Edits drop average resolve rate by 7.7 points, and trajectory analysis pins failures on limited awareness of the evolving workspace and insufficient re-inspection/verification of affected behavior. Frames workspace-change detection, edit reconciliation, and targeted verification as the next capability targets.
- **Theme:** Spec-driven development / correctness for coding agents
- **Relevance:** Concretely operationalizes "did the agent verify against the current spec/state?" for coding — a rare eval that pushes agents toward reconciling human-edited constraints.
- **Link:** https://arxiv.org/abs/2608.02499

## 6. GradCuit: Credit-Assigned Gradient Flow Enables Robust and Interpretable Test-Time Latent Reasoning
- **Authors:** Zhaoxin Yu, Qi Shen, Hengli Li, et al.
- **Summary:** Inserts optimizable latent states at a chosen Transformer layer between prompt and continuation, so causal self-attention gives every generated-token log-probability a differentiable path back to those latents — sequence-level, reward-weighted credit is assigned to the latents directly, without routing through decoded tokens. Across five instruction-tuned backbones and three reasoning benchmarks it averages 64.5% accuracy, beating chain-of-thought by 6.6 pts and the best competing latent method by 2.4 pts, with markedly lower variance across learning rates. Token-level and layer analyses show latent influence concentrates on reasoning-connector tokens and early-to-middle layers, giving a new axis of interpretable test-time scaling.
- **Theme:** Core LLM advances (reasoning)
- **Relevance:** Cleaner credit assignment for test-time latent reasoning with strong robustness — a compact alternative to prompt/decoding-based test-time compute.
- **Link:** https://arxiv.org/abs/2608.02585

## 7. DAPD: Dual-Anchored Policy Distillation
- **Authors:** Jianyu Wu, Yizhou Wang, Encheng Su, et al.
- **Summary:** Names a failure mode of on-policy self-distillation — "privilege illusion", where the student inherits behavior that only works with the teacher's privileged inference-time context — and traces it to information asymmetry between teacher and student. Proposes Dual-Path Anchoring (a self-conditioned bridge aligning reference and rollout along matched-information paths) plus Dual-Source Anchoring (applying the paths in both directions) to keep privilege-dependent behavior from leaking into the student. Reports +2.00 avg on Qwen3-4B tasks vs OPSD, with gains persisting at 32B scale (+2.78).
- **Theme:** Core LLM advances (fine-tuning / post-training)
- **Relevance:** Diagnoses a concrete post-training pathology in a widely used paradigm and offers a minimal fix — directly useful for anyone doing on-policy distillation.
- **Link:** https://arxiv.org/abs/2608.01735
