# Reading digest — 2026-09-04

## 1. Compile by Training: Turning Natural-Language Specifications into Local Neural Functions
- **Authors:** Yuntian Deng, Pengyu Nie, Stuart Shieber
- **Summary:** The authors propose a workflow that treats a natural-language specification as if it were source code, "compiling" it into a small, reusable neural adapter by having a teacher model synthesize input-output examples that a lightweight student then distills into a specialized function. The pipeline yields callable neural components whose behavior is pinned to the written spec, so downstream systems can invoke them like ordinary functions instead of re-prompting a general LLM each time. Reported results show the compiled adapters match the teacher on the intended spec while being far cheaper to serve and easier to compose into larger programs.
- **Theme:** (3) Spec-driven development and formal verification for coding applications
- **Relevance:** The clearest match this window for spec-driven agent output — natural-language specs are literally compiled into checkable, reusable units, which is exactly the primitive needed to define and enforce correctness of agent-produced code.
- **Link:** https://arxiv.org/abs/2609.04199

## 2. Rethinking On-Policy Distillation of Large Language Models II: One Training Example
- **Authors:** Zixuan Fu, Bingxiang He, Yuxin Zuo, et al.
- **Summary:** The paper stress-tests on-policy distillation by shrinking the training set to a single query and showing that the student still recovers most of the accuracy it would gain from a full corpus, because the on-policy loop keeps discovering fresh teacher states from the student's own rollouts. That reframes on-policy distillation as algorithm-starved rather than data-starved, arguing that scaling exploration matters more than scaling prompts. The finding suggests a materially cheaper recipe for post-training reasoning models when a good teacher is available.
- **Theme:** (1) Core LLM advances — fine-tuning / distillation
- **Relevance:** A direct, provocative claim about how little data on-policy distillation actually needs, from a follow-up in an ongoing series — high-signal for anyone maintaining a post-training pipeline.
- **Link:** https://arxiv.org/abs/2609.04172

## 3. Language Models Can Control Their Own Attention
- **Authors:** Namgyu Ho, Huzama Ahmad, Woosung Koh, et al.
- **Summary:** "Declarative Attention" gives the model a way to emit tokens that name which spans of the prior context are actually relevant, and the runtime then restricts KV reads for subsequent decoding to those spans. Because most steps only touch a small fraction of the cache, the authors report large decode speedups on long-context reasoning without a measurable accuracy hit. The mechanism is training-light and adds a genuine planning primitive — the model chooses its own working set.
- **Theme:** (1) Core LLM advances — reasoning / long-context planning
- **Relevance:** A novel model-controlled attention interface with clear efficiency wins on reasoning workloads; unusual because the LM itself, not a fixed router, decides what to attend to.
- **Link:** https://arxiv.org/abs/2609.02737

## 4. PACE: Towards Surfacing Hidden Conflicts in User Requests
- **Authors:** Yoojin Kim, Jihyoung Jang, Hyounghun Kim
- **Summary:** PACE is a multi-agent pipeline in which specialized agents pull implicit personal context, cross-check the current ask against it, and flag latent conflicts that a single-shot LLM would silently satisfy. The agents divide the work into retrieval, reasoning about user-specific evidence, and conflict adjudication, then produce an explanation of the tension for the user. Empirically the framework catches request conflicts that a strong monolithic baseline misses, illustrating role-specialized coordination as a concrete win.
- **Theme:** (2) Multi-agent frameworks & orchestration
- **Relevance:** A cleanly scoped multi-agent architecture with named roles and evidence-passing between agents — the kind of orchestration pattern worth studying.
- **Link:** https://arxiv.org/abs/2609.03293

## 5. Cliff: Learning Process Rewards from the First Mistake
- **Authors:** Peixuan Han, Runhui Wang, Ketan Ramaneti, et al.
- **Summary:** Cliff builds a process reward model by localizing the first step where a rollout goes wrong and using that boundary to shape per-step advantages during RL with verifiable rewards. Because credit is concentrated at the actual point of failure rather than smeared over the whole trajectory, training is more sample-efficient and the resulting policy generalizes better on reasoning benchmarks. The recipe is a lightweight alternative to full step-level annotation.
- **Theme:** (1) Core LLM advances — reasoning / RLVR
- **Relevance:** A pragmatic process-reward signal that plugs into existing RLVR loops; matches the "reasoning" priority and is directly useful for coding-agent training where the first-mistake heuristic maps naturally.
- **Link:** https://arxiv.org/abs/2609.02817

## 6. Repo-To-Skill: Distilling GitHub Repositories Into AI4AI Skills
- **Authors:** Jianlyu Chen, Yuyang Hu, Hongjin Qian, et al.
- **Summary:** DisCo mines GitHub repositories for repeatable operational patterns and turns them into "skills" — parameterized, executable procedures that an ML research agent can call on demand. At inference time the agent dispatches skills instead of re-deriving code, which the authors report significantly improves autonomous ML-research task completion across several benchmarks. The paper is essentially a scalable pipeline for building an agent's tool/skill library from real-world code.
- **Theme:** (2) Multi-agent frameworks & orchestration
- **Relevance:** Concrete architecture for skill-based tool assignment — relevant to anyone designing an agent whose competence should grow with a growing tool library rather than a growing prompt.
- **Link:** https://arxiv.org/abs/2609.02749

## 7. EarlyEval: Cheaper Agent Evaluation via Early Outcome Prediction
- **Authors:** Yuling Shi, Zhensu Sun, Junsen Dong, et al.
- **Summary:** EarlyEval trains a small predictor to guess an agent's eventual success from short prefixes of its trajectory, then uses that predictor to halt clearly-failing runs before completion. The reported result is a large reduction in evaluation compute at only a small drop in ranking fidelity for agent leaderboards. It is a practical evaluation-infra contribution rather than a modeling one.
- **Theme:** (1) Core LLM advances — agentic-system evaluation
- **Relevance:** Directly on the "agentic-system evaluation" bullet; useful in practice because rerunning agent benchmarks is a real cost sink.
- **Link:** https://arxiv.org/abs/2609.02783

## 8. Terminal-Universe: Turning Agent Trajectories into Scalable Terminal Environments
- **Authors:** Jie Wu, Zhenru Zhang, Beichen Zhang, et al.
- **Summary:** Terminal-Universe reconstructs executable shell workspaces from recorded agent trajectories, using them to synthesize diverse post-training tasks with reproducible ground truth. The pipeline turns a scarce resource (real agent runs) into a scalable environment source and, in reported experiments, meaningfully improves downstream terminal-agent performance after training on the generated tasks. It closes an evaluation-to-training loop that most agent stacks currently leave open.
- **Theme:** (2) Multi-agent frameworks & orchestration (agent environments & training data)
- **Relevance:** Addresses a real bottleneck for coding/agent research — building realistic executable environments at scale — with a mechanism that could generalize beyond terminals.
- **Link:** https://arxiv.org/abs/2609.04148

## 9. Editable Visual Design
- **Authors:** Junyan Ye, Wei Liu, Dongzhi Jiang, et al.
- **Summary:** The system pairs a coding agent with a vision-language critic to generate structured, layered designs by first synthesizing isolated visual assets and then composing and refining them as HTML/CSS. Because each element remains individually addressable in the emitted code, designers can edit or re-prompt at the layer level rather than regenerating the whole image. Reported comparisons show the layered output is both more faithful to the prompt and easier for humans to iterate on than flat image generations.
- **Theme:** (3) Spec-driven development and formal verification (spec-to-code agentic generation)
- **Relevance:** A concrete agentic system where a spec (visual/natural-language) drives structured, verifiable code artifacts — a useful counterpoint to "compile-by-training" that stays in the code domain.
- **Link:** https://arxiv.org/abs/2609.04034

## 10. Random Attention: Rethinking KV Cache Eviction for Efficient Reasoning
- **Authors:** Heng Wang, Jielin Qiu, Wenting Zhao, et al.
- **Summary:** The paper shows that randomly evicting tokens from the KV cache — while protecting the prompt — matches carefully-designed selective compression schemes on long reasoning traces, and delivers higher throughput because the eviction policy is trivial. The authors attribute this to the substantial redundancy in reasoning chains, meaning the "which token to drop" question matters less than commonly assumed. The result is both a strong baseline and a caution about the recent burst of learned eviction methods.
- **Theme:** (1) Core LLM advances — efficient reasoning
- **Relevance:** A surprising negative result that reframes an entire recent design space; worth reading before investing in complex KV-cache compression.
- **Link:** https://arxiv.org/abs/2609.03430
