## 1. ProgramDistill: From Interactive Web Apps to Verifiable Reference-Guided SWE Tasks
- Authors: Jeonghye Kim, Minseon Kim, Young Jin Kim, et al.
- Summary: The authors build a pipeline that discovers user-visible features by driving live web apps, then distills each feature into a task with a reference implementation and executable checks so a coding agent's output can be graded against verifiable behavior rather than fuzzy rubrics. From 26 apps they generate 4,063 tasks spanning single actions to long cumulative workflows, and frontier agents top out at 49.2% and 28.8% on the two workflow tiers — a sharp drop as horizon grows.
- Theme: Spec-driven development / formal verification for coding agents.
- Relevance note: Grounds SWE-agent evaluation in reference programs and executable oracles — a direct instance of spec-as-correctness for agent code.
- Link: https://arxiv.org/abs/2609.18805

## 2. Agora: Git as Shared Memory for Collective AutoResearch
- Authors: Yifan Zhang, Yunheng Zou, Shaokun Zhang, et al.
- Summary: Agora persists every artifact of an autonomous research swarm as commits on an append-only DAG so multiple LLM workers can branch, cite, and reuse each other's results without redundant re-search or coordination overhead. In a 12-day run, 13 workers produced 1,703 commits investigating weight-transfer initialization and closed 62% of the gap to a GPT-2 baseline, showing Git-as-blackboard scales as an inter-agent protocol.
- Theme: Multi-agent frameworks & orchestration.
- Relevance note: A concrete, tool-native communication protocol for many-agent systems that treats version control as the shared memory substrate.
- Link: https://arxiv.org/abs/2609.18094

## 3. ScienceIDE: Turning World's Scientific Codebase into Agent Learnable Environments
- Authors: Hejia Geng, Zesen Huang, Haoyang Li, et al.
- Summary: ScienceIDE wraps existing scientific repositories with a uniform interface that lets an agent propose tasks, run them, and verify correctness against domain-specific criteria, converting fragmented codebases into training-ready environments. Models fine-tuned inside it (PhAI-IDE at 72B/9B/4B) improve on scientific-code repair while showing positive transfer to general coding benchmarks.
- Theme: Spec-driven development / agentic-system evaluation (coding).
- Relevance note: Environment engineering plus verifiable task generation for domain-specialized coding agents — bridges themes 2 and 3.
- Link: https://arxiv.org/abs/2609.19134

## 4. Confidence Comes from Experience: Experiential Confidence Estimation from Reasoning to Agents
- Authors: Caiqi Zhang, Xiaochen Zhu, Chengzu Li, et al.
- Summary: XConf estimates an LLM's confidence by retrieving similar past episodes and reflecting on prior failure patterns instead of averaging over sampled trajectories. Across nine reasoning and agent benchmarks it beats self-consistency on discrimination and calibration while costing less compute, suggesting experience-based signals are a cheaper drop-in for uncertainty in agent loops.
- Theme: Core LLM advances (reasoning, agentic-system evaluation).
- Relevance note: A calibration primitive useful anywhere an agent has to decide whether to escalate, retry, or hand off.
- Link: https://arxiv.org/abs/2609.17708

## 5. Rethinking Critic Learning in PPO: Understanding and Mitigating Value Flattening
- Authors: Yizhuo Li, Jianhao Yan, Yun Luo, et al.
- Summary: The authors identify Value Flattening, a critic pathology in PPO where predicted values collapse to a nearly constant curve even when true state values differ sharply, undermining advantage estimation. Their SP³O fix supervises value loss only on well-separated anchor states, restoring critic sensitivity and lifting downstream policy quality.
- Theme: Core LLM advances (RL fine-tuning).
- Relevance note: Sharp diagnosis and minimal fix for a known failure mode in the RL loop that trains reasoning and agent policies.
- Link: https://arxiv.org/abs/2609.18708

## 6. ScienceBuddy: Recursive-in-Recursive Self-Improvement for Interactive Scientific Agents
- Authors: Shuhan Xue, Jianyuan Zhong, Ziyuan Nan, et al.
- Summary: ScienceBuddy couples two self-improvement loops — an inner one that evolves the agent's execution harness (tools, prompts, scaffolding) and an outer RL loop that fine-tunes the underlying model on the harness's own trace data. In an interactive scientific workspace the two loops feed each other, letting a role-decomposed agent team improve on tasks it saw fail on prior iterations.
- Theme: Multi-agent frameworks & orchestration.
- Relevance note: A worked example of coupling harness evolution with model training — the sort of orchestration architecture the field is converging on.
- Link: https://arxiv.org/abs/2609.17523

## 7. A Zeroth-Order Paradigm for LLM Preference Alignment
- Authors: Peter Chen, Xi Chen, Wotao Yin, Tianyi Lin
- Summary: ComPO aligns an LLM to pairwise preferences without a differentiable loss, using zeroth-order estimates of the preference direction to update the policy. Across several base models it outperforms DPO-style baselines and its pair-level diagnostics indicate it avoids the likelihood-displacement pathology that plagues direct alignment methods.
- Theme: Core LLM advances (fine-tuning / alignment).
- Relevance note: A gradient-free alignment recipe that sidesteps a known DPO failure mode — relevant for agent-policy fine-tuning where the reward is only comparative.
- Link: https://arxiv.org/abs/2609.19144

## 8. EvolveTrade: Experience-Driven Policy Refinement for Self-Evolving LLM Trading Agents
- Authors: Sehee Kim, Yumin Choi, Minki Kang, Sung Ju Hwang
- Summary: EvolveTrade edits a trading agent's own system prompt based on accumulated decision traces and realized portfolio returns, treating prompt-space search as the policy update. Across multiple market regimes the self-evolved policies expand the agent's use of code-mediated analysis, an example of experience-driven prompt refinement inside a live agent loop.
- Theme: Multi-agent frameworks & orchestration (agentic self-refinement).
- Relevance note: Concrete demonstration of prompt-as-parameter self-improvement in a high-stakes agentic setting.
- Link: https://arxiv.org/abs/2609.17632
