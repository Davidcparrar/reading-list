1. **SWE-CoWork: Benchmarking Coding Agents as Digital Employees in Organizations**
   - Authors: Xinping Lei, Minghao Liu, Ruijie Zhu, et al.
   - Summary: Builds a benchmark of 101 software tasks where a coding agent is dropped into a simulated engineering organization of 26 colleagues who each hold only partial requirements, forcing the agent to interrogate teammates, reconcile conflicting asks, and implement a change validated by hidden tests. The headline result is that leading models pass roughly 63% of fail-to-pass tests but close under 8% of assignments, and the authors trace the gap to requirement tracking breaking down across the clarify → implement → verify cycle.
   - Theme: (2) Multi-agent frameworks & orchestration (coordination/communication with teammate agents) + (1) agentic-system evaluation
   - Relevance: Directly measures how LLM agents coordinate under role-split information, which is the exact bottleneck multi-agent orchestration frameworks try to fix. Puts a number on the requirement-tracking failure mode.
   - Link: https://arxiv.org/abs/2611.20218

2. **Accelerate Bench: Evaluating Agents for Application-Level Program Optimization**
   - Authors: Bowen Liu, Yuhan Li, Nuo Chen, et al.
   - Summary: Introduces a 32-task benchmark drawn from scientific software and supercomputing contests in which coding agents must plan and apply speedups across an entire program rather than a single hot loop. Sixteen agents score between 25.5% and 67.4%, and the study isolates two underappreciated levers — build/runtime configuration and inter-change interactions — that shift the ranking materially even when the raw code edits are held constant.
   - Theme: (1) Agentic-system evaluation (coding, long-horizon multi-file planning)
   - Relevance: Rare agent benchmark that forces whole-program reasoning instead of patch-sized tasks, and surfaces the build-config confounder that most coding-agent evals ignore.
   - Link: https://arxiv.org/abs/2611.20882

3. **K2-Horizon: A Frontier Fleet of Open Source Language Models**
   - Authors: K2 Team, Zhengzhong Liu, Haonan Li, et al.
   - Summary: Releases six fully open language models, ranging from a 0.9B dense base up to a 375B-A23B mixture-of-experts, all built around a value-side attention MoE and a softplus attention gate, with training data, checkpoints, code, and synthetic-data pipelines published. The report also introduces a lossless diffusion-based decoding adapter that speeds up inference without changing the sampling distribution, and targets reasoning and agentic benchmarks as the primary evaluation.
   - Theme: (1) Core LLM advances (reasoning, agentic-system foundations, open base for fine-tuning/PEFT)
   - Relevance: Full-stack open release aimed squarely at reasoning and agent use, with concrete architectural novelties (attention-value MoE, softplus gate) and a decoder speedup — gives a credible open substrate for downstream agent work.
   - Link: https://arxiv.org/abs/2611.21003

4. **Sage S2.1 Flash Technical Report**
   - Authors: Kun Cai, Haodong Chen, Guangran Cheng, et al.
   - Summary: Technical report for a 320B-parameter mixture-of-experts model trained with dedicated modality encoders (molecules, biological sequences, spectra) and explicit verifiable-environment training in tool-use, coding, and research-workflow tasks. Across 33 benchmarks it reports top or near-top rankings on document, spreadsheet, machine-learning, desktop, and web agent evaluations, with the headline being competitive agentic-task performance at MoE scale.
   - Theme: (1) Core LLM advances (reasoning + tool-use/agent training), with implications for (2) multi-agent coding stacks that sit on top
   - Relevance: One of the few recent frontier-scale reports that spells out training on verifiable coding and tool-use environments, which is closer to the agent-correctness angle than generic pretraining.
   - Link: https://arxiv.org/abs/2611.21072

5. **Latent Feedback Is a Compute and Data Amplifier**
   - Authors: Benhao Huang, Chaitanya Dwivedi, Xuezhe Ma, et al.
   - Summary: Proposes feeding each token's top-layer hidden state back as additional input for the next token, giving a transformer a lightweight recurrent-style loop, and compares head-to-head against a vanilla transformer trained for more epochs under matched budgets. Reports reaching the same validation loss with up to 48% less compute or 47% less unique data, suggesting latent feedback acts as both a compute and a data amplifier rather than just an architectural flourish.
   - Theme: (1) Core LLM advances (pretraining efficiency, likely compounds with downstream fine-tuning/PEFT)
   - Relevance: Clean controlled comparison with concrete efficiency numbers; matters if downstream agent training pipelines are compute- or data-bound.
   - Link: https://arxiv.org/abs/2611.20404
