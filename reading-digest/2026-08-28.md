# Reading digest — 2026-08-28

## 1. PILOT in the Loop: Live Self-Improvement for Long-Horizon Agents
- **Authors:** Yang Xiao, Yusong Sun, Haoyi Wu, et al.
- **Summary:** PILOT recasts long-horizon agents as a supervisor–worker loop where a live supervisor rewrites the worker's skill set mid-run instead of waiting for offline post-mortems. Steering happens between action turns, so the worker's policy and toolbelt evolve as new subgoals are discovered rather than being frozen at deploy time. The reported effect is a joint accuracy lift and a substantial cut in emitted tokens on multi-step benchmarks, suggesting the supervisor is pruning wasteful exploration on the fly.
- **Theme:** Multi-agent frameworks & orchestration
- **Relevance:** Direct hit on role-differentiated multi-agent orchestration with a real-time communication protocol between the two roles — exactly the kind of coordination pattern the second theme is asking for.
- **Link:** https://arxiv.org/abs/2608.26530

## 2. JIT-Agent: Scaling Harness Intelligence via Just-in-Time Harness Evolution
- **Authors:** Guibin Zhang, Leo Lu, Fangzhou Xie, et al.
- **Summary:** JIT-Agent trains a dedicated model that synthesizes, repairs, and evolves the *harness* around an off-the-shelf LLM instead of tuning the base model itself. The harness generator adapts scaffolding (tool wiring, prompt structure, retry strategy) to each task at inference time, and the paper reports 7.7–8.8 point gains across benchmarks with ~36% fewer tokens by picking cheaper harnesses when the task allows. It reframes "agent design" as a learnable artifact separate from the LLM weights.
- **Theme:** Multi-agent frameworks & orchestration
- **Relevance:** Turns agent architecture itself into a first-class trainable object — a novel angle on the orchestration/tool-assignment question that generalizes across model families.
- **Link:** https://arxiv.org/abs/2608.25593

## 3. WikiSkill: Compiling Agent Experience into Persistent Knowledge for Skill Evolution
- **Authors:** Liyan Tang, Cyrus Rashtchian, Chun-Sung Ferng, et al.
- **Summary:** WikiSkill treats agent skills and a shared knowledge base as co-evolving artifacts: successful trajectories are distilled into reusable skill entries indexed against wiki-style knowledge, and later runs edit both sides in place. The compiled skills are shown to transfer across model families rather than being locked to the LLM that first wrote them, which is a genuine cross-agent-orchestration property. This gives multi-agent systems a shared, model-agnostic memory substrate for coordination.
- **Theme:** Multi-agent frameworks & orchestration
- **Relevance:** Persistent, cross-model skill store is the missing communication substrate between heterogeneous agents — highly on-theme for coordination and role/tool assignment.
- **Link:** https://arxiv.org/abs/2608.27454

## 4. CaSKG: Counterfactual-Causal Skill Graphs for Scalable Agent Skill Retrieval
- **Authors:** Zhiyuan Li, Linyuan Gao, Xuechun Ding, et al.
- **Summary:** CaSKG builds a skill graph whose edges are calibrated by counterfactual-causal reasoning over prior trajectories, so retrieval favors skills whose contribution was actually load-bearing rather than merely correlated with success. Applied on top of ScienceWorld it lifts the score from 72.62 to 80.50 versus a plain graph-of-skills baseline, showing the causal weighting materially changes retrieval quality. It is a concrete answer to "which past skill should this agent reuse next" in a scalable retrieval frame.
- **Theme:** Multi-agent frameworks & orchestration
- **Relevance:** Skill retrieval and reuse across tasks is a core primitive for tool/role assignment in agent architectures — the causal weighting is a novel and measurable improvement.
- **Link:** https://arxiv.org/abs/2608.25500

## 5. What Makes Good Agentic Data? An ACE Lens on Data Generation for LLM Agents
- **Authors:** Xingshan Zeng, Zishan Xu, Boju Zhang, et al.
- **Summary:** ACE proposes a three-axis lens — Accuracy, Complexity, Diversity — for judging agentic training data, and argues that execution-grounded accuracy plus learner-relative complexity beat raw scale. The framework is used to reshape a data-generation pipeline so that produced trajectories are calibrated to the current student model's frontier rather than blindly maximizing volume. The result is a cleaner recipe for fine-tuning agents where data quality dominates data quantity.
- **Theme:** Core LLM advances (fine-tuning / agentic-system evaluation)
- **Relevance:** Directly on-theme for how to fine-tune and evaluate agentic LLMs; the ACE decomposition is a general lens applicable well beyond the paper's own pipeline.
- **Link:** https://arxiv.org/abs/2608.27260

## 6. TTPO: Test-Time Policy Optimization
- **Authors:** Aozhe Wang, Zhengxi Lu, Jianze Wang, et al.
- **Summary:** TTPO does policy optimization at inference time without any ground-truth labels by exploiting an asymmetric objective: rollouts that agree with a majority-vote consensus are distilled, and rollouts that disagree are penalized. This lets a model self-train on the actual test distribution and, in the label-free regime, closes most of the gap to supervised training with a reported ~7.2-point lift on competition-style math benchmarks. It is a compact recipe for turning inference compute into policy improvement.
- **Theme:** Core LLM advances (reasoning / fine-tuning)
- **Relevance:** Practical test-time-training method for reasoning that requires no labels — a clean, reusable technique for the reasoning/PEFT thread.
- **Link:** https://arxiv.org/abs/2608.27448

## 7. Understanding Evolution Strategies for LLM Reasoning: Broader Reasoning Coverage than GRPO
- **Authors:** Yunpeng Ba, Zhi Zheng, Yue Xie, et al.
- **Summary:** The paper contrasts Evolution Strategies (ES) with GRPO for LLM reasoning and shows that ES's population maintains genuinely broader coverage of the reasoning space, while GRPO tends to collapse onto a narrower mode. The authors then propose a sequential GRPO→ES pipeline that keeps GRPO's sample efficiency early and inherits ES's diversity late, arguing the combination dominates either method alone. It is a useful diagnostic on where current on-policy RL for reasoning is leaving performance on the table.
- **Theme:** Core LLM advances (reasoning / RL)
- **Relevance:** A grounded critique of the currently dominant reasoning-RL recipe with a concrete replacement — directly relevant to reasoning and planning work.
- **Link:** https://arxiv.org/abs/2608.27351

## 8. UrbanGround: From Local Perception to Spatial Agency in a Real-Scale City
- **Authors:** Tianjie Ju, Zheng Wu, Yueqing Sun, et al.
- **Summary:** UrbanGround is a sandbox that drops multimodal-language-model agents into a realistic full-scale 3D city and asks them to move from purely local perception (what is in view) to durable goal-directed navigation and interaction. The main empirical finding is that strong local perceptual skills fail to compose into sustained agency: agents that name objects fine still cannot chain multi-block plans. It offers a diagnostic testbed for the gap between perception and long-horizon spatial planning.
- **Theme:** Core LLM advances (agentic-system evaluation)
- **Relevance:** Real-scale evaluation harness for multimodal agents that isolates a specific compositional failure mode — fills a gap in agent-evaluation infrastructure.
- **Link:** https://arxiv.org/abs/2608.27456

## 9. Code World Model: Coding Agent as World Brain
- **Authors:** Yiwen Chen, Guosheng Lin, Chi Zhang, et al.
- **Summary:** Code World Model splits a generative world model into a coding agent that maintains persistent world state as *executable code* (state transitions are literal function calls) and a video model that renders that state into observations. A coarse "proxy" derived from the code state is used to give the renderer frame-wise constraints, keeping the visual output faithful to the underlying program semantics. The coding agent is thus a machine-checkable specification for how the world evolves, and the video model is downstream of it.
- **Theme:** Spec-driven development / formal verification for coding (loose fit)
- **Relevance:** Only paper in the 48h window that treats agent-authored code as an inspectable, executable spec governing downstream behavior — the closest datapoint to the third theme.
- **Link:** https://arxiv.org/abs/2608.25927
