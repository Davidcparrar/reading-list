## 1. Σ-Mem: An Online Reliability Memory for LLM-based Multi-Agent Systems
- **Authors:** Peilin Feng, Suorong Yang, Soujanya Poria, et al.
- **Summary:** Argues that existing multi-agent memory hoards interaction transcripts while ignoring who is actually trustworthy for what. Σ-Mem instead maintains symmetric competence and peer-relationship matrices that are updated online from per-decision correctness feedback, using Weyl's inequality to bound spectral drift so the memory stays stable as new observations arrive. On Qwen-family agents the memory-driven router beats majority voting and fixed peer selection, adapts to reliability shifts, and generalizes to unseen peers and OOD task domains.
- **Theme:** Multi-agent frameworks & orchestration.
- **Relevance:** Directly targets coordination and role-assignment in LLM multi-agent systems with a lightweight, training-free memory — high-leverage for agent-fleet designs.
- **Link:** https://arxiv.org/abs/2607.27958

## 2. LEDGERMIND: Provenance-Constrained Multimodal Agentic Reasoning with a Structured Evidence Ledger
- **Authors:** Enjun Du, Hange Zhou, Chenxu Du, et al.
- **Summary:** Reframes an agent's trajectory as a provenance-constrained state machine whose central artifact is a typed evidence ledger: every tool output is normalized into entries carrying source, type, confidence, and lifecycle, and downstream reasoning is only allowed to cite ledger content. Around this ledger the authors add a three-layer grounding check, an adaptive direct-vs-full dispatcher, and a set of seven typed self-repair operators with a formal non-amplification guarantee on provenance. Training-free over six frontier MLLMs, it lifts VTC-Bench to 58.9% SOTA (+11.8 to +23.3 across backbones) and reduces phantom-grounding errors, showing the accuracy gains come from grounded — not coincidentally correct — trajectories.
- **Theme:** Multi-agent frameworks & orchestration (bridges into spec/verification of agent outputs).
- **Relevance:** Rare combination of an executable "spec" for agent evidence use plus audit metrics that measure trajectory faithfulness, not just final answers — closest thing in this batch to formal correctness of agent outputs.
- **Link:** https://arxiv.org/abs/2607.28374

## 3. Echoverse: Deep, Evolving Environments for Training Computer-Use Agents at Scale
- **Authors:** Yash Pandya, Sahil Gupta, Sarthak Harne, et al. (Microsoft Research)
- **Summary:** Attacks the environment-quality bottleneck for computer-use agents by co-evolving world and policy: the same graded rollout that scores the agent also refines the world. A two-phase pipeline first generates applications from specifications and validates them against machine-checkable workflow claims (to 95% compliance), then grounds tasks directly in the live DB with white-box feasibility filtering. Training a 9B model on 21k verified trajectories across 12 domains lifts task success 36.5% → 67.1% across 14 splits, and RL on top of that lifts held-out judged score 58.8% → 68.0%, closing to within 14 points of the GPT-5.4 teacher.
- **Theme:** Multi-agent frameworks & orchestration (agent-environment co-evolution, agentic-system evaluation).
- **Relevance:** Serious industrial recipe for scalable computer-use agent training — the operationalized notion of environment "depth" is a useful primitive for any agentic evaluation pipeline.
- **Link:** https://arxiv.org/abs/2607.28074

## 4. Harness-G: A Graph-Structured Harness for Search Agents
- **Authors:** Yanning Hou, Haoyuan Chen, Sihang Zhou, et al.
- **Summary:** Diagnoses a "retrieval-equivalence collapse" in RL-trained search agents — different queries hitting the same evidence — and blames the free-form query interface rather than the reward. Harness-G replaces query generation with finite action selection over a paragraph–sentence–entity graph, deterministically constructs queries from those picks, and adds Structured Non-myopic Credit (frontier-relative advantage plus enablement credit propagated back along provenance edges). At 3B it averages F1 55.24 across six QA benchmarks (+3.98 over Graph-R1); at 1.5B it jumps from 40.09 to 50.83, with the biggest wins on multi-hop tasks.
- **Theme:** Multi-agent frameworks & orchestration (agent action-space and credit design).
- **Relevance:** Concrete, ablated evidence that constraining an agent's action interface — rather than shaping rewards — is the right lever, generalizable well beyond search.
- **Link:** https://arxiv.org/abs/2607.27652

## 5. VideoCoCo: Code-as-CoT for Physically-Consistent Video Generation via an Agentic Dual-Engine System
- **Authors:** (20+ authors across CUHK, USTC, SCUT, HKU, NTU, PKU, SJTU, CMU, THU, HUST, MBZUAI)
- **Summary:** Splits physically-consistent T2V into two cooperating agents: a coding agent that synthesizes an executable Blender program encoding the scene's spatiotemporal dynamics, and an instruction agent that turns the sandbox-rendered deterministic draft into a photorealistic video via draft-conditioned editing. A 3k-triplet dataset (VideoCoCo-3K) is used to adapt the editor with LoRA. Reports 0.475 → 0.558 on PhyGenBench and a 52.18% → 77.88% jump on VBench-2.0, with ablations showing draft-based simulation, not just heavier tuning, drives the physics gains.
- **Theme:** Multi-agent frameworks & orchestration (code-as-intermediate-representation coordination).
- **Relevance:** Nice worked example of using executable code as a shared interlingua between reasoning and generative agents — a pattern that transfers straight to coding-agent stacks.
- **Link:** https://arxiv.org/abs/2607.27380

## 6. From RLVR to RLSVR: Task Transformation Induces Self-Verifiable Rewards for Open-Ended LLM Self-Improvement
- **Authors:** Qinsi Wang, Jing Shi, Huazheng Wang, et al.
- **Summary:** Extends verifiable-reward RL beyond math/coding by transforming an open-ended task into a proxy environment where correctness is auto-checkable. The instantiation, SpyRL, casts self-improvement as a "Who Is the Spy?" multi-agent game with asymmetric information and voting-based rewards, so the reward signal comes from the game structure rather than a learned judge. Reports gains over prior self-improvement recipes on summarization, creative writing, and math reasoning.
- **Theme:** Core LLM advances (RL/fine-tuning, reasoning).
- **Relevance:** Addresses the core "how do we do RLVR when there's no verifier?" problem via multi-agent task transformation — bridges themes 1 and 2.
- **Link:** https://arxiv.org/abs/2607.23802

## 7. Not All Tokens Deserve Equal Credit: Counterfactual Sensitivity Credit Reallocation for Long-CoT Reasoning
- **Authors:** Qiangqiang He, Zhongheng Wu, ZiJian Wang
- **Summary:** Observes that when a long-CoT trajectory is scored under both positive and negative outcome conditions, the most sensitive tokens shift in the same direction under either condition — a sign they dominate credit for the wrong reason. CSCR down-weights these high-sensitivity tokens and re-spends the budget on the rest, keeping total optimization mass constant. Reports stronger math-reasoning performance with fewer policy updates.
- **Theme:** Core LLM advances (reasoning, fine-tuning).
- **Relevance:** A cheap, drop-in modification to RL-for-reasoning that attacks a real failure mode of naive token-level credit — likely to compose with existing recipes.
- **Link:** https://arxiv.org/abs/2607.27888

## 8. Enhancing Rubric-based RL via Self-Distillation (CriPO)
- **Authors:** Mingxuan Xia, Yuhang Yang, Chao Ye, et al.
- **Summary:** Isolates two failure modes of rubric-based RL: criteria that are never exercised by rollouts (no gradient signal) and criteria whose signal gets washed out when many rubric scores are summed into one scalar reward. CriPO fixes both with criterion injection (forcing rollouts to touch untested criteria) and counterfactual self-teachers that disentangle per-criterion signal from the scalar. Claims roughly 2× fewer optimization steps to reach stronger final scores on medicine and science benchmarks.
- **Theme:** Core LLM advances (rubric-driven fine-tuning / PEFT-adjacent).
- **Relevance:** Practical fix for a very common recipe (rubric → scalar reward → RL) that many agentic-system builders use for evaluation-time supervision.
- **Link:** https://arxiv.org/abs/2607.18082

## 9. Fewer Clarifications, Better Code: Benchmarking Cross-Session Personalized Ambiguity Adaptation in Coding Assistants (CAPA)
- **Authors:** Zijian Xu, Wenshuo Zhang, Zisen Qin, Rui Sheng, Yushi Sun, Huamin Qu, Chuhan Shi
- **Summary:** Introduces personalized ambiguity adaptation: instead of resolving each ambiguous coding request in isolation, a long-term assistant should infer, from a user's prior resolved sessions, the *recurring* ways that user underspecifies things. CAPA operationalizes this with six linguistically-grounded ambiguity mechanisms, a three-stage generation pipeline (make-ambiguous → dialogue → cross-session consistency check), and 600 executable sessions across 60 user-ambiguity cells with held-out splits. Across 12 recent LLMs, same-user history lifts Executable Success by an average of 6.8 pts and First-Turn Executable Success by 15.6 pts, yet frontier models still cap at 78.7–90.0%.
- **Theme:** Spec-driven development / correctness for coding applications (elicitation of implicit user spec).
- **Relevance:** The closest paper in this batch to "defining correctness of agent outputs for coding" — treats a user's implicit spec as the object to be learned across sessions.
- **Link:** https://arxiv.org/abs/2607.26611

## 10. Frontis-MA1: Training an AI4AI Model towards Recursive Self-Improvement in Machine Learning Engineering
- **Authors:** Junlin Yang, Che Jiang, Yu Fu, et al.
- **Summary:** Trains a 35B "meta-evolution" agent whose action space is four program-evolution operators — Draft, Improve, Debug, Crossover — over the OpenMLE infrastructure (verifiable task environments, operator learning, extended search). Training combines execution-grounded SFT with RL on curated data, then wires the operators into an extended search that merges learning and evolution. On MLE-Bench Lite (single RTX 4090, 12h/task) it moves the score from 39.39% to 60.61%, and to 71.21% with optimization, surpassing several GPT variants.
- **Theme:** Spec-driven / correctness for coding applications (execution-grounded ML-engineering agents) with heavy overlap into core LLM advances.
- **Relevance:** One of the few papers here where the agent's outputs are code judged by executable ground truth — a concrete instance of correctness-via-execution for coding agents.
- **Link:** https://arxiv.org/abs/2607.28568
