# Reading digest — 2026-08-11

Found 10 paper(s) in the last 48h window.

1. **Macaron-V1: Towards Open Continual Learning with Self-Improvement and Mixture-of-LoRA** — Mind Lab, Vin Bo, Asher Cai, et al.
   Proposes an open agent-model family that pairs a Mixture-of-LoRA adapter router with a recursive self-improvement loop so specialized skills can be added without catastrophic forgetting. Each LoRA expert is trained on task-specific self-generated trajectories that a critic filters, letting the base model be extended continually rather than re-tuned end-to-end. Reported gains hold across coding, math, and tool-use suites relative to a full-parameter SFT baseline.
   Theme: (1) Core LLM — PEFT and fine-tuning.
   Relevance: Directly on-target for PEFT + agentic self-improvement at model-family scale.
   Link: https://arxiv.org/abs/2608.09819

2. **Motif 3: Technical Report** — Junghwan Lim, Joon Son Chung, Sungmin Lee, et al.
   A 314B-parameter sparse mixture-of-experts LLM built around a new "grouped differential latent attention" block that trims attention memory and improves long-context stability. The report documents pretraining data mix, expert-routing balancing, and post-training for reasoning, coding, and tool use, with competitive scores on agentic and long-context evaluations. Serves as a reference point for training frontier open-weight LLMs with tool-oriented objectives.
   Theme: (1) Core LLM — architecture and reasoning.
   Relevance: Fresh open-weight MoE recipe with explicit tool-use training — useful baseline signal.
   Link: https://arxiv.org/abs/2608.09119

3. **Mismatch Matters: On-Policy Distillation Beyond Token Agreement** — Zichao Yu, Chengzhi Yu, Shengze Xu, et al.
   Identifies a "degenerate agreement" failure in on-policy distillation where students exploit repetitive loops to match teacher tokens while producing globally wrong answers. Decomposes the residual into student-excess and student-deficit tokens and proposes TIDE, which applies bounded Hellinger shaping to the excess side and injects the teacher's top-K mass on the deficit side. On Qwen3 teacher-student pairs across math reasoning benchmarks it beats vanilla OPD and recent token-selection baselines.
   Theme: (1) Core LLM — reasoning and post-training.
   Relevance: Targets a subtle but common breakdown in reasoning distillation with a clean fix.
   Link: https://arxiv.org/abs/2608.09836

4. **Evo-Bench: Can Language Models Improve Agent Harness?** — Lisheng Huang, Chen Yang, Hao Zhou, et al.
   First benchmark that measures whether an LLM can autonomously rewrite its own agent harness — prompts, tools, control flow — instead of only solving fixed tasks. Uses auxiliary-task evolution to isolate harness-sensitive workloads and a sensitivity-aware split to test generalization across Search, Office, and General domains. Frontier models close roughly half the gap to hand-engineered harnesses in Search but stall on Office workflows, suggesting evolved harnesses transfer as reasoning scaffolds.
   Theme: (1) Core LLM — agentic-system evaluation.
   Relevance: Direct methodology contribution to evaluating self-improving agents.
   Link: https://arxiv.org/abs/2608.09096

5. **BDH-CQ: In-Context Learning with Recurrent Latent Reasoning** — Pathway team (authors unlisted on HF).
   Introduces a 150M-parameter recurrent-latent reasoner that keeps updating a high-dimensional memory across in-context demonstrations and iterates in latent space instead of verbalizing chain-of-thought. Reaches 29.5% pass@2 on ARC-AGI-1 at ~$0.0007 per task, pushing the cost-accuracy Pareto frontier by an order of magnitude. Ablations study which ARC concepts are learned from demonstrations vs. which remain out of reach.
   Theme: (1) Core LLM — reasoning and planning.
   Relevance: Concrete evidence that non-verbal, iterative latent reasoning can be competitive at very low cost.
   Link: https://arxiv.org/abs/2608.09888

6. **RoMeRL: Balancing Feedback Coverage and the Memory-Reward Trap in Self-Evolving Agent Memory via Reduced-Order Utility States** — Yi Yang, Zhennan Chen, Yihong Zhuang, et al.
   Shows that trajectory-indexed memory utilities in self-evolving agents dilute feedback and let irrelevant experiences absorb reward, then replaces them with a fixed-dimensional per-task state factorized by outcome polarity and memory dynamics. New experiences are absorbed by updating a bounded set of semantic coordinates, which concentrates feedback and bounds contamination. On ALFWorld and LifelongAgentBench it cuts memory size 84%, LLM calls 21%, and increases per-coordinate feedback density about 6×.
   Theme: (2) Multi-agent frameworks & orchestration — agent memory design.
   Relevance: A principled reformulation of a well-known failure mode in self-evolving agent memory.
   Link: https://arxiv.org/abs/2608.02508

7. **Intent Speaks Louder: Controllable User Simulation Beyond Response Imitation** — Bo Wang, Ruixing Zhang, Yunqi Liu, et al.
   Argues that user simulators trained by response imitation drift into generic behavior, and proposes UserIDA to condition each turn on an explicit intent directive and calibrate it with reinforcement learning. The framework separates "what the user wants" from "how they phrase it", enabling reproducible stress-testing of dialog agents with prescribed goal shifts. Reported improvements in intent adherence and diversity over supervised and preference-tuned simulators.
   Theme: (2) Multi-agent frameworks & orchestration — coordination via role-conditioned simulation.
   Relevance: Cleaner primitives for evaluating multi-turn agents, useful across orchestration benchmarks.
   Link: https://arxiv.org/abs/2608.09420

8. **Security Tests as Executable Specifications for LLM Code Generation: Benefits, Trade-offs, and Coverage Limits** — Yunhao Liang, Chengguang Gan, Ruixuan Ying, et al.
   Treats security tests as executable specs and dissects three orthogonal knobs — showing tests upfront, triggering revision on failure, and how failures are represented — via the SecTDD scaffold. Across 2,705 trajectories, 31 tasks, 16 CWEs, and two model families, showing all visible tests upfront raises joint functional-and-security success by 19.3 points on average, but candidates that pass every visible test still fail hidden behavior families. Establishes concrete limits of test-as-spec regimes and quantifies where structured vs. raw feedback wins or regresses.
   Theme: (3) Spec-driven development & formal verification for coding agents.
   Relevance: On-thesis for spec-driven development — quantitative, benchmark-heavy, and honest about coverage gaps.
   Link: https://arxiv.org/abs/2608.09740

9. **SWE-Bench ProMax: Benchmarking Agents on Large-Scale Multilingual Code Refactoring** — Yuling Shi, Jinghan Xu, Kelin Fu, et al.
   Expert-curated multilingual coding-agent benchmark with 170 instances across seven languages, built to fix quality issues (leakage, ambiguous specs, brittle graders) in prior refactoring benchmarks through manual review. Evaluates frontier agents on realistic refactor-and-verify tasks; the top system reaches 41.2% resolve rate, exposing large gaps outside Python/JavaScript. Provides a cleaner ground-truth surface for spec-driven and formal-check-oriented coding agents.
   Theme: (3) Spec-driven development & formal verification for coding agents.
   Relevance: Direct evaluation substrate for coding agents whose correctness must be verified against specs.
   Link: https://arxiv.org/abs/2608.09802

10. **Stealing Reasoning Traces from Proprietary LLM APIs** — Alexander Panfilov, David Schmotz, Ilia Shumailov, et al.
    Shows that encrypted or hidden intermediate reasoning traces served by proprietary LLM APIs can be intercepted and replayed into weaker open models to recover the trace, and via it, hidden prompts and private context. Formalizes the threat model, quantifies extraction fidelity, and demonstrates leakage even when the API surfaces only summary answers. Directly relevant to how deployed multi-agent systems protect their reasoning traces and intermediate scratchpads.
    Theme: (1) Core LLM — reasoning under adversarial deployment (with implications for agent orchestration).
    Relevance: Novel deployment-side threat vector that any agent stack sharing intermediate reasoning must consider.
    Link: https://arxiv.org/abs/2608.09867
