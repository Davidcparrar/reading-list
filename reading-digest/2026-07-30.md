## 1. Keep It InMind: Benchmarking the Implicit-Association Blind Spot in Agent Memory
- Authors: Ruizhe Li, Mingxuan Du, Benfeng Xu, et al.
- Summary: Introduces InMind, a 125-task expert-verified benchmark that isolates a specific failure of retrieval-based long-term memory: retrieval assumes the needed memory will *look like* the query, but world knowledge often bridges them silently (e.g., a stored tree-nut allergy is relevant to a macaron request only via "almond flour"). The paired controls disentangle three confounded causes — never stored, missing bridging knowledge, or stored-but-not-surfaced — and show that with the fact in context the backbone answers 84.0% of indirect queries, while six vector/graph/agentic memory systems reach at most 14.4% even though they can recall the same facts on demand. A minimal probe that keeps memory visible before the query recovers most of the gap, locating the failure in the query-conditioned retrieval interface rather than storage.
- Theme: Memory for LLMs and agents
- Relevance: Rare direct evaluation of *retrieval-conditioning* as the memory bottleneck across vector, graph, and agentic systems, with a diagnostic that pinpoints the failure locus.
- Link: https://arxiv.org/abs/2607.24368
- Window note: `published_at` 2026-07-26T20:00Z (arXiv 07-27 listing) — just outside the strict 48h window; kept for theme coverage.

## 2. CodeNib: A Multi-View Data System for Serving Repository Context to Coding Agents
- Authors: Zhongming Yu, Hengjia Yu, Boqin Yuan, et al.
- Summary: Treats "repository context" for coding agents as a first-class data system: builds reusable lexical, dense, and structural views per repo commit, keeps them updated across edits, and serves ranked search, symbol navigation, and bounded context through one runtime with explicit validity boundaries. On 100 snapshots, incremental graph/vector updates are 8.7× and 25.4× faster than a full rebuild (median), and static navigation matches live-server locations on 63% of 1,000 requests with a 4.7× median latency win. Selected context policies across five models preserve localization with 50–87% fewer trajectory tokens than paired grep/read.
- Theme: Memory for LLMs and agents (context/state management)
- Relevance: Concrete, measured design for the "working memory" layer under coding agents — an area where most work is anecdotal harness code rather than a system with lifecycle costs.
- Link: https://arxiv.org/abs/2607.25431
- Window note: `published_at` 2026-07-27T20:00Z (arXiv 07-28 listing) — effectively in-window.

## 3. Grading the Narrators: An Isnad-Rijal Framework for Claim-Level Provenance in Multi-Agent Knowledge Systems
- Authors: Ali Zahid Raja
- Summary: Ports the Islamic hadith-science methodology (isnad = chain-of-transmitters, rijal = narrator grading) into a formal apparatus for multi-agent AI pipelines: a mapping from hadith concepts to pipeline components, a relational schema for claim chains, and a decision matrix that combines chain grade with content criticism to decide what to trust, quarantine, or drop. Evaluated on 20,000 physics-textbook claims against a "weakest-link" quarantine policy, showing the framework filters agent-produced claims by provenance quality rather than just final-answer plausibility. Framed as a governance primitive rather than a new agent architecture.
- Theme: Multi-agent frameworks & orchestration
- Relevance: Addresses claim-level provenance for multi-agent systems, an under-served part of the orchestration stack (most work focuses on role/tool routing, not on how downstream agents should weight upstream agents' outputs).
- Link: https://arxiv.org/abs/2607.24117
- Window note: `published_at` 2026-07-27T00:00Z — just outside strict window; kept for multi-agent coverage.

## 4. SkillRise: Agentic Reinforcement Learning for Cross-Task Skill Evolution
- Authors: Zhiyuan Yao, Yuxin Chen, Zhengxi Lu, et al.
- Summary: A unified RL framework where a single policy alternates between solving tasks and curating a shared "skill document" that generalizes across related instances organized into progressively harder sequences. This casts cross-task transfer as skill accumulation rather than per-task specialization, with the same policy responsible for both writing and consuming skill notes. Reports strongest Pass@1 with 2.3–8.5 percentage-point gains over the strongest baseline.
- Theme: Multi-agent frameworks & orchestration (self-orchestration over skill memory)
- Relevance: Sits at the intersection of agentic RL and skill/knowledge orchestration — a natural companion to the memory theme, since the shared skill document is essentially explicit long-term procedural memory.
- Link: https://arxiv.org/abs/2607.26784

## 5. GPT-Red: Automated Red Teaming via Self-Play at Scale
- Authors: Eric Wallace, Christopher A. Choquette-Choo, Nikhil Kandpal, et al.
- Summary: Trains a red-teaming agent to discover novel prompt-injection attacks via a scalable self-play algorithm in which the attacker faces a diverse *population* of defenders rather than a single fixed target. The trained attacker reliably breaks past models, generates a larger and more diverse attack set than human red-teamers, and transfers to held-out environments. The population-based defender pool is the key structural claim over prior single-defender self-play.
- Theme: Multi-agent frameworks & orchestration (attacker-vs-defender-population self-play) / agentic-system evaluation
- Relevance: One of the few papers this week that treats a *multi-agent population* as a first-class training substrate, and the empirical scale (transfer + human-baseline coverage) is unusual for red-teaming work.
- Link: https://arxiv.org/abs/2607.26115

## 6. CAST: Game Solvers as Turn-Level Teachers for LLM Agents
- Authors: Yu Wang, Yi-Kai Zhang, Wentao Shi, et al.
- Summary: Injects game-solver state-value deltas into RLVR as *turn-level* advantages so credit isn't smeared across a whole trajectory. Under a soft-optimal solver assumption, maximizing the solver advantage becomes equivalent to on-policy distillation from the solver. Outperforms all trained baselines on Sokoban, Minesweeper, and Rush Hour.
- Theme: Core LLM advances (reasoning / planning / agentic RL)
- Relevance: Sharp, principled turn-level credit-assignment mechanism for LLM agents in planning-heavy environments, with a clean equivalence to distillation that makes it easy to reason about.
- Link: https://arxiv.org/abs/2607.25308

## 7. Can AI Agents Conduct Open-Ended AI Research? Early Evidence from Two Case Studies
- Authors: Peter Kirgis, Sayash Kapoor, Andrew Schwartz, et al.
- Summary: A "shadow evaluation" protocol where frontier agents attempt the central research question of an *unpublished* paper and are graded by the paper's original authors. Frontier agents completed all engineering without human help but did not make substantial research progress, and the authors identify five recurring failure modes including poor judgment about which experiments to run and ineffective backtracking. Notable methodologically because grading is done by the people who actually know the answer.
- Theme: Core LLM advances (agentic-system evaluation)
- Relevance: One of the most credible agent-capability evaluations of the week — the ground-truth is held by the paper authors, not by benchmark curators guessing at difficulty.
- Link: https://arxiv.org/abs/2607.27191

## 8. OmegaUse-OfficeVal: Benchmarking LLM Agents on Long-Horizon Office-Suite Tasks with Economic Grounding
- Authors: Jingbo Zhou, Yusai Zhao, Qi Bao, et al.
- Summary: 100 long-horizon office-suite tasks (averaging 2.32 human labor-hours each), each paired with a human labor-time and price proxy so agent runs can be scored on time and dollar cost, not just success rate. Reports all evaluated LLMs are cheaper and faster than humans on these tasks but still short of human-level quality. The economic-grounding step is the novel design lever versus prior office-agent benchmarks.
- Theme: Core LLM advances (agentic-system evaluation)
- Relevance: Adds cost/latency as first-class metrics for agent benchmarks, which shifts what "SOTA" means once quality alone stops discriminating models.
- Link: https://arxiv.org/abs/2607.27155

## 9. CoRT: Counterfactual Replay for Token-Level Rubric-Guided Policy Optimization
- Authors: Bo-Wen Zhang, Junwei He, Wen Wang, et al.
- Summary: A token-level credit-weighting scheme for rubric-conditioned GRPO. Instead of relying on an auxiliary scorer, CoRT rescores responses by *counterfactual replay* and maps token-wise log-likelihood contrasts to response-normalized weights that redistribute the GRPO advantage across tokens. Reports a 4.4 percentage-point improvement over matched response-level GRPO.
- Theme: Core LLM advances (fine-tuning / RL)
- Relevance: Cleanly targets the "which token deserves the reward" problem in RLHF-style training without adding a separate scorer, which is a real ergonomic and stability win.
- Link: https://arxiv.org/abs/2607.25659

## 10. DecoEvo: Score-Decoupled Co-Evolution of Solver and Rubric-Generator Skills in Text Space
- Authors: Jiangwang Chen, Zixin Song, Junlin Liu, et al.
- Summary: Co-evolves a solver and a rubric-generator under *decoupled* objectives with no gold rubrics: the solver is updated via criterion-level feedback from the current rubric, while the rubric-generator is revised through complementary audits that are independent of the aggregate solver score. Reports 2.8–5.0% relative gains over SkillOpt across five benchmarks. The decoupling is the key move — it stops the two skills from optimizing the same aggregate metric and reward-hacking each other.
- Theme: Core LLM advances (fine-tuning)
- Relevance: Concrete design for gold-rubric-free evaluator/solver co-training, addressing a well-known failure mode in self-improvement pipelines.
- Link: https://arxiv.org/abs/2607.25675
