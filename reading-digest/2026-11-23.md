## 1. MemOnce: A Scalable Memory Architecture for Large Language Models
- Authors: Chang Nie, Chaoyou Fu, Songlin Liu, et al.
- arXiv: 2611.27973 — https://arxiv.org/abs/2611.27973
- Summary: MemOnce proposes caching only compact final-layer hidden states at write time and reconstructing per-layer KV caches on demand when those tokens are actually retrieved, instead of storing the full KV cache for every past token. A sparse retrieval step over the cached states selects what to materialize, cutting memory and latency on very long contexts while retaining the information that matters.
- Theme: (1) core LLM advances — memory / long-context inference.
- Relevance: Directly reshapes how an agent carries state across long sessions, which matters for lifelong agentic workflows and RAG-free long-horizon coding.

## 2. Intent Contracts: Taking Tools Away from Agents
- Authors: Ziyuan Wang, Genliang Zhu, Xiaobo Chen, Chu Wang.
- arXiv: 2611.24025 — https://arxiv.org/abs/2611.24025
- Summary: The paper separates planning from execution: a tool-less planner emits a logged "intent contract" describing what should happen, and a trusted executor is the only component allowed to call tools against that contract. Task completion goes up, but the authors report that the pattern does not by itself reduce unauthorized actions — authorization still has to be enforced in the executor.
- Theme: (3) spec-driven development / formal-style constraints on agent output.
- Relevance: One of the cleanest fresh takes on treating agent outputs as contracts rather than free-form tool calls, which is the spec-first direction for correctness of coding agents.

## 3. MAWAM: A Multi-Agent World-Action Model for Coordinated Manipulation
- Authors: Xianzhe Fan, Chi-Pin Huang, Linxi "Jim" Fan, et al.
- arXiv: 2611.25105 — https://arxiv.org/abs/2611.25105
- Summary: MAWAM trains a single joint world-action model that predicts both the next actions of multiple robots and the shared visual rollout they produce, so coordination falls out of a common latent dynamics rather than hand-wired message passing. The model is evaluated on coordinated manipulation tasks where independent per-agent policies normally desync.
- Theme: (2) multi-agent frameworks & orchestration.
- Relevance: A concrete architecture-level answer to coordination — shared world model as the communication protocol — instead of yet another prompting-layer orchestrator.

## 4. SpecWM: Turning Verification into Refinement for Streaming World Models
- Authors: Listed on arXiv page.
- arXiv: 2611.26211 — https://arxiv.org/abs/2611.26211
- Summary: SpecWM frames verification of a streaming world model's rollout as an iterative refinement loop: a cheaper draft produces predictions, a verifier flags violations of the spec, and the verifier's signal is fed back to refine subsequent steps rather than to merely reject them. The reported result is tighter adherence to the stated constraints without paying the full cost of per-step verification.
- Theme: (3) spec-driven development / formal verification applied to generative agents.
- Relevance: Transfers naturally to coding agents — the same verify-then-refine loop is what a correct-by-construction code synthesis pipeline wants.

## 5. AgentRoboCritic: Understanding the Capability of Frontier Agents on Direct Robot Control
- Authors: Yiyang Du, Yuxuan Kuang, Qitao Zhao, et al.
- arXiv: 2611.26613 — https://arxiv.org/abs/2611.26613
- Summary: AgentRoboCritic is an action-level evaluation framework for frontier LLM agents that are asked to drive robots directly (not via a high-level skill library), along with an annotated dataset of failure cases and an open critic model. The paper characterizes where current agents break — perception grounding, long-horizon planning, control semantics — rather than just reporting an aggregate success rate.
- Theme: (1) core LLM advances — agentic-system evaluation.
- Relevance: The critic + dataset combo is a reusable evaluation harness, and the failure taxonomy is directly useful for planning-benchmark design.

## 6. Duopra: From Full-Duplex Conversation to Full-Duplex Agency
- Authors: Chiyu Chen, Pengzhou Cheng, Yuezhao Ma, et al.
- arXiv: 2611.25773 — https://arxiv.org/abs/2611.25773
- Summary: Duopra extends full-duplex voice modeling from "talk while listening" to "act while listening": the backend that executes tools is itself exposed as a tool, and a three-stage training pipeline teaches the model to keep conversational turns and task execution interleaved without stalling either. The authors report a substantial lift in tool-calling success rate under duplex conditions.
- Theme: (2) multi-agent frameworks & orchestration — tool/role assignment under streaming constraints.
- Relevance: Shows a workable protocol for concurrent conversation + tool use, which is the regime real agent products live in.

## 7. TwinLab-Bench: Evaluating AI Scientists in Agentic Twins of Real Labs
- Authors: Listed on arXiv page.
- arXiv: 2611.26248 — https://arxiv.org/abs/2611.26248
- Summary: TwinLab-Bench builds digital-twin environments of actual wet- and dry-lab workflows and drops AI-scientist agents into them end-to-end: plan, run instruments (simulated), interpret results, iterate. The benchmark is deliberately deployment-style rather than isolated-task to surface compounding failures across a full research loop.
- Theme: (1) core LLM advances — agentic-system evaluation.
- Relevance: Rare example of a benchmark that actually exercises long-horizon scientific coding and experiment control, not just single-shot QA.

## 8. AutoMaster: Autonomous Post-Training by Making the Same Model a Better Teacher
- Authors: Listed on arXiv page.
- arXiv: 2611.26510 — https://arxiv.org/abs/2611.26510
- Summary: AutoMaster post-trains a model using data generated by the same model acting as its own teacher, but with a mechanism to continuously raise the teacher's quality so self-distillation does not collapse to the base policy. The reported gains come without additional human supervision or an external stronger teacher model.
- Theme: (1) core LLM advances — fine-tuning / self-improvement.
- Relevance: A practical angle on continual post-training that complements RLAIF-style pipelines and is directly applicable to coding-model specialization.

## 9. Moving Generality from Model to Modeler: LLM Agents for PHM on a Deployment-Style Benchmark
- Authors: Zhenling Chen, Zhiguo Zeng, Anne Barros.
- arXiv: 2611.25252 — https://arxiv.org/abs/2611.25252
- Summary: The paper evaluates LLM-powered coding agents that build prognostics-and-health-management (PHM) models for unseen equipment from raw data, finding that the strongest driver of performance is how aggressively the agent explores and learns from the data itself, rather than the richness of a prebuilt toolkit. In other words, generality shifts from the model to the modeler.
- Theme: (1) core LLM advances — agentic coding evaluation.
- Relevance: A deployment-style, end-to-end coding-agent benchmark on a non-toy problem, with a clean takeaway for how to design agent harnesses.

## 10. Language Models Can Rewrite Their Own Weights
- Authors: Listed on arXiv page.
- arXiv: 2611.21885 — https://arxiv.org/abs/2611.21885
- Summary: The paper explores LLMs that programmatically edit their own weight matrices as part of inference, treating weight space as a first-class output of the model rather than only an artifact of training. Experiments probe when self-edits improve downstream performance versus when they destabilize the base model.
- Theme: (1) core LLM advances — PEFT / self-modification.
- Relevance: Expands the PEFT design space; the mechanism it studies is a potential primitive for agents that need to persistently adapt to a task.
