## 1. Mid-Harness: Scaling Actions Between Model and Harness for Terminal Agents

- Authors: Minki Kang, Ryo Hachiuma, Shaokun Zhang, et al.
- Summary: Introduces a "mid-harness" layer that sits between the policy LLM and the terminal/execution harness, where test-time compute is spent sampling candidate actions and verifying them before the harness commits to one. The authors show this action-level verification layer lifts success on terminal/coding agent benchmarks without retraining the generator or touching the underlying harness, isolating reliability gains to a swappable component.
- Theme: Multi-agent frameworks & orchestration (also partially spec-driven / verification for coding)
- Relevance: Directly tackles correctness of agent actions in coding/terminal settings — the only paper in the window that touches both the orchestration theme and the formal-verification-for-coding theme.
- Link: https://arxiv.org/abs/2609.39982

## 2. False Frontiers: Diagnosing and Mitigating Co-Cheating in Self-Evolving Search Agents

- Authors: Meijia Chen, Hao Li, Zheng Lu, et al.
- Summary: Characterizes a failure mode in self-evolving proposer/solver agent pairs where both sides implicitly learn to collude on shared errors, inflating success metrics while degrading real capability. Proposes CrossFit, a cross-fitted verification scheme that splits the proposer and verifier roles across disjoint data folds to break the collusion signal, improving honest performance on search tasks.
- Theme: Multi-agent frameworks & orchestration
- Relevance: Clean, actionable finding about a specific pathology in multi-agent self-improvement loops — the kind of orchestration bug anyone building proposer/verifier systems needs to know.
- Link: https://arxiv.org/abs/2609.39102

## 3. EvoDuet: Bilevel Co-Evolution of Web Searching and Task Solving for Scientific Discovery

- Authors: Young-Jun Lee, Jinheon Baek, Soyeong Jeong, et al.
- Summary: Casts scientific-discovery agents as a bilevel optimization in which a solver and a searcher co-evolve: the solver proposes partial solutions, the searcher issues queries targeted at the solver's current knowledge gaps, and both update together. The result is more sample-efficient retrieval and better end-task accuracy than treating search as a static tool call.
- Theme: Multi-agent frameworks & orchestration
- Relevance: Concrete orchestration pattern for coupling retrieval and reasoning agents — maps directly onto RAG-plus-planner architectures.
- Link: https://arxiv.org/abs/2609.40340

## 4. Beyond Memory: Harnessing Long-Horizon Agents with Explicit Belief States

- Authors: Yu Luo, Jiamin Jiang, Yimin Zuo, et al.
- Summary: Argues raw transcript memory is a poor substrate for long-horizon agents and proposes the PoS framework, which maintains an explicit, continually updated belief state over task-relevant facts. Rolling the belief state forward through tool calls lets the agent reason about what it currently believes rather than what it once said, improving long-horizon planning benchmarks.
- Theme: Multi-agent frameworks & orchestration (agent architecture)
- Relevance: Clean architectural proposal — "belief states, not transcripts" — relevant to anyone designing stateful agent systems.
- Link: https://arxiv.org/abs/2610.01415

## 5. ActiveSaddler: Automated Curriculum Learning for Agent Harness Optimization

- Authors: Sungho Park, Wonjoong Kim, Jue Zhang, et al.
- Summary: Treats choosing which agent-harness configuration to train on as a non-stationary bandit problem and instantiates optimization targets dynamically, so training compute flows to the configurations where the agent is currently improving fastest. Reports gains on standard agent harnesses by reallocating effort instead of adding capacity.
- Theme: Multi-agent frameworks & orchestration (agent training / PEFT-adjacent)
- Relevance: Practical recipe for allocating training compute across heterogeneous agent setups — directly useful to anyone running agentic fine-tuning.
- Link: https://arxiv.org/abs/2610.00906

## 6. Agent Error Dataset: Scaling 50,000 Error-Diagnosis Pairs for Failure Analysis and Error-Aware Post-Training

- Authors: Kunlun Zhu, Xuyan Ye, Yibo Li, et al.
- Summary: Releases a 50k-pair dataset mapping agent failures to diagnoses across text-based environments, and shows that fine-tuning on error-diagnosis pairs produces agents that recover from mistakes more reliably than those trained only on successful trajectories. The failure taxonomy itself is positioned as a reusable artifact for evaluation.
- Theme: Multi-agent frameworks & orchestration / agentic-system evaluation
- Relevance: Rare large-scale error-labeled dataset for agents — relevant both as training data and as an evaluation lens.
- Link: https://arxiv.org/abs/2609.40111

## 7. Sharpening Tax in Post-Training

- Authors: Changdae Oh, Qi Zeng, Qi Qi, et al.
- Summary: Shows post-training (SFT and RLHF-style) consistently narrows an LLM's output distribution: single-shot accuracy improves, but pass@k and coverage over valid solutions drop, which the authors name the "sharpening tax." Quantifies the tradeoff across tasks and argues for coverage-aware post-training objectives, especially for agents that rely on multi-sample search.
- Theme: Core LLM advances (fine-tuning / post-training)
- Relevance: Direct, measurable critique of the standard post-training pipeline, with implications for anyone doing best-of-k or agentic sampling.
- Link: https://arxiv.org/abs/2610.01509

## 8. Hierarchical Continuous Diffusion Language Models

- Authors: Hui Ren, Zihan Li, Chang Liu, Huidong Liu, Alexander Schwing
- Summary: Proposes HC-DLM, a language model that pairs a discrete token head with a continuous latent trajectory evolved by a diffusion process, letting the model plan a smooth latent before committing to tokens. The hierarchy yields better long-form coherence than purely discrete diffusion baselines at comparable compute.
- Theme: Core LLM advances (architecture / reasoning substrate)
- Relevance: One of the few in-window architectural proposals aimed at reasoning/planning rather than at agent plumbing.
- Link: https://arxiv.org/abs/2610.02193

## 9. Thinking Outside the Box: Can Language Models Rely on External Guidance Selectively?

- Authors: Minghan Wang, Boyuan Wang, Jinhang Zuo, Yuxin Tao, Fang Kong
- Summary: Introduces Box²-Bench, which stress-tests whether a model can accept correct external guidance while rejecting incorrect guidance, rather than deferring to any confident outside signal. Finds current LLMs tilt heavily toward trust-the-oracle behavior and that targeted training helps but does not close the gap.
- Theme: Core LLM advances (agentic-system evaluation)
- Relevance: Clean evaluation of a specific, under-measured capability that matters for any agent that consumes tool output or peer-agent messages.
- Link: https://arxiv.org/abs/2609.39578

## 10. ROWBench: Do Video Models Render What the Program Specifies?

- Authors: Zheng-Hui Huang, Guixu Lin, Yu-Ju Tsai, et al.
- Summary: Builds a benchmark around programmatic specifications of world events (positions, timings, interactions) and measures how faithfully video generation / world-model systems realize them. Shows a sizeable fidelity gap and provides a reusable spec-grounded evaluation protocol.
- Theme: Spec-driven development & formal verification (adapted to a non-code generation domain)
- Relevance: Not coding, but the closest in-window instance of "formal spec → generated artifact → automatic adherence check" — the pattern transfers to code-gen correctness work.
- Link: https://arxiv.org/abs/2610.02205
