## 1. SWE-Bench ProMax: Benchmarking Agents on Large-Scale Multilingual Code Refactoring
Authors: Yuling Shi, Jinghan Xu, Kelin Fu, et al.

An expert-curated benchmark that stresses coding agents on multi-file refactoring across seven programming languages, going beyond the typical "fix-one-bug" SWE-bench setup. Each task pairs a repository state with a target semantic-preserving transformation, and correctness is graded against language-specific test suites and type/build checks so agents cannot pass by localised patching. Reported leaderboard results show a large unsolved margin for frontier agents, especially on non-Python targets where refactors must respect module boundaries and static typing.
- Theme: (3) Spec-driven development / formal verification for coding-agent correctness
- Relevance note: Closest match to theme 3 in the window — treats correctness of coding-agent output as a graded, cross-language contract rather than a pass@1 sample.
- Link: https://arxiv.org/abs/2608.09802

## 2. Evo-Bench: Can Language Models Improve Agent Harness?
Authors: Lisheng Huang, Chen Yang, Hao Zhou, et al.

Introduces the first benchmark that measures whether an LLM can rewrite and evolve the surrounding agent harness (prompts, tool schemas, control-flow scaffolding) rather than only solve tasks within a fixed harness. Tasks are constructed with sensitivity analysis so that harness-level edits are the dominant lever on outcome, isolating the "self-improvement" signal from base-model capability. Results show large domain dependence: harness evolution helps substantially in tool-heavy domains, but degrades performance in tightly-specified reasoning tasks where the shipped harness is already near-optimal.
- Theme: (2) Multi-agent frameworks & orchestration
- Relevance note: Directly targets the "harness/orchestration is the object of study" gap that agent-eval work usually elides.
- Link: https://arxiv.org/abs/2608.09096

## 3. SkillZip: Evaluation-Free Skill Compression for Self-Evolving Agents by Discovering Reusable Structure
Authors: Xiaofan Bai, Hongqiang Lin, Chao Liu, et al.

Proposes a compression step for the skill libraries that self-evolving agents accumulate, framed as searching for the minimal structural program that explains observed skill traces while preserving rare exceptions. Because the objective is a description-length criterion over the trace set, the method does not require rolling out each skill for evaluation — a substantial cost win over prune-by-benchmark approaches. Empirically the compressed libraries maintain task success while cutting retrieval and prompt-context overhead.
- Theme: (2) Multi-agent frameworks & orchestration
- Relevance note: A practical answer to the long-standing "skill bloat" problem in evolving agent architectures.
- Link: https://arxiv.org/abs/2608.11079

## 4. VibeLifeBench: Can Your Life Agent Be Proactive and Persistent in a Living World?
Authors: Xiaohongshu Inc.

A 200-task benchmark spanning 10 everyday domains inside a persistent simulated world, designed so that the agent must both react to user requests and act proactively across long horizons (days of simulated time). Scoring separates "did the right thing eventually", "did it at the right time", and "did not create side effects", which forces evaluation of persistence and restraint rather than only completion. The paper reports current frontier models sitting well below human performance, with the largest gaps on proactive scheduling and multi-day follow-through.
- Theme: (2) Multi-agent frameworks & orchestration (agentic-system evaluation)
- Relevance note: One of the first benchmarks that grades an agent on when-not-to-act and long-horizon persistence, not just task completion.
- Link: https://arxiv.org/abs/2608.10875

## 5. ComBodied Agents: a New Paradigm of Human-Centric Agentic AI
Authors: Qianggang Ding, Xingyao Wang, Rui Feng, et al.

Argues for a framework in which digital tools (LLM/agent stack) and embodied tools (sensors, wearables, actuators) are wired into a single closed loop that tracks an individual user's state trajectory over time. The paper formalises a consent-aware update rule so that the shared world-model between the agent and the user is only mutated on explicit human sign-off, and shows the architecture on health-monitoring and coaching use cases. It is more of a design-space paper than a benchmark, but the closed-loop specification is unusually concrete.
- Theme: (2) Multi-agent frameworks & orchestration
- Relevance note: Positions consent and per-user state as first-class parts of the agent architecture — a useful contrast to shared-memory multi-agent designs.
- Link: https://arxiv.org/abs/2608.10915

## 6. InSight-doc: Agentic Visual Perception for Long-Document Understanding
Authors: Kaican Li, Weiyan Xie, Lewei Yao, et al.

Treats long-document QA as an agentic loop where a visual perceiver dynamically re-samples page regions at different resolutions in response to the reasoning trace, rather than encoding the whole document at a fixed grid. The system reports both accuracy gains and end-to-end latency reductions on multi-hundred-page inputs, and attributes the accuracy gain specifically to fewer hallucinations on layout-heavy pages (tables, figures with captions). The perceiver-reasoner split is a reusable pattern for other agentic-perception settings.
- Theme: (2) Multi-agent frameworks & orchestration (perception-reasoning agent architecture)
- Relevance note: Clean example of adaptive tool-invocation inside an agent loop, with reported wins on both cost and correctness.
- Link: https://arxiv.org/abs/2608.10628

## 7. BDH-CQ: In-Context Learning with Recurrent Latent Reasoning
Authors: Björn Engdahl, Adrian Kosowski, Jan Chorowski, et al.

Combines in-context learning with a recurrent latent-reasoning loop: instead of emitting more chain-of-thought tokens, the model iterates a compressed latent state a variable number of times before decoding an answer. The design keeps token cost roughly flat while trading latency for accuracy, and is reported to be competitive on ARC-AGI-1 at substantially lower total token budgets than long-CoT baselines. It sits in the current wave of "test-time compute in latent space, not token space" reasoning methods.
- Theme: (1) Core LLM advances — reasoning
- Relevance note: Explicit ablation of latent-loop depth vs. token-CoT length is the kind of evidence this literature has been missing.
- Link: https://arxiv.org/abs/2608.09888

## 8. Macaron-V1: Towards Open Continual Learning with Self-Improvement and Mixture-of-LoRA
Authors: Mind Lab, Vin Bo, Asher Cai, et al.

Releases an open agent-model family that continually acquires new task capabilities via a Mixture-of-LoRA architecture: each new skill is trained as an isolated LoRA adapter, and a learned router selects and composes adapters at inference. The recursive self-improvement loop uses the deployed model to generate and grade its own training data for new adapters, avoiding catastrophic forgetting of shipped skills. Weights and adapter routing are released, which makes it a useful base for downstream PEFT/continual-learning work.
- Theme: (1) Core LLM advances — fine-tuning / PEFT
- Relevance note: Concrete open reference for adapter-mixture continual learning, not just an ablation on top of a closed base.
- Link: https://arxiv.org/abs/2608.09819

## 9. Motif 3: Technical Report
Authors: Junghwan Lim, Joon Son Chung, Sungmin Lee, et al.

Technical report for a large sparse mixture-of-experts LLM built around "grouped differential latent attention" — an attention variant that keeps a shared low-rank base and per-group differential deltas, targeting long-context reasoning and code. The report details the training curriculum for reasoning, coding, and long-context together, and the ablations argue the latent-attention change is what unlocks stable scaling of the MoE past their prior generation. Benchmark numbers position it competitively against contemporary open MoE releases.
- Theme: (1) Core LLM advances — model architecture
- Relevance note: Substantive technical report from an open MoE release, with an architecture change (differential latent attention) worth tracking beyond this one model.
- Link: https://arxiv.org/abs/2608.09119

## 10. Reference-Free Post-Training of Open Large Language Models for Multilingual Machine Translation
Authors: Chris Han, Pengzhi Gao, Pei Fu, Jian Luan.

Applies group relative policy optimization (GRPO) to multilingual translation with reference-free reward signals — combining a quality-estimation model, a language-identification check, and a self-consistency term — so that gold translations are not required during post-training. The resulting open model is reported to match or exceed several proprietary baselines on standard MT test sets across languages where reference data is scarce. The recipe is a compact worked example of reference-free RL fine-tuning that transfers beyond translation.
- Theme: (1) Core LLM advances — fine-tuning
- Relevance note: Clean case study of GRPO with composed reference-free rewards; the recipe is directly borrowable for other generation tasks lacking gold labels.
- Link: https://arxiv.org/abs/2608.10812
