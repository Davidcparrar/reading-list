# Reading digest — 2026-08-25

Found 10 paper(s) in the last 48h window.

1. **Prime Agent: A Self-Improving RLM Harness**
   - Authors: Seth Karten, Alex L. Zhang, Kevin Thomas, et al.
   - Summary: Introduces an open-source harness for reasoning language models that combines a persistent IPython REPL, recursive subagents, and cross-episode memory so a base model can iteratively rewrite its own scaffolding. The authors report climbing ARC-AGI-3 performance from 30% to 95.5% by letting the harness itself become the target of improvement, effectively decoupling long-horizon capability from base-model weights.
   - Theme: Core LLM advances (agentic-system evaluation)
   - Relevance: Direct, measurable long-horizon-agent evaluation with a large delta from a simple architectural change — the kind of eval-plus-method paper the digest targets.
   - Link: https://arxiv.org/abs/2608.23552

2. **Apodex 1.1: Scaling Agentic Intelligence for Complex Work**
   - Authors: Apodex Team, B. An, B. Li, et al.
   - Summary: A large-team system report on scaling an agent stack for sustained, verifiable progress on professional workloads by co-scaling training environments and orchestration primitives rather than model size alone. The paper frames "environment scaling" as a first-class axis alongside data and parameters, and reports gains on multi-turn, multi-tool tasks across several professional domains.
   - Theme: Multi-agent frameworks & orchestration
   - Relevance: One of the few concrete recipes for coordinating agents at production scale, with explicit design choices for role and tool assignment.
   - Link: https://arxiv.org/abs/2608.23283

3. **The Interaction Tax: When Communication Erases Diversity in Multi-Agent Teams**
   - Authors: Summer Eunhyung Ann, Haokun Liu, Chenhao Tan
   - Summary: Empirically shows that when agents exchange full candidate solutions, their proposals converge and the ensemble collapses to a single mode — an "interaction tax" that wipes out the very diversity multi-agent systems are supposed to exploit. Independent generation followed by late aggregation preserves diversity better than richer collaborative protocols, questioning the default "just let the agents talk" pattern.
   - Theme: Multi-agent frameworks & orchestration (communication protocols)
   - Relevance: A cs.MA paper that directly challenges a common design assumption in multi-agent orchestration; changes what a well-designed coordination protocol should look like.
   - Link: https://arxiv.org/abs/2608.23541

4. **SWE Refactor Bench: Can Coding Agents Complete a Long-Horizon, Whole-Repository Stack Migration?**
   - Authors: Deyao Hong, Yizhe Chi, Wenyi Li
   - Summary: A benchmark of 520 whole-repository stack-migration tasks that scores agents on both completing the migration and preserving behavior, with an explicit specification of "correct" behavior via test-based oracles. Only 5.4% of runs passed every evaluation stage, exposing that current coding agents can look complete without meeting the migration's behavioral spec.
   - Theme: Spec-driven development & formal correctness of coding agents
   - Relevance: Directly targets spec-driven evaluation for coding agents at a scale (whole-repo, long-horizon) that most SWE benchmarks avoid.
   - Link: https://arxiv.org/abs/2608.23564

5. **SRPO: Self-Reflective Policy Optimization for Long-Horizon Reasoning**
   - Authors: Jialong Liu, Yuling Shi, Ning Yang
   - Summary: Introduces a policy-optimization loop in which the model reads its own failed trajectories, distills them into short "reflection patches," and then uses those patches as auxiliary conditioning for the next rollout batch. Reports 73.3% on AIME using roughly 8% of the FLOPs a comparable supervised fine-tune consumes, suggesting reflection-as-training-signal is a cheaper path to long-horizon reasoning than more data.
   - Theme: Core LLM advances (reasoning, fine-tuning)
   - Relevance: Concrete recipe for pushing long-horizon reasoning without scaling data; the FLOPs claim, if it holds, is a notable efficiency result.
   - Link: https://arxiv.org/abs/2608.23493

6. **MobilePA-Bench: Benchmarking Mobile Planner Agents on Complex Real-World Tasks**
   - Authors: Yi Zhu, Xiongwei Wu, Qiyi Wang, et al.
   - Summary: An interactive Android sandbox that scores mobile planner agents on tool-calling, sub-agent handoffs, and memory reuse under real device-runtime constraints (background app kills, network drops, permission prompts). Tasks are constructed so a single agent has to hand work to specialized sub-agents, letting the benchmark separate planning skill from orchestration skill.
   - Theme: Multi-agent frameworks & orchestration (evaluation)
   - Relevance: One of the first mobile-agent benchmarks to explicitly score sub-agent collaboration, which is where most existing GUI-agent evals stop short.
   - Link: https://arxiv.org/abs/2608.23035

7. **When "Do Not" Is Not Deny: Security Rules in CLAUDE.md vs Built-In Controls**
   - Authors: Ting Yan
   - Summary: Audits how security rules that developers write into CLAUDE.md (and similar agent-config files) actually map to the sandbox's enforced controls, and finds only 4–16% of prose rules correspond to a real deny primitive. The paper argues that natural-language "spec" files give a false sense of correctness because the runtime never checks them, and proposes rewriting a rule surface that is machine-verifiable.
   - Theme: Spec-driven development & formal verification for coding agents
   - Relevance: Concrete case study of spec-vs-enforcement drift in a coding-agent config, and a template for what a verifiable agent-security spec would need.
   - Link: https://arxiv.org/abs/2608.23550

8. **StrategyBench: Evaluating Explicit Strategy Induction in LLMs**
   - Authors: Jinghan Tan, Yuanzheng Wang, Lu Chen
   - Summary: A benchmark that separates two skills usually conflated in reasoning evaluation: extracting an explicit rule from worked examples, and then executing that rule on a fresh input. Findings show large gaps between induction and execution quality across categories, meaning models that appear to "reason" may only be memorizing solution shapes.
   - Theme: Core LLM advances (reasoning, agentic-system evaluation)
   - Relevance: Sharp diagnostic for whether LLM reasoning is genuine rule induction or pattern completion — directly useful when picking base models for planners.
   - Link: https://arxiv.org/abs/2608.23475

9. **How to Train a Critic Stably and Efficiently**
   - Authors: Penghui Qi, Xiangxin Zhou, Wee Sun Lee
   - Summary: Diagnoses common instabilities in critic-based RL for LLM reasoning and proposes Best-Practice Critic Optimization (BPCO), which combines DPPO-style updates, bounded value predictions, Monte Carlo return targets, and adaptive advantage estimation. The recipe stabilizes critic training on math-reasoning tasks where earlier critic setups either diverge or under-train.
   - Theme: Core LLM advances (reasoning, fine-tuning)
   - Relevance: A practical, drop-in stabilization recipe for the critic side of RL-for-reasoning pipelines, which is the failure mode most teams hit first.
   - Link: https://arxiv.org/abs/2608.23566

10. **Beyond the Stability-Exploration Dilemma: Environmental Regularization for LLM Policy Optimization**
    - Authors: Xianlei Zhou, Xiangdi Meng, Yu He, et al.
    - Summary: Argues the "keep policy close to reference" KL term in RLHF-style training over-constrains outputs while under-constraining the shift in the training input distribution, and introduces ERPO — a query-level KL that pins prompt distribution while leaving response exploration free. Reports better exploration without the usual reward-model collapse.
    - Theme: Core LLM advances (fine-tuning / policy optimization)
    - Relevance: A clean reframing of what the KL regularizer in policy optimization should actually protect, with a small enough change to plug into existing PPO/GRPO stacks.
    - Link: https://arxiv.org/abs/2608.23311
