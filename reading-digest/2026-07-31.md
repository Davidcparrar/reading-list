## 1. Metis: Memory Foundation Model
- **Authors:** Zeyu Zhang, Ziliang Guo, Yihang Sun, et al.
- **Summary:** Metis proposes a standalone "memory foundation model" that treats memory as a first-class, persistent state maintained outside a language model's context window, learned during pretraining and updated online without gradient steps. Rather than bolting retrieval onto an LLM, it exposes read/write primitives so downstream agents can store, retrieve, and consolidate information autonomously, and the paper argues this yields more coherent long-horizon behaviour than RAG or KV-cache tricks alone.
- **Theme:** Memory for LLMs and agents.
- **Relevance:** Directly frames memory as its own foundation model — a strong candidate for shaping how agents in the reading list handle persistent knowledge.
- **Link:** https://arxiv.org/abs/2607.26760

## 2. Memory Decoder at Scale: A Pretrained, Parametric Long-Term Memory
- **Authors:** Rubin Wei, Jiaqi Cao, Jiarui Wang, et al.
- **Summary:** Scales a plug-in "memory decoder" module to 6.9B parameters that is pretrained separately and attached to a frozen base LM to act as parametric long-term memory. The authors build a distributed Faiss pipeline for construction and show that spending compute on the memory module (rather than the base model) is a more efficient way to trade parameters for downstream accuracy.
- **Theme:** Memory for LLMs and agents.
- **Relevance:** A scaling-law-style study of parametric memory that complements retrieval-based approaches; useful design point for anyone building memory subsystems.
- **Link:** https://arxiv.org/abs/2607.27919

## 3. MemHarness: Memory Is Reconstructed, Not Replayed
- **Authors:** Rong Wu, Daocheng Fu, Licheng Wen, et al.
- **Summary:** Argues that agent memory should be actively reconstructed for the current task rather than blindly replayed, and trains a single policy model to both critique past traces and rewrite them into task-relevant context. On out-of-distribution agent benchmarks it beats verbatim-replay and RAG-style memory baselines, especially when the retrieved traces are noisy or partially wrong.
- **Theme:** Memory for LLMs and agents.
- **Relevance:** Directly targets the failure mode where "just show the LLM its history" hurts more than it helps — a common issue in long-running agent stacks.
- **Link:** https://arxiv.org/abs/2607.28272

## 4. Voice Memory for Agentic Speech Recognition
- **Authors:** Chao-Han Huck Yang, Zih-Ching Chen, Piotr Zelasko, et al.
- **Summary:** Introduces an inference-only "voice memory" that stores per-domain acoustic and lexical evidence and lets a frozen corrector agent look it up when repairing ASR hypotheses. The scheme cuts over-correction from ~64% to ~35% without touching the underlying speech model, illustrating an agentic memory pattern that generalises beyond text-only LLMs.
- **Theme:** Memory for LLMs and agents.
- **Relevance:** Concrete, tool-shaped example of episodic domain memory attached to a corrector agent — a template for augmenting other frozen models with retrievable state.
- **Link:** https://arxiv.org/abs/2607.26410

## 5. Frontis-MA1: Training an AI4AI Model towards Recursive Self-Improvement in Machine Learning Engineering
- **Authors:** Junlin Yang, Che Jiang, Yu Fu, et al.
- **Summary:** Post-trains a 35B "meta-evolution" agent that orchestrates atomic ML-engineering operators (edit, run, evaluate, refactor) inside a long-horizon search loop with execution feedback. The system iteratively improves its own ML pipelines, and the authors report measurable gains on ML-engineering benchmarks over prior single-shot code agents, positioning it as an early recursive-self-improvement result.
- **Theme:** Multi-agent frameworks & orchestration.
- **Relevance:** Concrete architecture for role/tool assignment inside a self-improving agent — informative for reading-list projects that coordinate multiple ML-engineering roles.
- **Link:** https://arxiv.org/abs/2607.28568

## 6. Qwen-UI-Agent Technical Report: Toward Next-Generation Real-World Centric Foundation GUI Agents
- **Authors:** Hanzhang Zhou, Panrong Tong, Xu Zhang, et al.
- **Summary:** Presents Qwen-UI-Agent, a foundation GUI agent that operates across mobile, desktop, and web with a single unified action space and is trained with online RL on real interfaces. A key contribution is an "AutoResearch"-style data flywheel that lets the agent collect new trajectories, self-evaluate, and improve without a fresh human labelling pass.
- **Theme:** Multi-agent frameworks & orchestration.
- **Relevance:** Full-stack view of a real-world agent (action schema + training loop + data flywheel), directly relevant to orchestration and long-lived agent architectures.
- **Link:** https://arxiv.org/abs/2607.28227

## 7. SkillRise: Agentic Reinforcement Learning for Cross-Task Skill Evolution
- **Authors:** Zhiyuan Yao, Yuxin Chen, Zhengxi Lu, et al.
- **Summary:** SkillRise casts skills as reusable, documented sub-policies and uses agentic RL to grow, prune, and share them across tasks such as ALFWorld, WebShop, and ScienceWorld. The curated "skill documents" act as an explicit, human-readable skill library, giving 2.3–8.5 point gains and offering a middle ground between monolithic policies and tool-call libraries.
- **Theme:** Multi-agent frameworks & orchestration.
- **Relevance:** Directly addresses coordination + role-specialisation across tasks — a scalable pattern for growing an agent's capability surface over time.
- **Link:** https://arxiv.org/abs/2607.26784

## 8. SpecFirst: Behavioral Specification Elicitation as a First-Class Step in Agent-Based Program Synthesis from Scratch
- **Authors:** Yihao Chen, Shi Chang, Feng Lin, et al.
- **Summary:** Splits program synthesis into a dedicated "spec agent" that first elicits behavioural specifications and a downstream coder agent that implements against them, formalising a communication protocol between the two roles. Adding this stage lifts test pass rates by 6.9–21.3% versus single-agent baselines on program-synthesis benchmarks.
- **Theme:** Multi-agent frameworks & orchestration.
- **Relevance:** Clean example of role decomposition (spec vs. code) with a measurable win — informative for any multi-agent pipeline that currently conflates planning and execution.
- **Link:** https://arxiv.org/abs/2607.27167

## 9. CoRT: Counterfactual Replay for Token-Level Rubric-Guided Policy Optimization
- **Authors:** Bo-Wen Zhang, Junwei He, Wen Wang, et al.
- **Summary:** Introduces CoRT, which uses counterfactual replays of a rubric to attribute reward at the token level and redistribute GRPO advantages away from response-level averaging. The approach yields sharper credit assignment during RL fine-tuning and is reported to outperform response-level GRPO on reasoning and instruction-following benchmarks.
- **Theme:** Core LLM advances (reasoning, RL fine-tuning).
- **Relevance:** Practical, drop-in improvement over GRPO with clear implications for how we PEFT/RL-tune reasoning models.
- **Link:** https://arxiv.org/abs/2607.25659

## 10. Flux-OPD: On-Policy Distillation with Evolving Contexts
- **Authors:** Yuran Wang, Zekun Wang, Bohan Zeng, et al.
- **Summary:** Proposes an on-policy distillation recipe where the teacher supervises the student under contexts that evolve during training and where conflicting corrections are down-weighted by a geometric-mean loss. This lets a compact student capture task preferences in open-ended domains without collapsing to any single teacher trajectory.
- **Theme:** Core LLM advances (distillation / fine-tuning).
- **Relevance:** Directly addresses the "which teacher signal do I actually trust" problem that dogs open-ended distillation, useful for downstream agent-model training.
- **Link:** https://arxiv.org/abs/2607.28022
