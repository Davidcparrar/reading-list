## 1. CoworkOS: Scaling Agent Coworkers for Real-world Automation

- **Authors:** Jiajie Jin, Guanting Dong, Chengjun Pan, et al.
- **Summary:** CoworkOS proposes a three-layer harness for long-horizon "coworker" agents that keeps strategy on the model and state/feedback on a runtime, with sync and async delegation to subagents and shared editable artifacts (docs, slides, CAD, Blender scenes) that both humans and agents can touch. Hierarchical workspaces plus persistent semantic memory let sessions be interrupted and resumed, and the paper reports parity with Codex and the DeepSeek harness across 12 benchmarks; a self-driven case study used GLM-5.3 to recursively post-train Qwen3.6-35B-A3B from 33.19 to 42.95 average over five rounds.
- **Theme:** Multi-agent frameworks & orchestration.
- **Relevance note:** Direct hit on multi-agent coordination with persistent memory, with real benchmarks against named frontier harnesses rather than a position piece.
- **Link:** https://arxiv.org/abs/2611.03178

## 2. Measuring AI Agents as Teammates with Collaborative Intelligence

- **Authors:** Sean Wu, Aneesh Pappu, Jiaru Zou, et al.
- **Summary:** The Collaborative Intelligence Benchmark introduces 240 tasks (160 public, 80 held-out) across eight dimensions of teamwork — refusing unsafe shortcuts, reporting misconduct, handling conflict, recovering a cheating teammate's work, etc. — each with code-verifiable outcomes, and only scores a model on tasks it can already solve alone so teamwork is isolated from raw ability. Across 18 closed- and open-weight models every system had visible weaknesses: the top score was 82.2/100, frontier models yielded under pressure in 86% of conflicts, and takeover pass rate dropped from 97% to 81% when the prior agent had cheated.
- **Theme:** Multi-agent frameworks & orchestration (agentic-system evaluation).
- **Relevance note:** Rare benchmark that treats collaboration — not just task completion — as the capability under test, with held-out tasks for honest evaluation.
- **Link:** https://arxiv.org/abs/2611.02633

## 3. CrossSWE: Benchmarking Cross-Repository Joint Development for Coding Agents

- **Authors:** Silin Chen, Yuling Shi, Heng Lian, et al.
- **Summary:** CrossSWE is a 171-instance benchmark across 165 repositories, 20 technical domains and 13 programming languages where each task requires coordinated changes across multiple interdependent repos; partial per-repo edits are explicitly shown to be insufficient. Across five LLMs the strongest (GPT-6.1 Sol) reached 58.48% Pass@1, and cross-repository inconsistency accounted for 44.2% of its failures, highlighting dependency reasoning and interface consistency — classic spec-adherence problems — as the current ceiling.
- **Theme:** Spec-driven development & correctness for coding agents.
- **Relevance note:** The closest thing this window has to spec-driven coding research: real-world cross-repo correctness explicitly treated as an interface/consistency problem.
- **Link:** https://arxiv.org/abs/2611.01484

## 4. Can Coding Agents Sustain Continual Evolution without Forgetting?

- **Authors:** Shangziqi Zhao, Yitong Zhang, Jia Li
- **Summary:** The authors route SWE-Bench, SWT-Bench and FeatureBench into six evolution orders and run two existing harness-evolution methods (AHE and Meta-Harness) across them, finding that evolving on a later task severely degrades earlier task performance — e.g., DeepSeek-V4-Flash-0731 with Meta-Harness drops from 94.0% to 32.0% on SWE-Bench after five rounds of FeatureBench evolution. A manual analysis of 520+ trajectories attributes most pass-to-fail transitions to verification conflicts (submission checks tied to one task's artifact type), followed by workflow conflicts, calling for evolution methods that detect and manage these harness-level contradictions.
- **Theme:** Spec-driven / coding agent correctness and evaluation.
- **Relevance note:** Empirically grounds a correctness failure mode specific to self-evolving coding agents: harness-level verification contracts don't compose across tasks.
- **Link:** https://arxiv.org/abs/2611.03219

## 5. Can Large Language Model Agents Learn by Watching Tutorial Videos?

- **Authors:** Haoyu Zhao, Zafeirios Fountas, Jun Wang
- **Summary:** The paper introduces a parameter-free pipeline that extracts structured, retrievable memory from chess tutorial videos and shows that LLM agents using this memory improve their decision quality over time without any weight updates. The method uses the video stream as the only supervision signal and builds a reusable experience store, which the authors argue is a template for turning passively watched content into agent competence.
- **Theme:** Core LLM advances — agentic learning and memory.
- **Relevance note:** Novel data source (video) for agentic self-improvement with no fine-tuning, directly intersecting the agentic-evaluation thread with memory engineering.
- **Link:** https://arxiv.org/abs/2611.01460

## 6. Library of Layers (LoL): Adaptively Ordering Transformer Layers at Runtime

- **Authors:** Abdellah Rahmani, Sean McLeish, Ang Li, Sanae Lotfi, Pascal Frossard
- **Summary:** LoL is a transformer architecture in which the sequence of blocks applied at inference is chosen dynamically from a shared pool, unifying parameter reuse (layer sharing) and conditional sparsity (block skipping) into a single mechanism. The paper argues that this reframes depth as a routing problem over a learned library and demonstrates compute/quality trade-offs that fixed-order transformers cannot reach.
- **Theme:** Core LLM advances — architectures that affect reasoning depth and compute.
- **Relevance note:** Rare pure-architecture contribution in this window; relevant because reasoning depth and routing are increasingly intertwined.
- **Link:** https://arxiv.org/abs/2611.03526

## 7. CUA-Master: Scaling Computer-use Agents through Open-World Recursive Improvements

- **Authors:** Xinlei Yu, Gen Li, Ji Zhao, Zhangquan Chen, Congcong Wang, et al.
- **Summary:** CUA-Master is a nested recursive-improvement framework that generates computer-use agent training data from open-world sources (sites, apps, documents) and iteratively refines both the task distribution and the trained agent on top of it. The authors position it as a path to scaling computer-use agents without hand-curated task banks and report gains across standard CUA benchmarks.
- **Theme:** Multi-agent frameworks & orchestration / core LLM advances for agents.
- **Relevance note:** Methodological contribution for how CUA training data itself can be bootstrapped — a frontier concern once ability is bounded by data variety.
- **Link:** https://arxiv.org/abs/2611.03126

## 8. NorthCUA Technical Report: Turbocharging Computer-Use Agents through Experience at Scale

- **Authors:** Chaoyun Zhang, Bingxuan Li, Pinxue Guo, Yangfan Gao, Zikun Cai, et al.
- **Summary:** NorthCUA documents an end-to-end, experience-driven RL pipeline for open-source computer-use agents, covering trajectory collection, reward modeling, and training-loop stabilization. The report centers on scaling behavior of experience data and claims strong parity with closed CUA systems on standard benchmarks using an open stack.
- **Theme:** Core LLM advances — RL fine-tuning for agents.
- **Relevance note:** Transparent recipe for RL-based agent training at scale; useful counterpoint to CUA-Master's data-generation angle.
- **Link:** https://arxiv.org/abs/2611.02102

## 9. Avatar Intelligence: Amplifying Human Agency Through Persistent Personal Agents

- **Authors:** Zheng Wu, Xinbei Ma, Yao Yao, Zhaoyuan Huang, Haowen Hu, et al.
- **Summary:** A position paper that argues for "avatar" agents — long-lived personal agents that act on a principal's behalf under delegated authority — and proposes an oversight metric to quantify when control genuinely rests with the human versus the agent. The authors frame open design problems around identity, consent, and memory for such agents and sketch an architecture built on persistent per-user state.
- **Theme:** Multi-agent / agent architecture (position).
- **Relevance note:** Lower rank because it is a position paper, but included because the delegation and oversight framing matters for how multi-agent systems will be evaluated.
- **Link:** https://arxiv.org/abs/2611.03092

## 10. Democratizing Robot-Use Agents: A Unified Harness with Open Models

- **Authors:** Jiarui Yuan, Yuxin Zuo, Xiaoyu Huang, Wenbo Zhang, Kwanyoung Park, et al.
- **Summary:** The paper introduces a unified harness that lets open-weight language models control robot manipulation without privileged simulator inputs, moving the policy burden into the harness (perception adapters, action grammar, replan loops) rather than into a specialized VLA. Open models paired with this harness are reported competitive with closed VLA baselines on manipulation suites.
- **Theme:** Multi-agent frameworks (harness design) with core-LLM relevance.
- **Relevance note:** Harness-centric angle that mirrors CoworkOS and NorthCUA for the embodied setting; useful cross-reference for how much open models can lift when the surrounding system is well engineered.
- **Link:** https://arxiv.org/abs/2611.01560
