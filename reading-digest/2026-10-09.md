# Reading digest — 2026-10-09

Found 10 paper(s) in the last 48h window.

## 1. MiMo-V2.6: Scaling Reinforcement Learning Towards Self-Improvement
- **Authors:** Core Team, Xiaomi (approx. 100 contributors)
- **Summary:** The paper scales RL post-training for an omni-modal LLM by widening the rollout budget, broadening the environment distribution, and sharpening the grader so that the policy keeps improving where prior RLVR recipes plateaued. The authors emphasize three coupled axes — larger batches, more diverse task environments, and higher-fidelity reward judging — and show that each axis independently moves self-improvement past a known compute-efficiency cliff. The release is pitched as a reference RL stack rather than a single checkpoint, with ablations across the trio of axes rather than a tuned headline.
- **Theme:** Core LLM advances (reasoning / RL fine-tuning)
- **Relevance:** A large-lab writeup of what actually scales in post-training RL — directly on-theme for the reasoning/PEFT thread and useful as a reference recipe when choosing between GRPO-family methods.
- **Link:** https://arxiv.org/abs/2610.11959

## 2. AgentGarten: Code Worlds for Evolving Agents
- **Authors:** Jiawei Chi, Shangchen Miao, Zhiyuan Shi, et al.
- **Summary:** AgentGarten builds a programmable "garden" where simulators, game engines, and a shared neural renderer sit behind a single API so agents can be trained in environments that themselves evolve as experience is distilled back into their generators. The framework pairs environment synthesis with experience-conditioned curriculum generation, letting the training surface and the policy co-evolve rather than being fixed up front. The authors argue that this closes a common bottleneck in agentic RL — scarce or stale environments — by turning environment construction into a learnable, parallelizable loop.
- **Theme:** Multi-agent frameworks & orchestration
- **Relevance:** Multi-agent orchestration pushed one layer deeper — the environments themselves are generated and routed to agents by code — which is a novel coordination substrate worth a careful read.
- **Link:** https://arxiv.org/abs/2610.12374

## 3. Learn2Play Bench: How Well Do LLM Agents Learn from Experience in Unfamiliar Environments?
- **Authors:** Yibo Li, Jinhang Qiu, Zhi Zheng, et al.
- **Summary:** Learn2Play is a suite of newly authored text-based games whose rules cannot be inferred from pretraining memorization, so an agent has to actually learn the dynamics through interaction before scoring. Each game ships both a canonical and a mutated variant, which lets the benchmark separate "I have seen this" from "I inferred this" at the per-task level. The results show a sharp gap between in-distribution success and genuine from-scratch rule discovery across current open and closed agents.
- **Theme:** Core LLM advances (agentic-system evaluation)
- **Relevance:** Rare agent benchmark that explicitly guards against training-data leakage by authoring novel games — exactly the diagnostic the agentic-eval thread needs.
- **Link:** https://arxiv.org/abs/2610.08215

## 4. Multi-Agent Egocentric World Model with Fine-Grained Embodied Interaction
- **Authors:** Dahyun Chung, Siyoon Jin, Hyunwook Choi, et al.
- **Summary:** ME-World generates per-agent first-person video streams that remain synchronized across agents inhabiting the same scene, with fine-grained interaction actions (contact, hand-off, mutual gaze) as the conditioning channel. The architecture explicitly factors a shared latent world from each agent's egocentric viewpoint, so one agent's action propagates into the other's rendered observation without re-rolling the entire scene. The authors show that this synchronization survives longer rollouts than independently generated single-agent streams.
- **Theme:** Multi-agent frameworks & orchestration
- **Relevance:** A rare world-model paper where multi-agent coordination is a first-class axis rather than an afterthought — directly relevant for role/action protocols between embodied agents.
- **Link:** https://arxiv.org/abs/2610.12299

## 5. TestPrism: Rethinking Test Evaluation Beyond a Single Reference
- **Authors:** Han Li, Lingxiang Hu, Jiacheng Huang, et al.
- **Summary:** TestPrism argues that scoring a generated test suite against one reference implementation systematically overrates its quality, because a "good" test should fail on plausibly incorrect implementations too, not merely pass on the gold one. The benchmark bundles each problem with a family of valid and invalid implementations and reports a mutation-sensitivity score alongside pass-rate, revealing that many LLM-generated test suites quietly collapse under this harder metric. The result is a sharper empirical lens on whether generated tests actually encode a specification.
- **Theme:** Spec-driven development & correctness for coding
- **Relevance:** Reframes test quality as a specification property (correct-reject + correct-accept) rather than a single-sided match — the paper most directly on the spec/formal-correctness thread this week.
- **Link:** https://arxiv.org/abs/2610.12289

## 6. ViSkill: Reinforcing VLM Agents with Evolving Visual-Native Skills
- **Authors:** Hongxing Li, Dingming Li, Yixin Li, et al.
- **Summary:** ViSkill lets a VLM agent accumulate "visual skill cards" from its own successful trajectories and then condition both inference and reward shaping on retrieved cards during subsequent PPO-style updates. The skill library grows as training proceeds, so the policy effectively bootstraps a visually indexed curriculum of its own prior wins without hand-authored skill ontologies. The authors report that the closed-loop skill-library + RL combination outperforms non-library baselines on the harder visual-reasoning tasks where single-shot policies drift.
- **Theme:** Core LLM advances (RL / planning for agents)
- **Relevance:** Clean implementation of experience-replay-as-skills for VLM agents — a concrete contribution to the PEFT/planning portion of the core-LLM thread.
- **Link:** https://arxiv.org/abs/2610.12403

## 7. SuperNav: An Agentic Navigation System for Any Task in Any Scene
- **Authors:** Jinkai Zhang, Jingyi Xu, Yuanhong Yu, et al.
- **Summary:** SuperNav uses an off-the-shelf multimodal LLM as the decision core and delegates all motion-level reasoning to a small bank of navigation tools, so there is no navigation-specific fine-tuning anywhere in the stack. The LLM selects, parameterizes, and sequences the tools per step, and the authors show that this strict separation of "what to do" (LLM) from "how to move" (tools) generalizes across scene types that a trained-end-to-end policy would overfit. The paper's contribution is really a tool-router recipe demonstrated on navigation, not another navigation model.
- **Theme:** Multi-agent frameworks & orchestration
- **Relevance:** A clean study in LLM-as-orchestrator-over-tools without any task-specific training — a useful datapoint for role/tool assignment in agent architectures.
- **Link:** https://arxiv.org/abs/2610.12126

## 8. OneSearch-VL: Unified Multimodal Deep Research Agent for Image and Video
- **Authors:** Partial list; final authors include Ray Zhang, Shaofei Huang, Tianrui Hui, et al.
- **Summary:** OneSearch-VL formalizes a Visually Grounded Evidence Graph as the state object for a multimodal research agent, so every intermediate claim is anchored to retrievable visual nodes rather than free-text citations. The training stack combines SFT on evidence-traceable trajectories with an RL reward that penalizes claims whose evidence lineage is broken, and the paper ships new benchmarks tuned to that notion of traceability. Reported gains over Qwen3-VL-8B with the same tool access come primarily from the evidence structure, not from a larger model.
- **Theme:** Core LLM advances (agentic reasoning & evaluation)
- **Relevance:** Pushes "cite your evidence" from a prompting pattern into a first-class state and reward signal — a concrete step toward verifiable multimodal research agents.
- **Link:** https://arxiv.org/abs/2610.12419

## 9. USDCraft: Geometrically Grounded Programmatic Modeling of Articulated 3D Assets for Simulation
- **Authors:** Chuanrui Zhang, Zaijia Yang, Duomin Wang, et al.
- **Summary:** USDCraft treats articulated-asset creation as program synthesis: a pretrained LLM writes and iteratively repairs an executable USD program whose output is checked against geometric constraints (joint limits, kinematic consistency, collision) at every step. There is no task-specific fine-tuning; correctness is enforced entirely through the executable grounding of each candidate program against a formal geometry oracle. The authors show the loop produces simulation-ready articulations that off-the-shelf prompting pipelines fail to assemble.
- **Theme:** Spec-driven development & correctness for coding
- **Relevance:** Working example of an LLM coder whose outputs are validated against a formal, executable specification rather than reference-match — directly on the formal-methods-for-code thread.
- **Link:** https://arxiv.org/abs/2610.11322

## 10. RunningTab: Direct Workspace Interaction with Environment-Side Tabs
- **Authors:** Jinheon Baek, Soyeong Jeong, Yumin Choi, Dongsu Han, Sung Ju Hwang
- **Summary:** RunningTab moves task-requirement bookkeeping out of the agent's context window and into an environment-maintained "tab" that records what has been read, what remains to be read, and which requirements are still unmet. The agent then interacts with the tab as if it were a filesystem object, which keeps long-running task state consistent even when the LLM's own context gets rotated. The paper reports fewer dropped requirements and fewer re-reads on long software tasks compared with memory-free and in-context baselines.
- **Theme:** Multi-agent frameworks & orchestration
- **Relevance:** A pragmatic answer to "where should an agent's working state actually live" — externalizes orchestration state in a way that is directly reusable by multi-agent systems.
- **Link:** https://arxiv.org/abs/2610.10444
