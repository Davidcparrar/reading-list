## 1. Thinking Fast, Anywhere: One System-1 for the Decision Points of Any Agent Workflow

- **Authors:** Rui Li, Liyang He, Zheng Zhang, et al.
- **Summary:** AnyS1 locates the recurring "decision points" in an agent workflow using procedural skills, then trains a small 4B model to handle the routine ones directly and route only low-confidence cases to a large model. The hybrid controller is presented as a workflow-level fast/slow split rather than per-token speculative decoding, and the paper reports substantial reductions in cost and latency without accuracy loss.
- **Theme:** Multi-agent frameworks & orchestration
- **Relevance:** Direct contribution to orchestration — a general decision-point protocol that any agent framework can plug a small System-1 into.
- **arXiv:** https://arxiv.org/abs/2611.23751

## 2. Piccolo: Co-Evolving Decision Models and Data through Recursive Self-Improvement

- **Authors:** Zhenqing Ling, Qirui Jiao, Daoyuan Chen, et al.
- **Summary:** Trains a 0.8B–27B family of multimodal decision models through an agent-driven data engineering loop in which model outputs feed back into dataset construction over multiple rounds. The authors report several counterintuitive findings about backbone choice, data curation strategy, and loss formulation under recursive self-improvement.
- **Theme:** Multi-agent frameworks & orchestration
- **Relevance:** A concrete multi-agent co-evolution recipe with scaling evidence — useful reference for closed-loop agent/data pipelines.
- **arXiv:** https://arxiv.org/abs/2611.24651

## 3. Game2Player: Scaling Gameplay Experience for Visual Agents through Environment-Player Co-Development

- **Authors:** Xirui Jiang, Yuxi Chen, Rui Yang, et al.
- **Summary:** A builder agent converts arbitrary web games into verifiable tasks while a player agent attempts them, closing a loop that produces hundreds of games and thousands of gameplay trajectories. The co-development framing makes environments and agents improve together rather than fixing one side.
- **Theme:** Multi-agent frameworks & orchestration
- **Relevance:** Role-specialised agent architecture (builder/player) with explicit verification hooks — a useful pattern for agent training-data flywheels.
- **arXiv:** https://arxiv.org/abs/2611.24154

## 4. PlayCraft: Designing Engaging Games from Agent Play Experience

- **Authors:** Weihao Cheng
- **Summary:** Pairs a vision-based player agent with a crafter agent that iteratively revises the game using the player's play reports, optimising for learning gain and learning-curve slope rather than just completion. Revised games show larger learning gains than the initial versions across multiple trials.
- **Theme:** Multi-agent frameworks & orchestration
- **Relevance:** Compact two-agent orchestration study where the coordination signal is a measurable learning curve — a clean instance of feedback-driven role assignment.
- **arXiv:** https://arxiv.org/abs/2611.26624

## 5. TwinLab-Bench: Evaluating AI Scientists in Agentic Twins of Real Labs

- **Authors:** Yang Wan, Linchao Zhu
- **Summary:** A 52-task benchmark in which an "AI scientist" agent designs experiments that are executed by per-task simulated lab agents, with scoring against hidden real-lab records. The strongest frontier model reaches only ~45 average, and the paper analyses where the failures come from.
- **Theme:** Core LLM advances (agentic-system evaluation)
- **Relevance:** Rigorous evaluation protocol for agent planning — verifiable ground truth derived from real labs rather than LLM-judge heuristics.
- **arXiv:** https://arxiv.org/abs/2611.26248

## 6. AutoMaster: Autonomous Post-Training by Making the Same Model a Better Teacher

- **Authors:** Guoxin Chen, Shuang Sun, Fanzhe Meng, et al.
- **Summary:** Proposes Skill-FT, in which an LLM agent writes natural-language "skills" that steer a teacher model's rollouts before those rollouts are used to fine-tune a smaller target. Reports 1.4–9.0 point gains over vanilla SFT on terminal, search, and software-engineering tasks.
- **Theme:** Core LLM advances (fine-tuning)
- **Relevance:** A post-training recipe that is directly software-engineering-relevant and uses an agent as the curriculum designer.
- **arXiv:** https://arxiv.org/abs/2611.26510

## 7. CurvDelta: Low-Curvature Delta Modeling For Surgical Learning and Unlearning

- **Authors:** Zeguan Xiao, Zhuocheng Liang, Yun Chen, et al.
- **Summary:** Constrains LLM weight updates to a low-curvature subspace of the loss landscape, which lets fine-tuning add or remove specific capabilities with less damage to unrelated behaviour. Ships a low-rank variant, CurvLoRA, that keeps the method practical.
- **Theme:** Core LLM advances (PEFT / fine-tuning)
- **Relevance:** A PEFT variant with explicit targeting + unlearning story — relevant to safely iterating on a tuned agent model.
- **arXiv:** https://arxiv.org/abs/2611.24654

## 8. Suppressing the Shortcut Hidden Behind the Gains of VideoLLM Fine-Tuning (VETO)

- **Authors:** Youngwoo Shin, Jongsuk Kim, Junmo Kim
- **Summary:** Shows that standard SFT on VideoLLMs amplifies a shortcut where the model answers from text regularities, not from the video. VETO projects fine-tuning updates onto the orthogonal complement of the text-only activation subspace, preserving in-distribution gains and improving robustness under distribution shift.
- **Theme:** Core LLM advances (fine-tuning)
- **Relevance:** Transferable technique — "project fine-tuning updates away from the shortcut subspace" is a general pattern beyond video, likely applicable to any multi-modal agent fine-tuning.
- **arXiv:** https://arxiv.org/abs/2611.25776

## 9. Inhabitant: An Agent Framework for Long-Horizon Human-Scene Interaction with Spatial Control and Quantitative Feedback

- **Authors:** Yao Zhang, Zhuchenyang Liu, Yu Xiao
- **Summary:** A training-free LLM agent that plans long-horizon 3D interactions by producing a structured control spec (positions, paths, poses), measures quantitative deviation from intent, and revises the spec in a tight loop. Reaches 98.7% task completion on the Inhabit 75-task benchmark.
- **Theme:** Multi-agent frameworks & orchestration (closest-fit for spec-like feedback loops)
- **Relevance:** Interesting bridge toward Theme 3: the agent emits a structured specification and quantitative deviation is the correctness signal — a spec/feedback pattern that generalises beyond scene interaction.
- **arXiv:** https://arxiv.org/abs/2611.25005

## 10. General progress substitutes for specific training data in language models

- **Authors:** Mark Marosi, Peter Antal
- **Summary:** Empirical study showing that withholding training data for a target skill only delays — never prevents — its emergence, and that the amount of data needed to relearn it shrinks as the model's overall capability grows. Suggests a trade-off in post-training curriculum design.
- **Theme:** Core LLM advances (training / fine-tuning theory)
- **Relevance:** Shapes how one thinks about fine-tuning and data curation for specialised agent capabilities — generic progress is partially fungible with task-specific data.
- **arXiv:** https://arxiv.org/abs/2611.24844
