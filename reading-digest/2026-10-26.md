## 1. On-Policy Self-Training: Data-Free Self-Improvement in Large Language Models

- **Authors:** Leon Sick, Lukas Hoyer, Yannick Strümpler, et al.
- **Summary:** Reframes on-policy self-distillation as a self-training problem: the model
  generates both the questions and the chain-of-thought traces that it then trains on,
  seeded only by high-level topic descriptions rather than a curated corpus. The authors
  report consistent improvements on text and visual QA benchmarks without any human-labeled
  data, suggesting curated datasets may not be a hard prerequisite for continued post-training
  gains.
- **Theme:** Core LLM advances (reasoning + fine-tuning).
- **Relevance note:** From a Google team, directly tackles data-free self-improvement — a
  central question for agentic post-training recipes.
- **Link:** https://arxiv.org/abs/2610.32770

## 2. Where Rounding Happens Matters: Rounding-Location Alignment Stabilizes LLM Reinforcement Learning

- **Authors:** Yijing Ke, Tianle Cai, Ruosong Wang
- **Summary:** Identifies that BF16 reinforcement-learning post-training is destabilized by
  mismatched rounding behavior between training and inference kernels, then proposes aligning
  the rounding locations of selected operations across the two paths. The alignment restores
  stable RL optimization in BF16 without needing to fall back to higher precision.
- **Theme:** Core LLM advances (RL post-training / numerical stability).
- **Relevance note:** A low-level but highly actionable fix for anyone running RLHF/RL-tuning
  pipelines in BF16 — the kind of recipe detail that silently breaks reasoning training.
- **Link:** https://arxiv.org/abs/2610.32951

## 3. Interpretable Sparse Fine-Tuning with TopKLoRA Enables Faithful Circuit Discovery

- **Authors:** Marek Masiak, Andrzej Szablewski, Nicola Cancedda, Constantin Venhoff
- **Summary:** Introduces TopKLoRA, a sparse LoRA variant that constrains adaptation to a
  small set of parameters so the resulting fine-tune can be read back as a circuit. The
  authors show the smaller circuits recovered this way can be surgically ablated to remove
  backdoor behaviors while leaving instruction-following intact.
- **Theme:** Core LLM advances (PEFT + interpretability).
- **Relevance note:** Ties PEFT directly to mechanistic interpretability — useful for defining
  verifiable guarantees over fine-tuned agent components.
- **Link:** https://arxiv.org/abs/2610.32866

## 4. MultiAgent-OPD: End-to-End Training of Hierarchical Multi-Agent Systems with On-Policy Distillation

- **Authors:** Yuhan Sun, Jiaxin Zhao, Yongdong Luo, et al.
- **Summary:** Jointly trains a hierarchical Leader–Searcher–Answerer agent team end-to-end
  by combining on-policy distillation (a frozen teacher supervising intermediate searcher
  steps) with reinforcement learning on the outer objective. Reports gains over strong
  baselines across seven datasets, with process-level teacher signal doing most of the work.
- **Theme:** Multi-agent frameworks & orchestration.
- **Relevance note:** Rare example of training a role-structured multi-agent pipeline as a
  single learned system rather than hand-wiring prompts — directly relevant to orchestration.
- **Link:** https://arxiv.org/abs/2610.23234

## 5. RSIHub: A Composable Framework for Agent-Evolution Methods

- **Authors:** Zimu Wang, Xiaobo Wang, Siyu Ye, et al.
- **Summary:** Open-source framework that factors agent-evolution methods (self-improvement,
  skill libraries, memory, tool synthesis) into interchangeable modules on a shared runtime,
  letting four prior methods be reimplemented without touching the core. Reports head-to-head
  comparisons on Terminal Bench 2 and τ³ Banking under matched conditions.
- **Theme:** Multi-agent frameworks & orchestration.
- **Relevance note:** Infrastructure paper from ByteDance that lowers the cost of comparing
  agent-architecture choices on tool-use benchmarks — practical baseline for new designs.
- **Link:** https://arxiv.org/abs/2610.32253

## 6. J-Comm: Jacobian-Guided Latent Communication between LLM Agents

- **Authors:** Xiangwei Wang, Wei Wang, Sachith Seneviratne, et al.
- **Summary:** Proposes that LLM agents exchange hidden-state messages instead of natural
  language, using Jacobian-derived signals to pick which internal representations to transmit.
  The latent channel preserves more reasoning content than textual summaries while remaining
  cheaper to send.
- **Theme:** Multi-agent frameworks & orchestration (communication protocols).
- **Relevance note:** Concrete alternative to text-based agent protocols — one of the first
  Jacobian-grounded designs for inter-agent messaging.
- **Link:** https://arxiv.org/abs/2610.32871

## 7. UserArena: Benchmarking Interactive User Simulation for Long-Horizon Shopping Agents

- **Authors:** Jujia Zhao, Jiakai Tang, Jing Yu, et al.
- **Summary:** Releases 64,729 real shopping-session trajectories from 11,010 users plus an
  interactive simulation environment, and validates the simulator offline against production
  A/B tests. Introduces On-Policy Trajectory Distillation to keep the simulated user faithful
  across many turns, where prior simulators drift.
- **Theme:** Multi-agent / agentic-system evaluation.
- **Relevance note:** Among the first long-horizon user-sim benchmarks grounded in production
  behavior — directly relevant to agent evaluation beyond single-turn harnesses.
- **Link:** https://arxiv.org/abs/2610.30932

## 8. SemantEq: Faithful Bidirectional Equivalence of Formal Statements

- **Authors:** Xinrui Li, Pawan Sasanka Ammanamanchi, Siddharth Bhat, et al.
- **Summary:** Defines when two Lean statements are "the same spec" by requiring a
  bidirectional rewriting chain through a restricted set of allowed moves, closing a gap
  where prior checks declared trivially-provable statements equivalent. Provides a benchmark
  and reference checker so autoformalization and spec-synthesis systems can be scored
  faithfully.
- **Theme:** Spec-driven development & formal verification.
- **Relevance note:** Fixes a known loophole in evaluating LLM-generated specs — needed
  before claims about spec-driven coding agents can be trusted.
- **Link:** https://arxiv.org/abs/2610.32919

## 9. SCOPE: Compiling Natural-Language Policies into Neurosymbolic Predicate Programs

- **Authors:** (not visible in the listing excerpt; submitter "Eladlev")
- **Summary:** Compiles English policy statements into neurosymbolic predicate programs:
  symbolic structure for the policy's logical skeleton, with learned predicates filling in
  perceptual or linguistic checks. The compiled program is executable and auditable, giving
  a bridge between informal spec text and formally checkable behavior.
- **Theme:** Spec-driven development & formal verification (natural-language → verifiable
  program).
- **Relevance note:** Natural-language-to-formal-program pipelines are exactly the shape
  needed for spec-driven agent coding; this one keeps the compiled artifact inspectable.
- **Link:** https://arxiv.org/abs/2610.31062

## 10. Trusting the Tool: Asymmetric Deference of LLM Vulnerability Auditors to Static-Analysis Evidence

- **Authors:** ZhiHong Liu, Shuyao Gao
- **Summary:** Measures how LLM-based security auditors react to static-analysis output and
  finds they defer much more readily to false reassurances ("no bug here") than to false
  alarms, biasing them toward missing real vulnerabilities. Shows that forcing per-claim
  re-verification against the code materially reduces that asymmetry.
- **Theme:** Spec-driven development & formal verification for coding (LLM-as-auditor
  calibration).
- **Relevance note:** Concrete, measured failure mode for "LLM-plus-static-analyzer" code
  review stacks — relevant to any pipeline that trusts an LLM to adjudicate verifier output.
- **Link:** https://arxiv.org/abs/2610.32876
