## 1. Repo0: Design-Driven Zero-to-All Code Generation
- **Authors:** Silin Chen, Haoyi Teng, Xiaodong Gu, et al.
- **Summary:** Repo0 targets the "zero-to-all" code-generation setting where an agent must build a whole project from natural-language requirements while continuously evolving its own repository structure. It maintains a Dual-DAG architectural state (requirements DAG + component DAG plus an alignment relation) and applies modularity-guided structural actions until the architecture converges, then hands the frozen design to a test-driven code-generation stage. On RepoCraft with GPT-5 mini and DeepSeek V3.2 it lifts Functionality Coverage by up to 20.08pp and Pass Rate by up to 29.74pp over the strongest planning baseline (RPG).
- **Theme:** (3) Spec-driven development & formal verification for coding
- **Relevance:** Direct fit for spec-driven coding — an explicit design specification (Dual-DAG) drives generation, with an ablation isolating the value of structural convergence before code is written.
- **Link:** https://arxiv.org/abs/2608.19854

## 2. SemaPLC: A Project-Grounded, Verification-Gated Agent Harness for PLC Code Generation
- **Authors:** Yanlun Tu, Huacan Wang, Ziyue Zhou, et al.
- **Summary:** SemaPLC generates PLC control code inside a strict harness that refuses to declare a task complete until three logged external checks pass: specification adherence, compilation inside the target project, and dynamic behavioral equivalence when the generated logic is executed on a live PLC runtime against a reference trace. Across 117 independent-POU tasks and 65 project-context tasks, the verification gate yields the highest strict-verified pass rate on all seven backbone models and separates methods most sharply on the runtime layer (52.2 vs. 22–31 for baselines). It is open-sourced and demonstrates that execution-grounded verification, not static scoring, is the faithful test of generated control logic.
- **Theme:** (3) Spec-driven development & formal verification for coding
- **Relevance:** Concrete formal/behavioral verification loop for code generation in a safety-critical domain, closely aligned with defining correctness of agent-produced code.
- **Link:** https://arxiv.org/abs/2608.18565

## 3. Co-RL: Unsupervised Reasoning Emerges from Diverse Cohort in Multi-agent RL
- **Authors:** Yunhao Yang, Yuexin Bian, Yunjie Tian, et al.
- **Summary:** Co-RL removes the ground-truth reward from RL-for-reasoning by having a cohort of decoupled models (no shared parameters) train simultaneously, each rewarded from its peers' judgments. Diversity across model families, sizes and rephrased prompts is shown to break the correlated-error feedback loop that causes single-model self-rewarding to collapse, preserving response diversity while improving reasoning. Reported gains average 3.0–8.6% across seven text benchmarks and 2.3–7.2% across four multimodal benchmarks, matching or beating supervised approaches without any labels.
- **Theme:** (2) Multi-agent frameworks & orchestration
- **Relevance:** Genuinely multi-agent training rather than a single model with tool use; addresses a well-known failure mode of self-rewarding pipelines by construction.
- **Link:** https://arxiv.org/abs/2608.17253

## 4. PolicyGuide: From Guarding One Action to Guiding the Whole Workflow for Policy-Compliant LLM Agents
- **Authors:** Seongjae Kang, Taehyung Yu, Sung Ju Hwang
- **Summary:** PolicyGuide compiles each written policy into a workflow graph and invokes a proactive verifier at every user-turn boundary, so the agent is guided along a compliant path across a multi-step procedure rather than just being blocked on one risky action. On τ²-bench (airline/retail/telecom) with a GPT-5.4 agent + verifier, mean Pass^4 rises from 0.42 to 0.62 (largest gain 0.19 → 0.61 on telecom), and the workflows transfer to Claude Sonnet 4.6 and Gemini 2.5 Pro agents. It also reports the lowest observed attack-success rate under adversarial users.
- **Theme:** (2) Multi-agent frameworks & orchestration
- **Relevance:** Orchestrates an agent + verifier pair via compiled workflow graphs — a concrete orchestration pattern with cross-model transfer and adversarial-robustness evidence.
- **Link:** https://arxiv.org/abs/2608.19861

## 5. SPADE: Self-Play in Adaptive Synthetic Executable Environments
- **Authors:** Bo Liu, Simon Yu, Yiding Jiang, et al.
- **Summary:** SPADE has a single LLM alternate between an Environment Designer that emits complete Gym-style executable environments (with reset/step, state, rewards, verifiers) and a Reasoning Agent that learns to solve them. The Designer is trained on a regret proxy — the gap between agent reward with and without privileged hints — pushing environments to the edge of the agent's competence while remaining feasible, aided by pretraining-corpus grounding and an environment memory. At 30B parameters SPADE beats the strongest fixed-environment RL baseline by +5.3 on average across eight held-out benchmarks and by +5.7 on BFCL-v4 multi-turn / +13.9 on ACEBench-Agent tool-use.
- **Theme:** (1) Core LLM advances (agentic-system training/eval)
- **Relevance:** Turns environment design itself into a learnable component of the training loop — a fresh take on scaling reasoning and agentic RL without a fixed goal distribution.
- **Link:** https://arxiv.org/abs/2608.19197

## 6. SkillGate: Training In-Policy Skill Selection in Long-Horizon Agents
- **Authors:** Qingyao Li, Wenxiang Jiao, Shuai Shao, et al.
- **Summary:** The paper names and diagnoses "selector credit starvation": under sequence-level outcome-reward RL, the very few tokens that pick a skill get a vanishing and often wrong-signed share of credit, so a correct choice is punished whenever downstream execution fails. SkillGate partitions the token support into two disjoint credit channels — outcome credit for execution tokens, and a separate action-local advantage on skill-naming tokens that is positive only when the trajectory's single read is the correct one. Under a 16-candidate skill slate across five agentic benchmarks, a 9B policy improves from 40.8% to 53.2% trial success while reading fewer skills and cutting exposure to misleading candidates by two-thirds.
- **Theme:** (1) Core LLM advances (RL for agentic reasoning/planning)
- **Relevance:** Clean identification of a structural RL-credit-assignment failure with a targeted, minimal fix and strong controlled ablations — useful methodology beyond skill selection.
- **Link:** https://arxiv.org/abs/2608.18852

## 7. SWE-bench Science: Can Coding Agents Resolve Engineering Tasks in Science?
- **Authors:** Zhipeng Xu, Jiahao Lu, Yining Zheng, Yuxin Wang, Xipeng Qiu
- **Summary:** A repository-level benchmark of 119 tasks pulled from 98 GitHub repos across 20 scientific domains, organized into Issue-driven, Expert-exploratory, and Engineering-integration paradigms. Even Claude Code with Opus-5 (max) sits below 50% pass@1, and the authors categorize four recurring failure modes (missing scientific knowledge/abstraction, surface-level repair, incomplete integration, poor generalization). A paired ablation shows scientific guidance is not uniformly beneficial — well-grounded context helps, poorly aligned context can anchor the agent to wrong repairs.
- **Theme:** (1) Core LLM advances (agentic-system evaluation)
- **Relevance:** Fresh, hard evaluation surface for coding agents in a distribution that current systems clearly struggle on, with instructive per-paradigm failure analysis.
- **Link:** https://arxiv.org/abs/2608.19799

## 8. EnvHarness: Awakening Static Worlds for Agent Learning
- **Authors:** Chengsong Huang, Zifeng Wang, Rujun Han, et al.
- **Summary:** EnvHarness is a plug-in layer that wraps a static training environment through its standard interfaces to reshape its behavior without touching underlying logic (so the original verifier is preserved). A companion component, EnvRigger, observes trajectories of a black-box target policy, diagnoses weaknesses, synthesizes harness components to target them, and validates via fresh rollouts. Across five benchmarks in four domains it beats both raw environments and domain-specific generation pipelines by up to 9.0 points on held-out instances with ~9.8% fewer execution steps, and it provides a stronger RL signal for continuous policy–environment co-evolution.
- **Theme:** (1) Core LLM advances (agentic training)
- **Relevance:** Practical, domain-general way to keep training environments fresh as agents improve; directly relevant to agentic-system evaluation and RL training pipelines.
- **Link:** https://arxiv.org/abs/2608.19880

## 9. MemTrapBench: Benchmarking Cognitive Traps in LLM Memory Use
- **Authors:** Mengru Wang, Haozhe Luo, Zhenqian Xu, et al.
- **Summary:** Existing memory benchmarks mostly check that facts were stored and retrieved, but not whether retrieved memories distort reasoning on the current task. MemTrapBench formalizes two failure modes — Reasoning Fixation and Belief Distortion — and finds that across two model families and five memory frameworks every memory strategy underperforms the no-memory baseline, with the strongest dropping >10%. The authors also propose AdaptiveMem, a simple inference-time instruction that mitigates the traps while preserving performance on standard memory benchmarks.
- **Theme:** (1) Core LLM advances (agentic-system evaluation / memory)
- **Relevance:** Highlights a systematic downside of currently deployed memory frameworks in agents and provides a light-touch mitigation — direct relevance for agentic evaluation.
- **Link:** https://arxiv.org/abs/2608.20202

## 10. FM-Bench: A Benchmark for Long-Horizon Management with Competing Agents
- **Authors:** Tianyou Wang, Chongyang Gao, Kezhen Chen, et al.
- **Summary:** FM-Bench places an LLM agent as a football club manager for 20 in-game years across ~340–400 decision stops with 26 tools, judged by a deterministic engine (no LLM-judge, no human rater). A solo track runs 15 frontier models against a frozen world, and an Arena puts all of them plus a scripted anchor into one shared 20-year world — one of the first head-to-head evaluations at this scale. The scoring separates six behavioral capabilities and shows that neither scale nor price predicts the order; models diverge only late in the horizon, and self-managed memory fails in two symmetric ways (an ever-growing archive vs. a plan rewritten every season).
- **Theme:** (1) Core LLM advances (agentic-system evaluation)
- **Relevance:** Long-horizon, cumulative-consequence benchmark with an objective engine and cross-model head-to-head play — probes exactly the failure modes short-task benchmarks miss.
- **Link:** https://arxiv.org/abs/2608.18423
