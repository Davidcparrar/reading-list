### 1. Doc2Harness: Benchmarking LLMs on Long-Horizon Harness Engineering of Coding Agents
- Authors: Yuyao Ge, Shenghua Liu, Peizhong Gao, et al.
- Summary: Introduces a deterministic two-stage benchmark where models must read a natural-language specification and build an agent harness end-to-end, then are graded only on observable outputs rather than hidden state. The paper measures long-horizon spec-following for coding agents and reports that the strongest frontier model clears only about half of the test cases, exposing systematic gaps between spec intent and generated harness behavior.
- Theme: 3 — Spec-driven development & formal verification for coding agents
- Relevance: Direct hit on the "specs define correctness of coding-agent output" theme — benchmarks whether models can turn written specifications into verifiable agent code and judges them on behavioral conformance.
- Link: https://arxiv.org/abs/2610.20344

### 2. 3DCodeVerse: Exploring 3D Worlds as Code
- Authors: Yipeng Gao, Ziyao Zeng, Jinfa Huang, et al.
- Summary: Builds an ecosystem that casts 3D-world construction as a code-generation problem, pairing a 2M-program dataset with a multi-agent harness and a verifiability layer that checks generated programs against structural and semantic criteria. Baselines are released alongside the dataset, showing how editable, verifiable code artifacts can serve as the correctness contract for coding agents in a non-trivial domain.
- Theme: 3 — Spec-driven development & formal verification for coding agents (with a strong multi-agent orchestration component)
- Relevance: Treats program verifiability — not just execution success — as the acceptance criterion for coding-agent output, exactly the framing we care about.
- Link: https://arxiv.org/abs/2610.22341

### 3. SwarmRSI: Recursive Self-Improvement through Evolving Scientific Agent Swarm
- Authors: Qianru Meng, Xi Zhang, Konstantinos Papakostas, et al.
- Summary: Proposes a swarm of research agents that iteratively refine hypotheses by consuming experimental feedback from peer agents and recombining useful sub-components across the swarm, closing the loop between generation and evaluation. The authors report top results on several scientific-reasoning benchmarks and attribute gains to the cross-agent recombination rather than any single orchestrator.
- Theme: 2 — Multi-agent frameworks & orchestration
- Relevance: Clean example of a coordination protocol where role assignment and inter-agent communication are themselves evolved, not hand-designed.
- Link: https://arxiv.org/abs/2610.20431

### 4. AutoSFT: An Agentic System for Automated Data Research in Supervised Fine-Tuning
- Authors: Bingxiang He, Pengqi Sun, Shihao Peng, et al.
- Summary: A multi-agent pipeline that separates execution, analysis, and synthesis roles to automatically propose, test, and consolidate supervised-fine-tuning data edits. The authors report consistent gains on instruction-following and code benchmarks over single-agent baselines, demonstrating role-structured orchestration applied to the dataset-engineering loop itself.
- Theme: 2 — Multi-agent frameworks & orchestration (with core-LLM fine-tuning payoff)
- Relevance: Concrete role/tool-assignment design that targets a bottleneck (SFT data curation) rather than demoing orchestration on toy tasks.
- Link: https://arxiv.org/abs/2610.22194

### 5. OpenGCUA: Toward a Fully Open Stack for Generalist Computer Use
- Authors: Hanzhang Zhou, Long Li, Quyu Kong, et al.
- Summary: Releases an open framework for computer-use agents that interleave GUI actions with programmatic (code-execution) actions, together with training recipes, implementation, and trajectory logs. The design makes action-space hybridization — not just screen clicking — the first-class primitive for computer-using agents.
- Theme: 2 — Multi-agent frameworks & orchestration (agent architecture for mixed action spaces)
- Relevance: Shifts GUI-agent research toward architectures that call code when code is cheaper and GUI when the API is missing — a core orchestration decision.
- Link: https://arxiv.org/abs/2610.22200

### 6. Mosaic: Multi-Session Agentic Reinforcement Learning
- Authors: Yilong Xu, Minrui Xu, Xinyu Zhou, et al.
- Summary: Extends agentic RL to trajectories that span multiple sessions by assigning per-session credit based on each session's estimated marginal contribution to the final outcome, rather than crediting the trajectory as a monolith. Reported gains are strongest on long-horizon tasks where naive advantage estimators collapse credit onto the last session.
- Theme: 1 — Core LLM advances (planning, agentic-system evaluation)
- Relevance: Addresses an actual bottleneck in long-horizon agent training: how to attribute reward across session boundaries without exploding variance.
- Link: https://arxiv.org/abs/2610.22174

### 7. Cortex: Consolidating Context into Parametric Memory
- Authors: Jintian Zhang, Feng He, Xinnian Liang, et al.
- Summary: Converts in-context knowledge into merge-friendly low-rank or structural weight updates so that gains from a context window can be retained parametrically after the context is dropped. Sequential edits preserve most non-target behavior, suggesting a practical path toward PEFT-style memory consolidation rather than permanent context-window growth.
- Theme: 1 — Core LLM advances (fine-tuning / PEFT, memory)
- Relevance: Attacks the "context ≠ memory" problem with a mergeable update scheme — directly relevant for agents that outgrow their window.
- Link: https://arxiv.org/abs/2610.20399

### 8. Recovering Reliable Supervision via Critique-Guided On-Policy Distillation
- Authors: Kaixiang Zhao, Tianrun Yu, Shangzhe Li, et al.
- Summary: Instead of discarding a student's wrong reasoning traces during distillation, lets the teacher critique them so the student can revise and relearn from its own near-misses. The paper shows the critique signal restores useful supervision on math reasoning tasks where plain reject-sampling throws away most of the student's output.
- Theme: 1 — Core LLM advances (reasoning, fine-tuning)
- Relevance: A simple, methodologically clean fix to a known data-efficiency problem in reasoning distillation.
- Link: https://arxiv.org/abs/2610.20572

### 9. Waypoint-OPD: Transferring RL-Induced Policy Shifts via Gated On-Policy Distillation
- Authors: Bingxi Hou, Guochao Jiang, Guofeng Quan, et al.
- Summary: Gates teacher-to-student transfer during on-policy distillation using agreement between early and late RL checkpoints as a signal for which policy shifts are worth copying over. The gating improves math and code reasoning benchmarks relative to ungated OPD baselines.
- Theme: 1 — Core LLM advances (reasoning, fine-tuning)
- Relevance: Targets the exact failure mode where naive distillation smears over both useful and noisy RL-induced updates.
- Link: https://arxiv.org/abs/2610.21601

### 10. More Methods, Better Agents? A Reality Check on Self-Distillation in Agentic Reinforcement Learning
- Authors: Linhao Zhong, Bozhen Fang, Xuehao Wang, et al.
- Summary: Benchmarks ten published self-distillation variants against plain GRPO across multiple agent tasks and model sizes, finding that most gains vanish under careful controls and that hidden training instabilities are common. The paper argues reported wins in agentic RL often fail to transfer when compute is held constant.
- Theme: 1 — Core LLM advances (agentic-system evaluation)
- Relevance: Negative-result paper that recalibrates expectations for anyone picking a self-distillation recipe for agents — essentially a prior over which methods to trust.
- Link: https://arxiv.org/abs/2610.19789
