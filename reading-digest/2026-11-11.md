# Reading digest — 2026-11-11

Found 10 paper(s) in the last 48h window.

## 1. WorkflowArena: Benchmarking Executable Workflow Orchestration in LLM-Based Multi-Agent Systems
- **Authors:** Zheng Jiang, Fang Niu, Huan-ang Gao, et al.
- **Summary:** WorkflowArena targets the orchestration layer of multi-agent systems rather than the individual workers, scoring whether an executable workflow — delegation graph, handoffs, retries, tool bindings — actually improves end-to-end task success. It decomposes workflow quality along structural axes (branching, dependency, recovery) and runs head-to-head comparisons where the same underlying worker model is wrapped in different orchestration patterns. The paper isolates how much credit belongs to workflow design versus raw model capability on real multi-step tasks.
- **Theme:** Multi-agent frameworks & orchestration
- **Relevance:** Directly operationalizes the "coordination/role-assignment" question in theme 2, giving a controlled way to compare orchestration frameworks independent of base model strength.
- **Link:** https://arxiv.org/abs/2611.12856

## 2. Don't Just Trust Your Memory: Evidence-Linked Memory Reduces Memory-Induced Degradation in LLM Agents
- **Authors:** Yukyeong Lee, Yumin Choi, Jinheon Baek, Sung Ju Hwang
- **Summary:** WikiTrace treats every lesson stored in an agent's memory as a claim attached to the specific trajectory that produced it, so retrieval can verify provenance before the lesson is reused. When the current context contradicts or fails to support a cached lesson, the agent either revises it or discards it rather than acting on stale advice. Across five agentic benchmarks the evidence-linked variant beats both vanilla memory and self-reflective memory baselines, especially where naive memory causes drift.
- **Theme:** Multi-agent frameworks & orchestration (agent architecture / memory layer)
- **Relevance:** Addresses a load-bearing failure mode for any long-running orchestrated agent — memory that quietly corrupts future decisions — with a mechanism that other frameworks can adopt as-is.
- **Link:** https://arxiv.org/abs/2611.14320

## 3. Sage-Taiyi: A Metacognitive Architecture for Scientific Discovery
- **Authors:** Weida Wang, Benteng Chen, Yigeng Jiang, et al.
- **Summary:** Sage-Taiyi wraps a research agent in an explicit metacognitive layer that keeps separate stores for evidence, assumptions, and open questions, and uses those stores to decide which research direction and which method to pursue next. Proposals are linked back to the experiments that would discriminate between them, so the agent's self-model is the planner. The paper reports lab-validated yield gains on chemistry campaigns in addition to topping a scientific ideation benchmark.
- **Theme:** Multi-agent frameworks & orchestration (agent architecture)
- **Relevance:** A concrete role-structured architecture where self-monitoring is a first-class component — a cleaner answer to "what sits above the worker agents?" than generic planner/executor splits.
- **Link:** https://arxiv.org/abs/2611.12762

## 4. Infrathon: Benchmarking Language Agents for Real-World, Long-Horizon AI Infra Optimization
- **Authors:** Zhengyu Hu, Zheyuan Xiao, Yike Wang, et al.
- **Summary:** Infrathon pits coding and systems agents against long-horizon ML-infra optimization tasks (kernel tuning, scheduler tweaks, memory layout) where the scoring horizon can stretch across many iterations. Model rankings shift substantially as the horizon grows, and in some tasks the agents outperform human-designed baselines. The harness exposes both how agents trade exploration against commit, and how different orchestrator designs handle extended rollouts.
- **Theme:** Multi-agent frameworks & orchestration (long-horizon agent evaluation)
- **Relevance:** One of the few recent benchmarks that explicitly measures agent performance as a function of horizon length, which is where multi-agent coordination either pays off or breaks.
- **Link:** https://arxiv.org/abs/2611.11995

## 5. System Optimizations for Cost-Efficient Agent Harnesses
- **Authors:** Jongseok Park, Jiaxiang Yu, Ion Stoica, et al.
- **Summary:** This paper sits a thin optimization layer over existing agent harnesses (ReAct, AutoGen-style graphs, tool-calling loops) that caches intermediate reasoning, batches tool calls, and prunes redundant branches at the harness level without touching the underlying model or framework. Reported end-to-end cost drops of up to 35% come with only marginal accuracy loss across coding, math, and computer-use tasks. The contribution is treating the orchestration layer itself as a serving problem rather than a prompt-engineering problem.
- **Theme:** Multi-agent frameworks & orchestration
- **Relevance:** Practical, framework-agnostic lever for anyone running real agent workloads — a view of orchestration from the serving/economics side rather than the capability side.
- **Link:** https://arxiv.org/abs/2611.12122

## 6. MMDM: Measuring Massive Multitask Decision Making
- **Authors:** Junhao Shen, Qing Zong, Yue Guo, et al.
- **Summary:** MMDM assembles 5,448 single-pass decision questions across 16 task types, deliberately stressing where common-knowledge recall diverges from structured decision-making (interdependent options, mutually exclusive constraints, multi-select answers). Strong models that score well on factual benchmarks drop sharply as options become interdependent, exposing a decision-reasoning gap that isn't captured by MMLU-style eval. The dataset is designed as a diagnostic, not a leaderboard, with per-task-type breakdowns.
- **Theme:** Core LLM advances (reasoning / evaluation)
- **Relevance:** Targets a specific capability — committing to a correct option under coupled constraints — that is central to both planning and agentic tool selection.
- **Link:** https://arxiv.org/abs/2611.14309

## 7. Are Dense Rewards Worth Their Tokens in GRPO?
- **Authors:** Vikash Singh, Weicong Chen, Debargha Ganguly, et al.
- **Summary:** Across 1,668 matched-compute runs the paper finds that Monte-Carlo-style dense process rewards do worse than vanilla GRPO when the token budget spent on reward estimation is counted honestly. The authors then show that a simple prompt-selection trick — training preferentially on prompts whose predicted success rate is near 1/2 — produces consistent small gains, suggesting the signal usefully comes from curriculum rather than from denser supervision. It is a sharp, well-ablated null result against the current "more rewards = better" direction in reasoning RL.
- **Theme:** Core LLM advances (fine-tuning / RL)
- **Relevance:** A cheap, reproducible counterweight to the dense-reward trend; directly actionable for anyone deciding how to spend an RL compute budget.
- **Link:** https://arxiv.org/abs/2611.13560

## 8. Speculative Self-Distillation Enables Efficient Knowledge Internalization
- **Authors:** Shayan Talaei, Agam Bhatia, Azalia Mirhoseini, et al.
- **Summary:** The method lets a model absorb new facts or a new domain skill into its weights for closed-book use by distilling from its own speculatively-decoded outputs rather than from a teacher or from the raw corpus. Accuracy approaches full on-policy distillation while using far fewer supervised tokens, closing much of the gap between SFT and RL-style knowledge internalization. The result is a practical PEFT-adjacent recipe when the goal is parametric knowledge rather than behavioral style.
- **Theme:** Core LLM advances (fine-tuning / PEFT)
- **Relevance:** Hits the "cheap, parametric domain adaptation" use case where neither retrieval nor LoRA on instruction data is quite right.
- **Link:** https://arxiv.org/abs/2611.12016

## 9. EVAThink: Evidence Sufficiency-Guided Training for Adaptive Thinking in Video Understanding
- **Authors:** Changti Wu, Ruizhe Fan, Bin Wang, et al.
- **Summary:** EVAThink trains a vision-language model to decide, per query, whether the frames it has sampled already provide enough evidence to answer directly or whether an explicit chain-of-thought pass is warranted. The policy is learned via a two-stage RL recipe on just 6.7K samples, using evidence sufficiency as the shaping signal rather than fixed reasoning budgets. The system matches or beats always-reason baselines at a fraction of the compute.
- **Theme:** Core LLM advances (reasoning / adaptive compute)
- **Relevance:** A clean operationalization of "think only when needed" that generalizes beyond video — same signal shape could gate planning in text and tool-use agents.
- **Link:** https://arxiv.org/abs/2611.13907

## 10. Sable: A Small-Field Sumcheck Argument for Bit-Exact Inference of Large Language Models
- **Authors:** Tomer Solberg
- **Summary:** Sable produces a cryptographic proof that a specified integer-quantized transformer, run on a given prompt, produced a given token sequence bit for bit, with proving done on a single GPU for several large open-weight models. The construction uses a small-field sumcheck argument tailored to quantized matmul, giving verification times that are tractable for an external auditor. It is the first end-to-end verifiable-inference pipeline that targets production-size open-weight LLMs rather than toy models.
- **Theme:** Spec-driven development & formal verification (correctness of agent outputs)
- **Relevance:** Formal-methods anchor for the week — gives a spec ("the model you claimed produced this output") that can be checked without re-running the model, which is the foundation for any auditable coding-agent pipeline.
- **Link:** https://arxiv.org/abs/2611.14083
