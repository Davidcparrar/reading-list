## 1. Memory-Centric Continual Learning for AI Agents
**Authors:** Dongfang Li, Zhuoen Chen, Bonian Jia, et al.
**Summary:** Reframes memory in LLM agents as the mechanism of continual learning rather than a passive log, arguing that any memory component should be judged by whether it improves future actions. The paper offers a taxonomy of memory types, a two-loop (inference/learning) lifecycle, an evaluation protocol tied to downstream task outcomes, and a scaling framework meant to guide how memory grows with agent experience.
**Theme:** Core LLM advances (agentic-system evaluation; agent memory as learning primitive).
**Relevance note:** Directly on the top-priority axis — memory and continual learning for agents — and proposes an outcome-based evaluation protocol that could ground future digests' quality bar.
**Link:** https://arxiv.org/abs/2610.29357

## 2. Building AI Research Teams for Autonomous Discovery of Linear Attention Architectures
**Authors:** Yujian Liu, Li An, Zelin He, et al.
**Summary:** Builds a persistent multi-agent "research team" whose members have different disciplinary backgrounds, private histories, and an adaptive compute-allocation controller that redistributes effort across members over long investigations. Applied to architecture search, the team discovers linear-attention variants that outperform GDN2 at the 1.3B-parameter scale, making it a concrete demonstration of multi-agent orchestration producing non-trivial ML artifacts.
**Theme:** Multi-agent frameworks & orchestration (role/history differentiation, adaptive allocation).
**Relevance note:** Rare multi-agent paper where the system's output is itself a strong model — a useful datapoint on when heterogeneous agent teams beat a monolithic researcher.
**Link:** https://arxiv.org/abs/2610.28887

## 3. Sage-A1.5: From Long-Horizon Execution to Scientific Exploration with Capability Composition
**Authors:** Wenjie Lou, Tianshuo Peng, Shiyang Feng, et al.
**Summary:** A 35B mixture-of-experts agent built around three composable capabilities layered on top of long-horizon execution: subagent orchestration, self-verification, and open-ended scientific exploration. The design treats each capability as a swappable module invoked by the base executor, letting the same agent switch between structured task-completion and free-form discovery without re-training.
**Theme:** Multi-agent frameworks & orchestration (subagent + self-verification composition).
**Relevance note:** Concrete architecture for mixing an orchestrator with verifier and explorer subagents — a useful reference for anyone wiring role/tool assignment into their own stack.
**Link:** https://arxiv.org/abs/2610.28578

## 4. Evolving Agent Interfaces (Agent S4)
**Authors:** Saaket Agashe, Yuzhe Yang, Gonzalo Gonzalez-Pumariega, et al.
**Summary:** Introduces a meta-agent that uses population-based evolution over computer-use interfaces (prompts, tool wrappers, scaffolding) built from the task experience of underlying worker agents. Agent S4 improves open-source computer-use agent results while reducing cost per task, by selecting interface variants that empirically help the current model rather than hand-engineered scaffolding.
**Theme:** Multi-agent frameworks & orchestration (interface evolution as a first-class training signal).
**Relevance note:** Operationalizes the "harness matters as much as the model" idea with evolutionary search — complements paper #7 below on harness scaling.
**Link:** https://arxiv.org/abs/2610.28601

## 5. DeepEvolve: Towards Recursive Self-Improvement for Future Forecasting
**Authors:** Zhipeng Chen, Yunsen Liang, Yanxi Chen, et al.
**Summary:** An agent system for live forecasting that improves from its own experience by combining parameter-level evolution of the policy with distillation of successful rollouts into reusable skills. The result is a feedback loop in which skills added to the library change what the policy is next trained on, giving measurable recursive gains on open-world forecasting tasks.
**Theme:** Multi-agent frameworks & orchestration (recursive self-improvement; skill library + policy co-evolution).
**Relevance note:** Clean recipe for pairing weight updates with a growing skill library — the kind of pattern spec-driven agent systems will need once correctness criteria are added.
**Link:** https://arxiv.org/abs/2610.29784

## 6. Cache Engineering for Agents
**Authors:** Tianyu Fu, Ruoxi Wang, Zihan Min, et al.
**Summary:** Lets long-running LLM agents directly manage their active KV cache — dropping entries and adjusting position encodings — rather than trimming conversation history, and co-designs a serving engine so these operations are cheap at inference time. The combination keeps long-horizon context under agent control without the usual cost of re-encoding or losing in-context state.
**Theme:** Core LLM advances (inference-time control for agentic systems).
**Relevance note:** A rare systems paper on an interface that agent frameworks will likely adopt as context windows grow and tool-call histories dominate token budgets.
**Link:** https://arxiv.org/abs/2610.28577

## 7. Harness Scaling for Generalizable Agentic Reinforcement Learning
**Authors:** Fei Bai, Huatong Song, Chuan Hao, et al.
**Summary:** Trains agentic policies with RL across a diverse portfolio of execution harnesses instead of a single fixed one, and shows that this harness diversity transfers to unseen white-box and black-box harnesses at test time. The paper frames the harness as part of the training distribution rather than infrastructure, treating generalization across scaffolds as a core RL objective.
**Theme:** Core LLM advances (fine-tuning / agentic RL; agent evaluation across environments).
**Relevance note:** Complements Agent S4 (#4): one evolves the harness, the other trains the policy to be harness-agnostic — together they frame a useful axis for 2027 agent work.
**Link:** https://arxiv.org/abs/2610.29458

## 8. DecisionPivot: A Diagnostic Benchmark for Decision Models in LLM Systems
**Authors:** Xialie Zhuang, Mingcong Lei, Zunhai Su, et al.
**Summary:** A diagnostic benchmark of 48 tasks and roughly 40k items designed to expose the behavior of decision-making modules inside LLM systems under controlled variations, with calibration and confidence as first-class metrics. The findings show substantial decision-level gaps hidden by aggregate task scores, especially around confidence calibration under ambiguous evidence.
**Theme:** Core LLM advances (agentic-system evaluation; verification of decision steps).
**Relevance note:** The eval harness closest in spirit to spec-driven correctness checks — judges individual decisions rather than end-to-end task completion, which is where correctness properties for agent outputs will have to be anchored.
**Link:** https://arxiv.org/abs/2610.28522

## 9. Automating ML for Science: Can Frontier Agents Climb Scientific Hills in the Wild? (Agent4Sci)
**Authors:** Ming Zhong, Stacy Li, Nicholas Carlini, et al.
**Summary:** Agent4Sci is a long-horizon testbed where coding agents attempt to improve published scientific ML models from their own repos. The study finds that most gains come from generic engineering tricks (hyperparameter tweaks, pipeline fixes) rather than scientific insight, and that adding targeted plug-in skills roughly doubles the gains some agents obtain.
**Theme:** Core LLM advances (agentic-system evaluation on coding tasks).
**Relevance note:** Honest, pessimistic measurement of where frontier coding agents actually make progress — useful counterweight to benchmarks that reward headline pass rates.
**Link:** https://arxiv.org/abs/2610.28763

## 10. TraceForge: Distilling with Your Own Thinking
**Authors:** Yan Wang
**Summary:** Generates student-style reasoning traces for distillation by having the student author its own candidate chains conditioned on the teacher's final answer, then selects traces via a supervised + adversarial training objective. Improvements on HumanEval+ and MBPP+ show that distilled students can match teacher accuracy on code tasks without relying on the teacher's hidden reasoning traces.
**Theme:** Core LLM advances (reasoning distillation; coding evaluation).
**Relevance note:** Addresses the practical blocker that many teachers hide chain-of-thought — a direct way to transfer coding reasoning without relying on closed teacher traces.
**Link:** https://arxiv.org/abs/2610.29680
