## 1. CurvDelta: Low-Curvature Delta Modeling For Surgical Learning and Unlearning
- Authors: Zeguan Xiao, Zhuocheng Liang, Yun Chen, et al.
- Summary: Introduces a parameter-update constraint that confines fine-tuning deltas to a low-curvature subspace of the loss landscape, so the adapted model keeps its general capabilities while still absorbing new task signal. The authors couple this with a low-rank variant (CurvLoRA) that is a drop-in replacement for standard LoRA, and report gains on reasoning, code, and machine-unlearning benchmarks over vanilla full fine-tuning and LoRA baselines.
- Theme: 1 — core LLM advances (fine-tuning / PEFT, agent capability preservation).
- Relevance note: Direct PEFT contribution with explicit code-reasoning evaluation; the unlearning angle is useful for agent operators who need targeted edits without regressing on tool use.
- Link: https://arxiv.org/abs/2611.24654

## 2. The Resolution Hypothesis: Agent Evolution's Key Is Identifying Improvements
- Authors: Yuanhao Zeng, Shaocheng Lan, Ao Lu, et al.
- Summary: Runs over 10M LLM calls across seven self-improvement methods and argues that the bottleneck is not search or proposal quality but the evaluator's inability to reliably tell small improvements apart from noise. The paper formalises "resolution" of an evaluator and shows that boosting it (via repeated rollouts, better scoring, or variance-reduced metrics) unlocks agent gains that otherwise stall out.
- Theme: 1 — core LLM advances (agentic-system evaluation).
- Relevance note: Systematic study with large-scale evidence; actionable implications for anyone running agent self-improvement loops where the scorer is the real ceiling.
- Link: https://arxiv.org/abs/2611.23068

## 3. Do LLM Agents Still Need to Be Told How to Self-Improve?
- Authors: Shobhita Sundaram, Cansu Sancaktar, Phillip Isola
- Summary: Investigates whether modern LLM agents can produce their own improvement signal without human-written scaffolds, prompts, or curricula, and under what conditions "autonomous" self-improvement actually beats prescribed strategies. The authors find that strong base models can sometimes bootstrap useful critiques and edits purely from interaction, but that targeted hints still help for long-horizon or multi-step reasoning tasks.
- Theme: 1 — core LLM advances (reasoning, planning, self-improvement).
- Relevance note: Clean empirical read on how much hand-holding agent self-improvement still requires in 2026 — directly informs how aggressive to be with meta-prompt engineering.
- Link: https://arxiv.org/abs/2611.23219

## 4. Piccolo: Co-Evolving Decision Models and Data through Recursive Self-Improvement
- Authors: Zhenqing Ling, Qirui Jiao, Daoyuan Chen, et al.
- Summary: Presents a 0.8B–27B family of multimodal decision-making models trained with an agent-driven data-engineering loop: model generations drive new data construction, which is curated and re-fed to the next model, repeatedly. The resulting family improves on prior open multimodal decision baselines without relying on a static, one-shot dataset.
- Theme: 1 — core LLM advances (recursive self-improvement, planning).
- Relevance note: Concrete recipe for combining data synthesis with model training in a closed loop — a pattern directly relevant to coding and tool-use agents.
- Link: https://arxiv.org/abs/2611.24651

## 5. Evidence-Based Credit Assignment for Search-Augmented Language Models
- Authors: Wen Wang, Jindong Wang, Jiahua Bao, et al.
- Summary: Proposes a training-time reward that scores each retrieved document by how much it contributes to reaching the reference answer, so individual search calls — not only the final generation — get usable credit. The method yields more sample-efficient RL fine-tuning of retrieval-augmented reasoners by removing the sparse, end-of-trajectory reward signal typical of search-RAG pipelines.
- Theme: 1 — core LLM advances (reasoning, RL fine-tuning of search agents).
- Relevance note: Addresses a well-known pain point for tool-using agents whose rewards are sparse and delayed; technique is straightforward to port to other tool-call settings.
- Link: https://arxiv.org/abs/2611.23824

## 6. From Repositories to Training Environments: Scaling Long-Horizon Coding Agents with Environment Evolution Loop
- Authors: Yang Tian, Tianyu Zheng, Xiyuan Yang, et al.
- Summary: Introduces RepoFactory, which ingests real-world repositories and turns them into verifiable, executable coding environments, then refines those environments with a proxy-feedback loop that measures agent behaviour and patches gaps. Training a 35B coding agent on 10,159 generated environments improves long-horizon coding benchmark scores over training on static datasets.
- Theme: 2 — multi-agent frameworks & orchestration (coding agent architecture).
- Relevance note: End-to-end pipeline for turning raw repos into training signal — relevant both as a multi-agent orchestration study and as infrastructure for anything spec-driven downstream.
- Link: https://arxiv.org/abs/2611.21152

## 7. QDA: Closed-Loop LLM Quantization Design with Agents
- Authors: Xingyang Li, Tianlang Zhao, Song Han, Ligeng Zhu
- Summary: Treats post-training quantization recipe design as an agent task: an LLM agent picks and composes methods from a compatibility-aware library per target model, scored by a cheap KL-divergence proxy that estimates quality without full evaluation. The closed loop produces model-specific recipes that beat uniform defaults, with no extra inference-time overhead.
- Theme: 2 — multi-agent frameworks & orchestration (agent tool/role assignment for systems tasks).
- Relevance note: Nice example of an agent orchestration pattern applied to a problem (quantization) usually solved by hand-tuned heuristics; the proxy-scoring trick generalises.
- Link: https://arxiv.org/abs/2611.23388

## 8. Heave-Ho: Decentralized Long-Horizon Multi-Humanoid Collaboration
- Authors: Ting-Hsuan Chen, Siheng Zhao, Han Jiang, et al.
- Summary: Presents a decentralized orchestration framework for teams of humanoid robots doing long-horizon loco-manipulation, pairing a vision-language planner with speech-based leader–follower coordination. The system scales to ten robots and ships HH-Bench, a benchmark of cooperative tasks that isolates planning, communication, and physical coordination failures.
- Theme: 2 — multi-agent frameworks & orchestration (coordination, communication protocols).
- Relevance note: Rare paper that takes agent-to-agent communication seriously at scale with a concrete protocol (speech-mediated leader/follower), and ships a benchmark.
- Link: https://arxiv.org/abs/2611.22275

## 9. Game2Player: Scaling Gameplay Experience for Visual Agents through Environment-Player Co-Development
- Authors: Xirui Jiang, Yuxi Chen, Rui Yang, et al.
- Summary: Co-develops verifiable web-game environments and gameplay trajectories through two cooperating agent roles — a builder that creates games and a player that attempts them — iterating until both produce useful signal. The pipeline yields 568 games plus a benchmark for training and evaluating visual agents in environments neither side had seen beforehand.
- Theme: 2 — multi-agent frameworks & orchestration (role assignment, environment generation).
- Relevance note: Demonstrates a generate–solve agent pair as a data factory; portable to other verifiable-environment domains (including code benchmarks).
- Link: https://arxiv.org/abs/2611.24154

## 10. FVScore: Specification-Driven Neuro-Symbolic Video Evaluation
- Authors: Do Xuan Long, Long T. Le, Yiwen Song, et al.
- Summary: Decomposes a video-generation prompt (plus implicit physical and compositional constraints) into a set of propositions, then checks each proposition against the generated video with perception tools and returns timestamped violations rather than a scalar score. The resulting evaluator is auditable, localizable, and better aligned with human judgments than standard reference-based scores.
- Theme: 3 — spec-driven development and formal methods (adjacent: spec-decomposed, neuro-symbolic evaluation of generated artifacts).
- Relevance note: Closest paper to Theme 3 inside the 48h window. It is not aimed at code, but the pattern — automatically decompose the spec, check each clause with a tool, report pinpointed violations — is exactly the shape of neuro-symbolic agent-output verification that Theme 3 cares about, and is straightforward to re-aim at code correctness.
- Link: https://arxiv.org/abs/2611.22673
