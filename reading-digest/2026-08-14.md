## 1. Intern-S2-Preview: Scientific Agentic Foundation Model
- **Authors:** Lei Bai, Jiaqi Cao, Chiyu Chen, et al.
- **Summary:** Introduces a family of open scientific "agentic" foundation models that couple multimodal pre-training with a multi-task reinforcement-learning post-training stage and an external memory module for long-horizon tool use. The RL stage jointly optimizes reasoning quality, tool calls, and memory reads across scientific domains, and the memory acts as a persistent scratchpad so the agent can resume long analyses without rebuilding context. Reported results show a large jump over base-model baselines on scientific benchmarks that require multi-step tool use, with the biggest gains attributed to the memory-augmented loop rather than raw model scale.
- **Theme:** (2) Multi-agent frameworks & orchestration (also touches Theme 1 via RL post-training).
- **Relevance:** Concrete agent architecture where memory + tool use + RL are jointly trained — directly on-theme for orchestrated agent systems and how they are actually evaluated.
- **Link:** https://arxiv.org/abs/2608.13505

## 2. AutoDesign: Meta-Harness Optimization for Long-Horizon Agentic Design
- **Authors:** Yaxin Luo, Haobin Jiang, Jialv Zou, et al.
- **Summary:** Frames the "harness" around a code agent (its prompts, tool wrappers, planning loop) as the object to optimize rather than the model itself, and searches over harness variants using rollout feedback on long-horizon design tasks. The system recursively rewrites parts of its own scaffolding when a rollout scores poorly, keeping edits that improve the reward and rolling back those that regress. On structured media-generation benchmarks it beats hand-tuned harnesses using the same frozen backbone.
- **Theme:** (2) Multi-agent frameworks & orchestration.
- **Relevance:** Meta-level agent architecture: treating orchestration scaffolding as a search space is exactly the direction the second theme cares about.
- **Link:** https://arxiv.org/abs/2608.13560

## 3. Spatial Memory Agent: Experience-Grounded Procedure Memory for Spatial Intelligence
- **Authors:** Haokai Zhang, Yuhang Ding, Yunshu Zhou, et al.
- **Summary:** Builds a train-free agent that improves spatial reasoning by writing verified successful procedures into a transferable memory store and retrieving them at inference. Reflection over failed attempts is used to gate what enters memory, so the store stays high-signal instead of growing with noisy traces. A frozen VLM combined with this memory reportedly matches or beats fine-tuning baselines on several spatial benchmarks, illustrating an approach where capability comes from the retrieval loop rather than parameter updates.
- **Theme:** (2) Multi-agent frameworks & orchestration (agent architecture with procedural memory).
- **Relevance:** Clean example of an agent architecture whose "learning" lives entirely in a retrieval store — a pattern worth understanding for orchestration designs.
- **Link:** https://arxiv.org/abs/2608.12743

## 4. Persistent Recursive Worlds Enable Autonomous Software Evolution
- **Authors:** Beichen Huang, Zhenyu Liang, Bowen Zheng, et al.
- **Summary:** Argues that long-horizon autonomous software work should be organized around a persistent project state (spec, code, test outcomes, decisions) rather than a persistent agent, so any short-lived agent can pick up where the last one left off. The framework treats the spec-and-state layer as the durable artifact and lets agents replay against it to make incremental, verified changes; a multi-day case study reports successful compiler-like construction that no single-shot run could complete. This is closest in spirit to spec-driven development for agentic coding among the papers in the window.
- **Theme:** (3) Spec-driven development & formal-style correctness for coding agents.
- **Relevance:** The only paper in the 48h window that squarely addresses persistent spec/state as the correctness backbone for autonomous code work.
- **Link:** https://arxiv.org/abs/2608.10450

## 5. Mechanist: AI as a Scientific Instrument for Discovering the Mechanisms of Intelligence
- **Authors:** Mengru Wang, Junfeng Fang, Shuofei Qiao, et al.
- **Summary:** Presents an autonomous agentic system that proposes, tests, and refines mechanistic hypotheses about model internals via causal interventions, closing the loop between formulation and empirical validation. The agent selects probes, runs interventions, and writes findings back to a shared hypothesis store so subsequent runs can build on confirmed structure. Case studies recover known interpretability results and surface a handful of new ones, suggesting an evaluation template for "agent that does research" pipelines.
- **Theme:** (1) Core LLM advances (agentic-system evaluation on scientific-discovery workloads).
- **Relevance:** Bridges interpretability research and agentic-loop design — useful as a concrete evaluation harness for agents doing autonomous investigation.
- **Link:** https://arxiv.org/abs/2608.12036

## 6. AI4AI at Test-Time: Strong-to-Weak Capability Transfer via Harnesses
- **Authors:** Cheng Qian, Wenting Zhao, Liangwei Yang, et al.
- **Summary:** Shows that a stronger LLM can, at inference time, author a task-specific harness (prompts, tool calls, verification scaffold) that a weaker LLM then executes, and that this transfer meaningfully lifts the weaker model's task score without any weight updates. The stronger model uses a small set of exemplar rollouts on the target task to write a harness tailored to the weaker model's failure modes, and the weaker model just follows it at deploy time. This gives a cheap alternative to distillation for capability transfer.
- **Theme:** (1) Core LLM advances (inference-time capability transfer, alternative to PEFT).
- **Relevance:** Direct challenger to fine-tuning as the default way to move capability across models — worth tracking alongside PEFT results.
- **Link:** https://arxiv.org/abs/2608.12307

## 7. Massive Activations in Hybrid Linear Attention Large Language Models
- **Authors:** Zunhai Su, Bohan Sun, Xialie Zhuang, et al.
- **Summary:** Characterizes an "activation spike + inter-spike plateau" pattern that appears in hybrid linear-attention architectures and traces it to how cancellation timing between the linear and softmax paths interacts with residual accumulation. The analysis explains why quantization and pruning schemes tuned for pure softmax attention degrade sharply on hybrid stacks, and suggests targeted mitigations at the spike locations. Useful background for anyone deploying newer efficient-attention LLMs.
- **Theme:** (1) Core LLM advances (architecture and inference-time behavior).
- **Relevance:** Practical result for people picking or quantizing hybrid-attention models — the failure mode described here has direct deployment implications.
- **Link:** https://arxiv.org/abs/2608.12149

## 8. ToolHazard: Scaling Adversarial Environments for Security Evaluation and Alignment of LLM-based Agents
- **Authors:** Yutao Mou, Pengfei Yang, Zhe Yin, et al.
- **Summary:** Builds a scalable pipeline for synthesizing adversarial multi-tool environments that stress-test LLM agents against indirect prompt injection and tool-output poisoning, producing a benchmark plus a training set for alignment. The pipeline procedurally generates hazardous tool schemas and injected payloads so evaluation and defensive training data can grow without hand-authoring each scenario. Frontier agents show large gaps that shrink measurably after alignment fine-tuning on the generated data.
- **Theme:** (1) Core LLM advances (agentic-system safety evaluation).
- **Relevance:** Agentic evaluation with an actually growable adversarial surface — what most static tool-use benchmarks lack.
- **Link:** https://arxiv.org/abs/2608.11878

## 9. ComBodied Agents: a New Paradigm of Human-Centric Agentic AI
- **Authors:** Qianggang Ding, Xingyao Wang, Rui Feng, et al.
- **Summary:** Proposes a closed-loop architecture that fuses digital tools (browsers, APIs) and embodied tools (robots, sensors) around a persistent per-user state model, so the agent's action selection is conditioned on consent and current human context. The state model is updated by both digital and physical observations, letting the same coordination layer schedule work across modalities without bespoke glue per environment. Positioned as an architecture template rather than a single benchmark result.
- **Theme:** (2) Multi-agent frameworks & orchestration (architecture proposal spanning digital + embodied tools).
- **Relevance:** Useful reference point for orchestration designs that span heterogeneous tool surfaces under a shared state contract.
- **Link:** https://arxiv.org/abs/2608.10915

## 10. SkillZip: Evaluation-Free Skill Compression for Self-Evolving Agents by Discovering Reusable Structure
- **Authors:** Xiaofan Bai, Hongqiang Lin, Chao Liu, et al.
- **Summary:** Addresses the "skill library keeps growing" problem in self-evolving agents by compressing accumulated skills into a smaller reusable core plus rare exceptions, using structural explanation rather than execution-time evaluation to decide what to merge. Because compression is evaluation-free, it scales to libraries where re-running every skill for validation would be prohibitive. Reports competitive downstream success while collapsing the library to a fraction of its original size, easing retrieval under limited context.
- **Theme:** (2) Multi-agent frameworks & orchestration (skill library / memory management for agents).
- **Relevance:** Directly addresses a scaling pain of skill-library-based agents; complements the memory-driven papers above.
- **Link:** https://arxiv.org/abs/2608.11079
