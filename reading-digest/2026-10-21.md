## 1. Sage-A1.5: From Long-Horizon Execution to Scientific Exploration with Capability Composition

- Authors: Wenjie Lou, Tianshuo Peng, Shiyang Feng, et al.
- Summary: Sage-A1.5 is a 35B mixture-of-experts agent that composes capabilities by dispatching subagents and verifying intermediate results against its own rubrics, aiming at open-ended scientific exploration rather than fixed-script execution. The authors couple subagent orchestration with a self-verification loop that can escalate or re-plan when a step's verifier rejects, and they report gains on long-horizon execution plus previously-closed science tasks.
- Theme: 2 — multi-agent orchestration (subagent dispatch, role assignment, self-verification).
- Relevance: direct hit on orchestration + role/tool assignment with a sized model and open-ended tasks; strongest multi-agent entry in the window.
- Link: https://arxiv.org/abs/2610.28578

## 2. Evolving Agent Interfaces (Agent S4)

- Authors: Saaket Agashe, Yuzhe Yang, Gonzalo Gonzalez-Pumariega
- Summary: Rather than scaling a fixed computer-use agent, Agent S4 uses a meta-agent that proposes new interface fragments and usage-knowledge entries from past trajectories, and selects them by held-out task performance. The result is an agent architecture whose tools and tool-usage priors evolve with task experience instead of being hand-engineered.
- Theme: 2 — agent architectures and tool/role assignment.
- Relevance: directly tackles coordination between the model, its interfaces, and its accumulated usage knowledge — a less common axis than policy fine-tuning.
- Link: https://arxiv.org/abs/2610.28601

## 3. HarnessPro: Recursive Harness Self-Improvement with Pareto Optimization for Performance-Cost Trade-offs

- Authors: Zhuoshi Pan, ZhiYuan Feng, Yukuo Cen
- Summary: HarnessPro treats the agent harness (tools, loops, verifiers) as the thing to optimize while the LLM stays fixed, iterating with LLM-generated tests rather than human labels. It then picks lite / balanced / heavy variants from the Pareto front so the operator can pick a point on the cost–performance curve instead of a single configuration.
- Theme: 2 — orchestration (harness design + evaluation).
- Relevance: pairs harness evolution with explicit cost accounting, which is where most "self-improving agent" papers hand-wave.
- Link: https://arxiv.org/abs/2610.26770

## 4. HarnessRL: Co-Evolving Policies with a Just-in-Time Training Harness for Open-Ended RL

- Authors: Xiaoqiang Wang, Ting-En Lin, Yuchuan Wu
- Summary: HarnessRL adapts task sampling, rollout layout, and reward rubrics *during* RL so an evolving policy is not stuck with a stale rubric that stops rewarding real progress. The method is motivated by the common failure where rubric-based open-ended RL plateaus once the policy learns to game the fixed rubric.
- Theme: 2 — orchestration (coupling training-time infrastructure with the agent's policy).
- Relevance: distinct from inference-time harness papers above — targets the training loop itself as part of the agent system.
- Link: https://arxiv.org/abs/2610.26426

## 5. OpenVLHarness: Real-World Visual Agentic Tool-Use with Multimodal Memory

- Authors: Yu Zhou, Cheng-Fu Yang, Rui Sun, et al.
- Summary: OpenVLHarness is a harness that combines a tool interface and a persistent multimodal (image + text) memory, letting a vision-language agent plan over past screenshots and tool outputs instead of a single prompt window. The authors report wins on 22 visual benchmarks over matched no-tool baselines.
- Theme: 2 — tool assignment + persistent memory across tool calls.
- Relevance: concrete multimodal instantiation of the "agent = model + harness + memory" view, with broad eval coverage.
- Link: https://arxiv.org/abs/2610.26860

## 6. S-Agent 2.0: Spatial Reasoning with a General Coding Agent

- Authors: Rui Gong, Ruoyu Wang, Yalun Dai, et al.
- Summary: S-Agent 2.0 wraps a general coding agent around command-line 3D perception tools and a persistent scene memory, so spatial queries are answered by having the model write and run code against those tools rather than reasoning over raw pixels. Reported gains come from the agent composing tools and caching scene state across turns.
- Theme: 2 — tool assignment for a coding agent (bridges toward coding-agent evaluation).
- Relevance: closest paper in the window to coding-agent-plus-tools, which is adjacent to the user's theme-3 interest.
- Link: https://arxiv.org/abs/2610.28354

## 7. PAR: Progress-Aligned Recurrence for Length Generalization in State Tracking

- Authors: Pan Wang, Yihao Hu, Guangyuan Dong, et al.
- Summary: PAR trains looped (recurrent) language models so that each iteration of the loop corresponds to a specific number of underlying state-update operations, and anchors recurrent-state norms to keep them stable. The result is state-tracking performance that generalizes to problem lengths well beyond those seen in training.
- Theme: 1 — reasoning and planning (length generalization is a classical blocker for both).
- Relevance: a mechanism-level advance on reasoning, not just a bigger model or a new benchmark.
- Link: https://arxiv.org/abs/2610.27628

## 8. MMEnterprise-Bench: Evaluating Enterprise Agents over Evolving Multimodal Records

- Authors: Seohyun Lee, Jongha Kim, Dohwan Ko, et al.
- Summary: A 1,613-question benchmark over multimodal workplace records (threads, documents, images) that changes over time, scoring agents on evidence reasoning, conflict resolution across versions, and recognizing when a question is actually unanswerable. Strong frontier models still fail noticeably on conflicting or multi-image evidence.
- Theme: 1 — agentic-system evaluation under realistic, non-static context.
- Relevance: explicitly targets the "evidence is evolving and sometimes contradicts" case, which most agent benchmarks ignore.
- Link: https://arxiv.org/abs/2610.27911

## 9. DecisionPivot: A Diagnostic Benchmark for Decision Models in LLM Systems

- Authors: Xialie Zhuang, Mingcong Lei, Zunhai Su
- Summary: DecisionPivot pulls apart aggregate accuracy to measure decision consistency across rephrasings, calibration of stated confidence, and reliability under near-ties. The authors show models with similar top-line accuracy diverge sharply on these components, which matters when an LLM is used as a routing / escalation decision model.
- Theme: 1 — agentic-system evaluation (diagnostic axes, not just accuracy).
- Relevance: useful for anyone running LLMs as judges, routers, or decision controllers inside a larger agent.
- Link: https://arxiv.org/abs/2610.28522

## 10. AdaExploreBench: Benchmarking LLM Agents for Proactive Exploration and Test-time Adaptation in Evolving Environments

- Authors: Rui Wang, Zishen Lai, Jiayu Liu
- Summary: AdaExploreBench tests whether LLM agents can proactively probe an environment to recover hidden rules — and whether they notice when the rules silently change under them, invalidating earlier conclusions. The benchmark isolates two failure modes current agents share: under-exploration and over-trust in stale priors.
- Theme: 1 — agentic-system evaluation under distribution shift / test-time adaptation.
- Relevance: pairs well with DecisionPivot and MMEnterprise-Bench for a non-static view of agent evaluation.
- Link: https://arxiv.org/abs/2610.25950
