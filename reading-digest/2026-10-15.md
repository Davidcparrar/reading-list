# Reading digest — 2026-10-15

Found 10 paper(s) in the last 48h window.

## 1. Long-Horizon RL Needs Muon
- **Authors:** Kai Ruan, Jinghao Lin, Tao Chen, et al.
- **Summary:** The paper studies what a single-rollout asynchronous RL recipe needs to actually train long-horizon coding agents and shows the usual AdamW setup leaves gains on the table. It combines the Muon optimizer with a tailored loss and penalty mix (including a conservative baseline for the implicit value function) so that credit propagates across long trajectories. Reported training-success numbers come in meaningfully higher than the compared baselines on long-horizon coding environments.
- **Theme:** Core LLM advances (reasoning / long-horizon fine-tuning)
- **Relevance:** Direct study of what optimizer + loss design is needed for training coding agents on long horizons — hits the "fine-tuning / agentic-system evaluation" subtheme head-on.
- **Link:** https://arxiv.org/abs/2610.20256

## 2. More Methods, Better Agents? A Reality Check on Self-Distillation in Agentic Reinforcement Learning
- **Authors:** Linhao Zhong, Bozhen Fang, Xuehao Wang, et al.
- **Summary:** The authors run a controlled sweep of ten published self-distillation methods against vanilla GRPO across four distinct agent environments, holding backbone and budget fixed. They find most methods deliver limited or inconsistent gains, exhibit training instability that is hidden by looking only at final scores, and show weak correlation between added compute and downstream performance. The paper is essentially a negative-result audit of the self-distillation literature for agentic RL.
- **Theme:** Core LLM advances (agentic-system evaluation / fine-tuning)
- **Relevance:** A rigorous head-to-head of agent fine-tuning methods — exactly the kind of agentic-system evaluation the digest is asked to surface, and useful as a sanity check before adopting any of these methods.
- **Link:** https://arxiv.org/abs/2610.19789

## 3. Cortex: Consolidating Context into Parametric Memory
- **Authors:** Jintian Zhang, Feng He, Xinnian Liang, et al.
- **Summary:** Cortex frames long-context handling as a weight-update problem: distill the capability that long context grants into mergeable low-rank or feed-forward deltas, so the base model keeps its other skills. The method distills context-conditioned outputs into these updates, then merges them so a model can "remember" a document without carrying its tokens. Experiments argue this preserves general capability while retaining what the context taught.
- **Theme:** Core LLM advances (fine-tuning / PEFT)
- **Relevance:** A PEFT-flavoured take on context-to-weights consolidation — directly relevant to agentic systems that need durable per-task memory without re-feeding long context.
- **Link:** https://arxiv.org/abs/2610.20399

## 4. Recovering Reliable Supervision via Critique-Guided On-Policy Distillation
- **Authors:** Kaixiang Zhao, Tianrun Yu, Shangzhe Li, et al.
- **Summary:** The paper argues that standard on-policy distillation silently fails when the student's rollout is wrong, because the teacher is asked to continue from a broken state and ends up endorsing the error. CriticOPD changes the teacher's role from completer to critic: the teacher explains what is wrong, and the student rewrites its own solution with that critique as context. Across the reasoning benchmarks reported, this recovers reliable supervision where plain on-policy distillation plateaus.
- **Theme:** Core LLM advances (reasoning / fine-tuning)
- **Relevance:** Clean diagnosis of a known failure mode in on-policy distillation plus a practical fix — a method paper that improves both reasoning training recipes and student-teacher setups.
- **Link:** https://arxiv.org/abs/2610.20572

## 5. Agent-Reflex: Teaching Language Agents to Act Reflectively
- **Authors:** Guanting Dong, Xinyu Yang, Jiajie Jin, et al.
- **Summary:** Agent-Reflex is a three-stage training framework that teaches an LLM agent to notice when a tool call returned something noisy or wrong, backtrack, and try a different path rather than compounding the error. The stages build up from supervised reflex traces to RL-with-feedback over multi-turn tool trajectories. The reported wins are concentrated on tasks where recovery from a bad intermediate step matters more than first-try correctness.
- **Theme:** Multi-agent frameworks & orchestration (agent architecture / tool use)
- **Relevance:** Agent architecture work focused on failure-recovery during tool orchestration — a core capability for any multi-tool, multi-step agent pipeline.
- **Link:** https://arxiv.org/abs/2610.17953

## 6. WorkRover: Scaling Long-Horizon Cowork Agent Training Via Recursive Environment Evolution
- **Authors:** Hang He, Linting Wang, Guanming Liu, et al.
- **Summary:** WorkRover addresses the shortage of good training environments for long-horizon "cowork" agents by having an agent build its own training environments, test them, and iteratively repair the ones that are too easy, too hard, or non-executable. On top of that it uses a finer-grained credit assignment scheme for multi-turn rollouts so training signal reaches early turns. The pitch is a scalable, self-improving environment stack for cowork agent training.
- **Theme:** Multi-agent frameworks & orchestration (environments / credit assignment)
- **Relevance:** Combines two scarce assets — environment generation at scale and multi-turn credit assignment — for the kind of long-horizon coordination tasks multi-agent systems have to handle.
- **Link:** https://arxiv.org/abs/2610.18067

## 7. SwarmRSI: Recursive Self-Improvement through Evolving Scientific Agent Swarm
- **Authors:** Qianru Meng, Xi Zhang, Konstantinos Papakostas, et al.
- **Summary:** SwarmRSI runs a swarm of scientific agents that each propose, run, and critique experiments, then reuse successful components (prompts, tools, sub-plans) from one another through a shared repository. A feedback loop over multiple generations is used to refine hypotheses and the agents themselves, making the swarm's capability a function of time rather than of any single agent. The system is a concrete instance of orchestration-plus-reuse for scientific discovery agents.
- **Theme:** Multi-agent frameworks & orchestration (coordination / role assignment)
- **Relevance:** A pointed example of orchestration + inter-agent reuse protocols — maps straight onto the "coordination, communication protocols, role/tool assignment" subtheme.
- **Link:** https://arxiv.org/abs/2610.20431

## 8. Share the Symbol, Not the Vector: Training-Free Fact Communication Across Language Models
- **Authors:** Xin Li, Mengbing Liu, Hao Jiang, et al.
- **Summary:** SYNC proposes a training-free protocol for one language model to transmit a fact to another by sending indices into a shared word list rather than hidden-state vectors. The receiver injects the referenced tokens' meaning along its own directions, so no translator or fine-tuning is needed, and a probe tells the sender which receiver layers can absorb the fact. Across several model families the receivers show high selective fact-use without any joint training.
- **Theme:** Multi-agent frameworks & orchestration (communication protocols)
- **Relevance:** Directly a communication-protocol paper for heterogeneous multi-model systems — rare to see something this concrete on model-to-model messaging without a learned translator.
- **Link:** https://arxiv.org/abs/2610.19696

## 9. Doc2Harness: Benchmarking LLMs on Long-Horizon Harness Engineering of Coding Agents
- **Authors:** Yuyao Ge, Shenghua Liu, Peizhong Gao, et al.
- **Summary:** Doc2Harness turns the task of writing an executable test/eval harness for a software project from a spec document into a deterministic, two-stage benchmark. Models must produce code and the glue around it that actually passes the authors' hidden spec checks, which exposes cross-cutting feature placement as the dominant failure mode (top model scores 53.05%). It is one of the clearer attempts to measure spec-to-correct-code behavior for coding agents end-to-end.
- **Theme:** Spec-driven development & correctness for coding agents
- **Relevance:** Direct hit on the spec-driven-development theme: it benchmarks whether LLM coding agents can realize a spec as a working harness, and surfaces specific spec-adherence failure modes.
- **Link:** https://arxiv.org/abs/2610.20344

## 10. Diff Diffusion: Predicting Edit Paths with Diffusion Models for Efficient Code Editing
- **Authors:** Xiaolong Xu, Hao Jiang, Bo Jiang, et al.
- **Summary:** Diff Diffusion recasts code editing as denoising a sequence of structured edit operations from the original snippet to its revised version, so computation is concentrated on changed regions rather than regenerating full files. Multi-stage training plus parallel decoding give it low-latency, multi-position edits that match or beat autoregressive baselines on public edit-completion benchmarks, with a 2.78x speedup and 39.0% lower production P50 latency. It is an edit-as-formal-operation take on code modification, which is adjacent to spec-driven coding.
- **Theme:** Spec-driven development & correctness for coding agents (edit-level)
- **Relevance:** Treats code changes as explicit, structured operations rather than free-form text — closest in-window neighbor to formal/spec-level reasoning about code edits.
- **Link:** https://arxiv.org/abs/2610.17831
