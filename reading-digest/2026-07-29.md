## 1. Keep It InMind: Benchmarking the Implicit-Association Blind Spot in Agent Memory
- **Authors:** Ruizhe Li, Mingxuan Du, Benfeng Xu, et al.
- **Summary:** The paper builds a stress test for agent memory that decouples what is stored from how it is later queried, forcing systems to recall a fact even when the query shares none of its surface terms. Across six memory implementations, direct look-ups hit near-perfect recall while indirect, implicit-association queries top out around 14%, exposing that current memory stacks rely heavily on lexical overlap rather than semantic linking. The result reframes agent-memory evaluation: retrieval quality on cue-matched probes overstates real capability.
- **Theme:** Memory for LLMs and agents (episodic/long-term memory retrieval)
- **Relevance note:** Directly targets the memory-blind-spot problem for agents — the top-priority theme.
- **Link:** https://arxiv.org/abs/2607.24368

## 2. CodeNib: A Multi-View Data System for Serving Repository Context to Coding Agents
- **Authors:** Zhongming Yu, Hengjia Yu, Boqin Yuan, et al.
- **Summary:** CodeNib treats a code repository as a live, multi-view store — lexical index, dense embeddings, and structural graph — that a coding agent can query instead of re-grepping the tree each turn. The system keeps the three views incrementally updated (graph 8.7× faster, vectors 25.4× faster than rebuilds) and serves 50–87% fewer trajectory tokens than grep/read style exploration. It reads as a purpose-built long-horizon working-memory substrate for coding agents.
- **Theme:** Memory / context-and-state management for agents
- **Relevance note:** Concrete memory-and-context infrastructure for agent trajectories; complements the InMind benchmark by proposing the storage side.
- **Link:** https://arxiv.org/abs/2607.25431

## 3. From Proprietary to Open-Source: Bridging the Distribution Gap via Multi-Agent Protocol Distillation
- **Authors:** Junlin Liu, Jiangwang Chen, Zixin Song, et al.
- **Summary:** MAPD frames knowledge transfer between a proprietary and an open-source model as a multi-agent handshake mediated by a structured, style-normalized protocol rather than raw traces. Because the intermediate is a protocol (roles, message schemas, control tokens) rather than free text, the student can inherit the teacher's coordination patterns without being pinned to its surface style. Reported QA success rates approach the proprietary baseline.
- **Theme:** Multi-agent frameworks & orchestration (inter-agent communication protocol)
- **Relevance note:** Rare paper that formalizes the communication protocol as the transferable object between agents.
- **Link:** https://arxiv.org/abs/2607.24280

## 4. ReDesign: Recovering Editable Design Structures from Images via Agentic Decomposition
- **Authors:** Jooyeol Yun, Jintae Park, Hyesu Lim, et al.
- **Summary:** ReDesign decomposes the image-to-editable-file task across specialist tools (vector recovery, text, layout, layer segmentation) and orchestrates them under a "graceful verification" step that catches per-tool errors before they cascade downstream. The pipeline is evaluated on a new 14,796-instruction Figma edit-replay benchmark, isolating agent decomposition quality from single-shot generation. It is a clean case study of role/tool assignment plus verification in a multi-agent system.
- **Theme:** Multi-agent frameworks & orchestration (role/tool assignment, error containment)
- **Relevance note:** Concrete agentic-decomposition architecture with a new benchmark for measuring it.
- **Link:** https://arxiv.org/abs/2607.25565

## 5. A New Role for Relevance: Guiding Corpus Interaction in Agentic Search
- **Authors:** Jiangnan Li, Yuqing Li, Mo Yu, et al.
- **Summary:** RARG re-purposes classical relevance scores as an *execution prior* — a coarse-to-fine roadmap the agent consults while grep-style browsing a corpus — rather than as the final answer. This yields better convergence on browse-QA and reasoning-intensive retrieval, where naive tool loops wander. The framing (relevance as planning signal, not endpoint) is a small but principled shift for agentic search architectures.
- **Theme:** Multi-agent / agentic frameworks (search-agent planning)
- **Relevance note:** Mechanism-level contribution to how a search agent decides its next tool call.
- **Link:** https://arxiv.org/abs/2607.24223

## 6. Towards Robust Reinforcement Learning for Small-Scale Language Model Agents
- **Authors:** Md Rezwanul Haque, Md. Milon Islam, Fakhri Karray
- **Summary:** The paper catalogs three reproducible failure modes when applying PPO to small language-model agents — silent parameter freezing, numerical overflow, and policy collapse — and proposes minimal safety mechanisms that produce stable convergence across 15 configurations. It is squarely a fine-tuning / agentic-training paper aimed at making small-model RL usable outside frontier-scale budgets. Useful as a diagnostic reference before running any agentic RL job.
- **Theme:** Core LLM advances (fine-tuning, agentic-system training & evaluation)
- **Relevance note:** Practical, reproducible RL training guidance for LM agents.
- **Link:** https://arxiv.org/abs/2607.25091

## 7. Kimi K3: Open Frontier Intelligence
- **Authors:** Kimi Team, Jiaqi Deng, Yuhao Dong, et al.
- **Summary:** Kimi K3 is a 2.8T-parameter MoE with ~104B active parameters, native vision, and a 1M-token context window, positioned as an open-weights frontier model. The technical report emphasizes attention-mechanism changes and multi-domain RL that together deliver a ~2.5× scaling-efficiency improvement over K2. Chiefly interesting as a public data point on where open frontier training is landing.
- **Theme:** Core LLM advances (scaling, long context, RL post-training)
- **Relevance note:** Reference point for the current state of open frontier LLMs; long-context claims are directly relevant to memory workflows.
- **Link:** https://arxiv.org/abs/2607.24653

## 8. Pass the Baton: Trajectory-Relayed On-Policy Distillation
- **Authors:** Haolei Xu, Xiaowen Xu, Haiwen Hong, et al.
- **Summary:** The paper identifies a "prefix failure" pathology in on-policy distillation — the student poisons its own rollout early, then the teacher can't recover it — and uses continuation asymmetry to detect the drift and hand the baton to the teacher mid-rollout. Reported gains include +5.73% on math-reasoning benchmarks with 50% less training compute. A small algorithmic tweak with a clear diagnostic signal.
- **Theme:** Core LLM advances (fine-tuning / distillation for reasoning)
- **Relevance note:** Targets reasoning-model distillation with a well-motivated fix, not another benchmark chase.
- **Link:** https://arxiv.org/abs/2607.26057

## 9. VisualPatchWorld: Code World Models as Latent Structured Representations for Planning
- **Authors:** Jiaxin Bai, Jiaxuan Xiong
- **Summary:** VisualPatchWorld represents world dynamics as executable, inspectable code, selected via active probes rather than free-form model rollouts. Reported planning success is 69% — 23.5 points above prior code-baselines — attributed to automated construction of physics-informed models. The design is a concrete example of using code as the latent state a planning agent reasons over.
- **Theme:** Core LLM advances (planning, structured world models)
- **Relevance note:** Interesting take on planning with code-as-state; sits between core LLM and agent reasoning.
- **Link:** https://arxiv.org/abs/2607.25236
