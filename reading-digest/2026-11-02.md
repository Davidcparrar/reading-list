## 1. CEPO: A General Framework for Improving Prompt Optimization in Multi-Agent Systems
- **Authors:** Jongha Kim, Seohyun Lee, Jonathan Minho Chung, et al.
- **Summary:** CEPO factors a multi-agent system's prompt into a single shared Coordinator prompt that encodes system-level routing/role rules and separate Executor prompts that each agent uses locally, then plugs any existing prompt optimizer into both tracks under role-aware update rules. Across 11 benchmarks spanning four domains, dropping CEPO on top of four existing optimizers consistently lifts their scores, and a document-understanding ablation shows the budget efficiency scales better with the number of agents than agent-specific-only prompt search. The design cleanly separates "how agents coordinate" from "what each agent does", which is the knob prompt-optimization pipelines have been collapsing.
- **Theme:** Multi-agent frameworks & orchestration
- **Relevance:** A clean, generic coordinator/executor abstraction that any prompt optimizer can slot into — directly on-theme for orchestration and communication-protocol work.
- **Link:** https://arxiv.org/abs/2610.34722

## 2. R²Orch: Recursive Self-Improvement for Agent Orchestration via Self-Play within a Skill-Internalization Loop
- **Authors:** Mingda Zhang, Yun Huang, Qiang Huang, et al.
- **Summary:** R²Orch replaces hand-designed curricula and single-score skill judgments with nested self-play: an inner loop improves the orchestrator on tasks proposed by a Proposer, and an outer loop rewrites that curriculum by rewarding the Proposer for picking tasks whose outcomes diverge as skills are withdrawn. The Skill-Withdrawal mechanism retires skills once a controlled evaluation shows the orchestrator does as well without them, driving the system toward a zero-skill deployment where capabilities have been internalized into weights. On twelve datasets (QA, math, code, interactive) the recipe beats baselines, and the released R2Orch code trains the full loop end-to-end.
- **Theme:** Multi-agent frameworks & orchestration
- **Relevance:** A rare treatment of orchestration as a learning problem (not just a prompt-engineering problem), with an explicit mechanism for distilling skills back into the orchestrator — fresh on-theme contribution.
- **Link:** https://arxiv.org/abs/2610.22740

## 3. REA: A Routed Embodied Agent Runtime for Asynchronous Brain–Cerebellum Control
- **Authors:** Pengfei Zhou, Yixing Ma, Zhengfeiyang Zhang, et al.
- **Summary:** REA runs a deliberative "System-2" foundation-model agent, a learned "System-1" router, and reactive "System-0" low-level policies inside one runtime under a strict rule that no running policy may wait on the brain, replacing per-step LLM calls with a pre-measured route memory, a boundary-triggered judge gate, and a shared-budget escalation ladder. On LIBERO-Pro (3,000 episodes across 60 tasks) it reaches 95.9% success while cutting control steps 25% and control time 17%, and the same runtime transfers to RoboTwin 2.0, BEHAVIOR-1K, and a real Unitree G1 humanoid. The novelty is making heterogeneous policies — frontier LLMs, VLAs, hand-written code — compose asynchronously inside one agent architecture.
- **Theme:** Multi-agent frameworks & orchestration
- **Relevance:** Concrete multi-tier agent runtime with explicit coordination/routing primitives; demonstrates orchestration under real-time constraints.
- **Link:** https://arxiv.org/abs/2610.42053

## 4. RoboArchitect: Automating the Design of Robotic Agents with Persistent Memory
- **Authors:** Shengguang Wu, Suning Huang, Cherie Ho, et al.
- **Summary:** RoboArchitect uses a coding model as a "harness architect": it watches rollouts of a frozen robot policy, diagnoses failures, and iteratively edits the surrounding control code — when to query vision tools, when to call the policy, how to recover — including a persistent memory file in which the harness records learned facts like effective grasp depths. Without touching policy weights, the evolved harness lifts average success from 9.7%→43.3% on unseen scenes and 12.7%→40.2% on unseen tasks, often beating a fine-tuned baseline on far-OOD setups. The result is a concrete piece of evidence that an LLM-authored agent architecture around a frozen policy can replace fine-tuning as the adaptation primitive.
- **Theme:** Multi-agent frameworks & orchestration
- **Relevance:** Automated agent-architecture design loop with a learned persistent-memory channel — directly addresses "agent architectures" and "role/tool assignment".
- **Link:** https://arxiv.org/abs/2610.42141

## 5. HALO: Human-Grounded Granular Evaluation of Proactive Agents
- **Authors:** Wenqi Pei, Xinyu Wang, Jinrui Liu, et al.
- **Summary:** HALO benchmarks proactive agents on four need types (Dependency, Blockage, Risk, Opportunity) across 10 everyday domains and 50 personal environments, requiring the agent to retrieve evidence from structured DBs or documents before deciding whether to intervene and at what intensity. HALO-8K adds 8,000 model responses graded by 20 experts along action level, acceptability, and diagnosis — recording timing and intensity failures separately — and finds over-proactivity (premature or excessive intervention) accounts for 61.2% of rejected responses, with the best proprietary / open models at 72.9% / 56.6% acceptability. It is one of the first evaluations that measures when agents act, not just whether they succeed.
- **Theme:** Core LLM advances (agentic-system evaluation)
- **Relevance:** Granular, human-grounded evaluation of agent behavior with diagnostic categories for timing and intensity — exactly the kind of agent-eval instrument the theme calls for.
- **Link:** https://arxiv.org/abs/2610.39086

## 6. CaPtain: A Pipeline for Post-Training Code-as-Policy Robot Agents
- **Authors:** Yijia Fan, Xilin He, Yilei Jiang, et al.
- **Summary:** CaPtain treats a robot policy as an agent that writes code against low-level perception/geometry/guarded-motion APIs and trains it with the familiar SFT-then-multi-turn-RL recipe, including a "physical critic" that reads privileged simulator state and credits individual code-call turns by how much they moved the predicted end-of-episode success probability. Starting from a 0% zero-shot Qwen3.5-4B, CaPtain reaches 73.8% on LIBERO after RL and 78.5% on LIBERO-PRO, and transfers to real hardware after sim-only adaptation while releasing weights, data, and the harness. The physical-critic turn-credit mechanism is a transferable idea for any long-horizon agent whose actions only pay off much later.
- **Theme:** Core LLM advances — agentic RL for code-writing agents (also brushes spec-driven / code-correctness)
- **Relevance:** Only HF-featured paper this cycle that explicitly trains a code-generating agent with a correctness-shaped reward; the closest match to the formal-correctness-for-coding-agents theme.
- **Link:** https://arxiv.org/abs/2610.40799

## 7. On the Origin and Evolution of Training–Inference Mismatch in LLM Reinforcement Learning
- **Authors:** Yu Li, Yufa Zhou, Tian Lan
- **Summary:** The paper decomposes the off-policyness of real-world LLM RL into two separate sources — the numerical gap between the inference engine and the trainer at the sampler's weights, and the policy lag introduced by asynchronous weight updates — showing numerics is roughly a fixed bias (removable by per-prefix score centering) while policy lag drives a self-reinforcing feedback loop that importance weighting only tames while the effective-sample-size ratio stays above one half. From that account they derive DLC (Discrepancy–Lag Correction), which centers the numerical term, clips the lag ratio against the sampler, and resynchronizes when ESS drops; on Qwen3-0.6B/1.7B it keeps the KL from on-policy within 2× the natural on-policy noise and avoids collapses that per-token corrections miss. It is a careful diagnostic story for why asynchronous RLHF/RLVR pipelines fall over.
- **Theme:** Core LLM advances (reinforcement learning / fine-tuning for LLMs)
- **Relevance:** Addresses a core, under-analyzed failure mode of large-scale LLM RL — directly relevant to the fine-tuning / post-training strand.
- **Link:** https://arxiv.org/abs/2610.40945

## 8. SciGame: Let Agents Play the Scientific Discovery Games in the Real and Counterfactual World
- **Authors:** Yusheng Zhao, Bowei He, Xue Liu, Mingxiao Li
- **Summary:** SciGame converts papers into "scientific cards" that each define a pair of environments — the original physical law and a dimensionally consistent counterfactual version — and then measures an agent's Identification and open-ended Discovery performance under Prior-only, Fixed, and Adaptive experimentation protocols, with a live Temporal split curated from post-cutoff papers so pretrained memorization cannot shortcut it. Five frontier models show that familiar priors actively hurt once the governing relation is altered, adaptive experimentation only helps the strongest models at tight budgets, and recovering the exact symbolic law remains the bottleneck even when agents interpret evidence correctly. The counterfactual-pair design is a sharper instrument than static science benchmarks for separating empirical reasoning from pretraining recall.
- **Theme:** Core LLM advances (agentic-system evaluation, planning under exploration)
- **Relevance:** Benchmark that disentangles priors from experimentation — a clean addition to the agent-evaluation literature.
- **Link:** https://arxiv.org/abs/2610.37919

## 9. Latent Reasoning in Continuous Space for Unified Multimodal Models (LARC)
- **Authors:** Byungwoo Jeon, Yoonwoo Jeong, Hyunseok Lee, et al.
- **Summary:** LARC argues that chain-of-thought fails to lift image generation in unified multimodal models because reasoning happens in discrete token space while generation lives in continuous space, so it trains reasoning to run in the same continuous hidden-state manifold the generator uses. A two-stage recipe — curriculum SFT that gradually migrates token-level reasoning into latent reasoning, followed by information-gain RL without ground-truth labels — yields a 7-point gain over BAGEL on GenEval and the first clean test-time-scaling behavior for image generation under both parallel and sequential sampling. The modality-matched reasoning view is a transferable idea beyond image generation.
- **Theme:** Core LLM advances (reasoning, test-time scaling)
- **Relevance:** Direct contribution to the reasoning strand with an explicit test-time-scaling result; moves the "latent/continuous CoT" line of work forward.
- **Link:** https://arxiv.org/abs/2610.42149

## 10. MemSteer: Turning User Histories into Supervision for Agent Memory Optimization
- **Authors:** Jie Huang, Cuiling Lan, Qize Yu, et al.
- **Summary:** MemSteer synthesizes QA-plus-evidence supervision from unlabeled user histories by building evidence-grounded answer plans that specify how facts across records jointly support a reference answer, with source-grounded audits and blind answer recovery filtering the generated pairs. The companion MemSteer-Opt then uses that supervision to diagnose memory-system failures and revise the store / retrieval / context-construction stages — all without touching model parameters — matching optimizers that use official QA data on ATM-Bench and RHELM and improving over BM25 baselines by 13.4 / 4.1 / 6.6 points. The pipeline makes "which memory design is right for this user" an auto-tunable question.
- **Theme:** Core LLM advances (agent memory as a design problem to optimize, agentic-system evaluation)
- **Relevance:** Operationalizes memory-design evaluation and gives a label-free optimization loop — directly useful for anyone comparing agent-memory architectures.
- **Link:** https://arxiv.org/abs/2610.39276
